[name]

Абстрактный класс материалов.

Материалы описывают внешний вид [page:Object объектов]. В большинстве случаев они определяются независимым от рендерера способом, поэтому вам не придется переписывать материалы, если вы решите использовать другой рендерер.

Следующие свойства и методы наследуются всеми другими типами материалов (хотя они могут иметь другие значения по умолчанию).

Конструктор

[name]()

Создает абстрактный материал (вызывать не имеет смысла).

Свойства

[property:Float alphaTest]

Устанавливает значение альфы, которая будет использоваться при выполнении альфа-теста. Материал не будет отрисован, если непрозрачность меньше этого значения. По умолчанию `0`.

[property:Boolean alphaToCoverage]

Включает функцию alpha to coverage. Может использоваться только в том случае, когда MSAA включён для текущего контекста рендеринга (рендерер должен быть создан с параметром `antialias` равным `true`). По умолчанию `false`.

[property:Constant blendDst]

Назначение смешивания. По умолчанию [page:Materials.custom_blending OneMinusSrcAlphaFactor]. Все возможные значения данного свойства смотрите [page:Materials.custom_blending здесь].

Чтобы этот параметр имел эффект, свойство [page:.blending] должно быть установлено в [page:Materials.blending_mode CustomBlending].

[property:Constant blendDstAlpha]

Прозрачность [page:.blendDst]. Используется значение [page:.blendDst], если оно равно `null`. По умолчанию `null`.

[property:Constant blendEquation]

Уравнивание используемое для смешивания. По умолчанию используется [page:Material.custom_blending AddEquation]. Все возможные значения этого свойства смотрите [page:Materials.custom_blending здесь].

Чтобы этот параметр имел эффект, свойство [page:.blending] должно быть установлено в [page:Materials.blending_mode CustomBlending].

[property:Constant blendEquationAlpha]

Прозрачность [page:.blendEquation]. Используется значение [page:.blendEquation], если оно равно `null`. По умолчанию `null`.

[property:Blending blending]

Какое смешивание использовать при отображении объектов с данным материалом.

Это значение должно быть установлено в [page:Materials.blending_mode CustomBlending] для использования пользовательских [page:.blendSrc], [page:.blendDst] или [page:.blendEquation].

Все возможные значения см. в разделе [page:Materials.blending_mode режимы смешивания]. По умолчанию используется [page:Materials.blending_mode NormalBlending].

[property:Constant blendSrc]

Источник смешивания. По умолчанию [page:Materials.custom_blending SrcAlphaFactor]. Все возможные значения данного свойства смотрите [page:Materials.custom_blending здесь]

Чтобы этот параметр имел эффект, свойство [page:.blending] должно быть установлено в [page:Materials.blending_mode CustomBlending].

[property:Constant blendSrcAlpha]

Прозрачность [page:.blendSrc]. Используется значение [page:.blendSrc], если оно равно `null`. По умолчанию `null`.

[property:Boolean clipIntersection]

Изменяет поведение секущих плоскостей так, что обрезается только их пересечение, а не их объединение. По умолчанию `false`.

[property:Array clippingPlanes]

Определяемые пользователем секущие плоскости, заданные как объекты [page:Plane] в мировом пространстве. Эти плоскости применяются к объектам, к которым прикреплен данный материал. Точки в пространстве, чье расстояние до плоскости отрицательно, обрезаются (не отображаются). Для работы этой функции свойство [page:WebGLRenderer.localClippingEnabled] должно быть установлено в `true`. По умолчанию `null`.

[property:Boolean clipShadows]

Определяет, следует ли обрезать тени в соответствии с секущими плоскостями, указанными для этого материала. По умолчанию `false`.

[property:Boolean colorWrite]

Нужно ли отображать цвет материала. Это свойство можно использовать вместе со свойством [page:Integer renderOrder] меша для создания невидимых объектов, которые закрывают другие объекты. По умолчанию `true`.

[property:Object defines]

Пользовательские определения для вставки в шейдер. Они передаются в виде объекта с парами ключ/значение. `{ MY_CUSTOM_DEFINE: '' , PI2: Math.PI * 2 }`. Эти пары определяются как в вершинных, так и во фрагментных шейдерах. По умолчанию — `undefined`.

[property:Constant depthFunc]

Какую функцию глубины использовать. По умолчанию [page:Materials.depth_mode LessEqualDepth]. Все возможные значения см. [page:Materials.depth_mode здесь].

[property:Boolean depthPrepass]

Если `true`, использовать специальный режим прозрачности "Depth Prepass", который рендерит только один (ближайший к наблюдателю) слой прозрачности.

[property:Boolean depthTest]

Включать ли проверку глубины при рендеринге этого материала. По умолчанию `true`.

[property:Boolean depthWrite]

Влияет ли рендеринг этого материала на буфер глубины. По умолчанию `true`.

При отрисовке 2Д-наложений может быть полезно отключить запись глубины, чтобы сложить несколько объектов вместе, не создавая артефактов Z-буфера.

[property:Boolean dithering]

Применять ли к цвету дизеринг для устранения полос. По умолчанию `false`.

[property:Boolean envMapAutoAssign]

Если `true`, то `envMap` и связанные с ним свойства параллакса таких материалов, как [page:MeshStandardMaterial] и [page:MeshNodeMaterial] автоматически назначаются/вычисляются в соответствии с тем, какой [page:CubeReflectionProbe] влияет на объект, на котором используется этот материал. По умолчанию [page:Material.DefaultEnvMapAutoAssign] (`true`).

[property:Integer id]

Уникальный номер для данного экземпляра материала.

[property:Boolean isMaterial]

Является ли объект экземпляром класса [name]. Только для чтения.

[property:String name]

Необязательное имя объекта (не обязательно уникальное). По умолчанию используется пустая строка.

[property:Boolean needsUpdate]

Указывает, что материал должен быть перекомпилирован.

[property:Float opacity]

Величина в диапазоне `0.0` - `1.0`, указывающая, насколько прозрачен материал. Значение `0.0` означает полностью прозрачный, `1.0` - полностью непрозрачный.

Если свойство [page:Boolean transparent] материала не установлено в `true`, материал будет оставаться полностью непрозрачным, и это значение будет влиять только на его цвет. По умолчанию `1.0`.

[property:Boolean polygonOffset]

Использовать ли смещение полигонов. По умолчанию `false`. Это соответствует функции `GL_POLYGON_OFFSET_FILL` WebGL.

[property:Integer polygonOffsetFactor]

Устанавливает коэффициент смещения полигонов. По умолчанию `0`.

[property:Integer polygonOffsetUnits]

Устанавливает единицы измерения смещения полигонов. По умолчанию `0`.

[property:String precision]

Переопределяет точность рендеринга по умолчанию для этого материала. Может быть `"highp"`, `"mediump"` или `"lowp"`. По умолчанию `null`.

[property:Boolean premultipliedAlpha]

Нужно ли предварительно умножать значение альфа-канала (прозрачности). По умолчанию `false`.

[property:Constant shadowSide]

Определяет, с какой стороны грани отбрасывают тени. Может быть [page:Materials.side v3d.FrontSide], [page:Materials.side v3d.BackSide], [page:Materials.side v3d.DoubleSide] или `null`. По умолчанию используется [page:Materials.side v3d.FrontSide].

Если `null`, то сторона, отбрасывающая тени, определяется следующим образом:

[page:Material.side] Сторона, отбрасывающая тень
v3d.FrontSide задняя сторона
v3d.BackSide передняя сторона
v3d.DoubleSide обе стороны

[property:Constant side]

Определяет, какая сторона граней будет отрисовываться: передняя, задняя или обе. По умолчанию [page:Materials.side v3d.FrontSide]. Другие варианты: [page:Materials.side v3d.BackSide], [page:Materials.side v3d.DoubleSide] и [page:Materials.side v3d.TwoPassDoubleSide].

[property:Boolean stencilWrite]

Выполняются ли операции с буфером шаблона. Для выполнения записи или сравнения с буфером шаблона это значение должно быть `true`. По умолчанию `false`.

[property:Integer stencilWriteMask]

Битовая маска, используемая при записи в буфер шаблона. По умолчанию `0xFF`.

[property:Integer stencilFunc]

Используемая функция сравнения шаблонов. По умолчанию [page:Materials.stencil_function AlwaysStencilFunc]. Все возможные значения свойства смотрите [page:Materials.stencil_function здесь].

[property:Integer stencilRef]

Значение, используемое при выполнении сравнений шаблонов или операций с шаблонами. По умолчанию `0`.

[property:Integer stencilFuncMask]

Битовая маска, используемая при сравнении с буфером шаблона. По умолчанию `0xFF`.

[property:Integer stencilFail]

Какую операцию выполнять с шаблоном, если функция сравнения возвращает false. По умолчанию - [page:Materials.stencil_operation KeepStencilOp]. Все возможные значения см. в разделе [page:Materials.stencil_operation операции с шаблонами].

[property:Integer stencilZFail]

Какую операцию выполнять с шаблоном, если функция сравнения возвращает true, но тест глубины не прошел. По умолчанию [page:Materials.stencil_operation KeepStencilOp]. Все возможные значения см. в разделе [page:Materials.stencil_operation операции с шаблонами].

[property:Integer stencilZPass]

Какую операцию выполнять с шаблоном, если функция сравнения возвращает true и тест глубины пройден. По умолчанию [page:Materials.stencil_operation KeepStencilOp]. Все возможные значения см. в разделе [page:Materials.stencil_operation операции с шаблонами].

[property:Boolean toneMapped]

Определяет, накладывается ли на этот материал тоновое отображение в соответствии с настройкой [page:WebGLRenderer.toneMapping toneMapping] рендерера. По умолчанию `true`.

[property:Boolean transparent]

Определяет, является ли этот материал прозрачным. Это влияет на рендеринг поскольку прозрачные объекты требуют особого обращения и отображаются после непрозрачных объектов.

Если установлено значение `true`, то степень прозрачности материала контролируется установкой его свойства [page:Float opacity]. По умолчанию `false`.

[property:String type]

Значение — строка `"Material"`. Это значение не должно быть изменено и может быть использовано для того, чтобы найти все объекты данного типа в сцене.

[property:String uuid]

[link:https://ru.wikipedia.org/wiki/UUID UUID] данного экземпляра материала. Он присваивается автоматически, поэтому его не нужно редактировать.

[property:Integer version]

Он начинается с `0` и считает, сколько раз [property:Boolean needsUpdate] установлено в `true`.

[property:Boolean vertexColors]

Определяет, будет ли использоваться раскраска вершин. По умолчанию `false`.

Это свойство не оказывает влияния на [page:MeshNodeMaterial нодовые материалы].

[property:Boolean visible]

Определяет, является ли данный материал видимым. По умолчанию `true`.

[property:Object userData]

Объект, который можно использовать для хранения пользовательских данных о материале. Он не должен содержать ссылки на функции, так как они не будут клонироваться.

Статические свойства

[property:Boolean DefaultEnvMapAutoAssign]

Настройка по умолчанию для [page:.envMapAutoAssign] для вновь созданных материалов. Значение по умолчанию — `true`.

Методы

[page:EventDispatcher EventDispatcher] методы доступны для этого класса.

[method:Material clone]()

Возвращает новый материал с теми же параметрами, что и данный материал.

[method:Material copy]([param:Material material])

Копирует параметры из указанного материала в текущий.

[method:String customProgramCacheKey]()

В случае использования onBeforeCompile этот коллбэк может использоваться для определения значений параметров, используемых в onBeforeCompile, чтобы Verge3D мог повторно использовать кэшированный шейдер или перекомпилировать шейдер для данного материала по мере необходимости.

Например, если onBeforeCompile содержит условное утверждение типа:

if (black) { shader.fragmentShader = shader.fragmentShader.replace('gl_FragColor = vec4(1)', 'gl_FragColor = vec4(0)') }

то customProgramCacheKey должен быть установлен следующим образом:

material.customProgramCacheKey = function() { return black ? '1' : '0'; }

В отличие от свойств, коллбэк не поддерживается в методах [page:.clone]() и [page:.copy]().

[method:undefined dispose]()

Освобождает связанные с GPU ресурсы данного материала. Текстуры материала не утилизируются. Их необходимо утилизировать с помощью метода [page:Texture.dispose]().

[method:undefined onBeforeCompile]([param:Shader shader], [param:WebGLRenderer renderer])

Необязательный коллбэк, который выполняется непосредственно перед компиляцией программы шейдера. Эта функция вызывается с исходным кодом шейдера в качестве параметра. Полезно для модификации встроенных материалов.

В отличие от свойств, коллбэк не поддерживается в методах [page:.clone]() и [page:.copy]().

[method:undefined setValues]([param:Object values])

values — контейнер с параметрами.

Устанавливает свойства на основе `values`.
