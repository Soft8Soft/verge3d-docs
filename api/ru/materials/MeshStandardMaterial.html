[name]

Стандартный материал на основе физических законов освещения, использующий конвенцию Metallic-Roughness.

Рендеринг на основе физики (PBR) является стандартом во многих 3Д-приложениях. Этот подход отличается от старых тем, что вместо использования приближенных данных о том, как свет взаимодействует с поверхностью, используется физически корректная модель. Идея заключается в том, что вместо того, чтобы настраивать материалы так, чтобы они хорошо выглядели при определенном освещении, можно создать материал, который будет "правильно" реагировать на все сценарии освещения.

Для достижения наилучших результатов при использовании этого материала всегда следует указывать [page:.envMap карту окружения].

Конструктор

[name]([param:Object parameters])

[page:Object parameters] — (необ.) объект с одним или несколькими свойствами, определяющими внешний вид материала. Сюда можно передать любое свойство материала (включая любое свойство, унаследованное от [page:Material]).

Исключением является свойство [page:Hexadecimal color], которое может быть передано в виде шестнадцатеричной строки и по умолчанию имеет значение `0xffffff` (белый). Для него производится вызов метода [page:Color.set](color).

Вместо создания данного материала с использованием «Ява Скрипта», более эффективным методом будет сделать аналогичный материал в «Блендере», «3дс Максе» или «Майе».

Свойства

Общие свойства смотрите в базовом классе [page:Material].

[property:Texture aoMap]

Красный канал этой текстуры используется в качестве карты эмбиент окклюжн. По умолчанию — `null`. Для карты aoMap требуется вторая текстурная развёртка.

[property:Float aoMapIntensity]

Интенсивность эффекта эмбиент окклюжн. По умолчанию - `1`. Нулевое значение отключает эффект.

[property:Texture bumpMap]

Текстура для создания карты неровностей. Черные и белые значения отображают воспринимаемую глубину относительно освещения. Фактически не влияет на геометрию объекта, только на освещение. Если определена карта нормалей, то она будет проигнорирована.

[property:Float bumpScale]

Насколько сильно карта неровностей влияет на материал. Типичные диапазоны 0-1. По умолчанию — `1`.

[property:Color color]

[page:Color Цвет] материала, по умолчанию используется белый цвет (`0xffffff`).

[property:Object defines]

Объект вида:

{ 'STANDARD': '' };

Используется в [page:WebGLRenderer] для выбора шейдеров.

[property:Color emissive]

Излучающий (световой) цвет материала, по сути, сплошной цвет, на который не влияет другое освещение. По умолчанию — черный.

[property:Texture emissiveMap]

Устанавливает карту излучения (свечения). По умолчанию — `null`. Цвет эмиссионной карты модулируется цветом эмиссии и интенсивностью эмиссии. Если у вас есть эмиссионная карта, обязательно установите цвет излучения на какой-либо другой, но не черный.

[property:Float emissiveIntensity]

Интенсивность излучаемого света. Модулирует цвет излучения. По умолчанию - `1`.

[property:Texture envMap]

Карта окружения. Для обеспечения физически корректного рендеринга следует добавлять только те карты окружения, которые были предварительно обработаны [page:PMREMGenerator]. Назначается автоматически из соответствующего объекта [page:CubeReflectionProbe], если [page:Material.envMapAutoAssign] имеет значение `true`. По умолчанию — `null`.

[property:Float envMapIntensity]

Масштабирует эффект карты окружения путем умножения ее цвета. По умолчанию `1`.

[property:Matrix4 envMapParallaxMatrix]

[page:Matrix4] используется для применения эффекта параллакса к [page:.envMap] материала. Эта матрица переносит преобразование из мирового пространства в пространство конкретного [page:CubeReflectionProbe reflection probe], карту окружения которого этот материал использует для рендеринга. Вычисляется автоматически, если [page:Material.envMapAutoAssign] — `true`. По умолчанию используется единичная матрица.

[property:Matrix4 envMapParallaxMatrixInv]

[page:Matrix4], обратная к [page:.envMapParallaxMatrix]. Используется для применения эффекта параллакса к [page:.envMap] материала. Вычисляется автоматически, если [page:Material.envMapAutoAssign] — `true`. По умолчанию используется единичная матрица.

[property:Constant envMapParallaxType]

Определяет тип объема параллакса. Такое же, как [page:CubeReflectionProbe.parallaxType]. Назначается автоматически из соответствующего [page:CubeReflectionProbe], если [page:Material.envMapAutoAssign] — `true`. По умолчанию [page:Lights ReflectionProbeTypeInfinite].

[property:Boolean flatShading]

Использовать ли плоскостной шейдинг для геометрии модели. По умолчанию `false`.

[property:Boolean fog]

Будет ли туман влиять на данный материал. По умолчанию `true`.

[property:Boolean isMeshStandardMaterial]

Флаг, указывающий что объект является экземпляром [name]. Только для чтения.

[property:Texture map]

Карта цветов. Может иметь дополнительный альфа-канал, используемый в сочетании со свойствами [page:Material.transparent .transparent] и [page:Material.alphaTest .alphaTest]. По умолчанию `null`. Цвет данной текстуры модулируется диффузным [page:.color цветом].

[property:Float metalness]

Насколько материал похож на металл. Неметаллические материалы, такие как дерево или камень, используют 0.0, металлические - 1.0, и ничего (обычно) между ними нет. По умолчанию — `0`. Значения между `0.0` и `1.0` могут использоваться для получения эффекта ржавчины. Если указана карта metalnessMap, оба значения перемножаются.

[property:Texture metalnessMap]

Синий канал этой текстуры используется для изменения "металличности" материала.

[property:Texture normalMap]

Текстура для создания карты нормалей. Значения RGB влияют на нормаль поверхности для каждого фрагмента пикселя и изменяют способ освещения. Карты нормалей не изменяют фактическую форму поверхности, только освещение. В случае, если материал имеет карту нормалей, созданную с использованием левосторонней конвенции, компонент y [page:.normalScale] должен быть отрицательным, чтобы компенсировать разную ориентацию.

[property:Vector2 normalScale]

Насколько сильно карта нормалей влияет на материал. Типичные диапазон - 0-1. По умолчанию используется вектор `(1, 1)`.

[property:Float roughness]

Насколько шероховатым кажется материал. `0.0` означает гладкое зеркальное отражение, `1.0` - полностью рассеянное. По умолчанию `1.0`. Если указан параметр roughnessMap, оба значения умножаются.

[property:Texture roughnessMap]

Зеленый канал этой текстуры используется для изменения шероховатости материала.

[property:Boolean wireframe]

Рендерит геометрию в виде каркаса («вайрфрейма»). По умолчанию `false` (т.е. используется полное заполнение полигонов).

[property:Float wireframeLinewidth]

Управляет толщиной каркаса. По умолчанию - `1`.

В связи с ограничениями [page:WebGLRenderer WebGL], на большинстве платформ ширина линии всегда будет равна 1, независимо от установленного значения.
