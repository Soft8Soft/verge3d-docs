[name]

Класс, содержащий полезные методы для работы с материалами.

Методы

[method:undefined replaceTexture]([param:Material mat], [param:Texture oldTex], [param:Texture newTex])

  • [page:Material mat] — материал.
  • [page:Texture oldTex] — заменяемая текстура.
  • [page:Texture newTex] — новая текстура.

Заменяет текстуру на указанном материале. Метод поддерживается только для материалов [page:MeshNodeMaterial] и [page:MeshStandardMaterial].

[method:undefined disposeTextures]([page:Material mat])

  • [page:Material mat] — материал.

Удаляет все [page:Texture textures], найденные в данном [page:Material материале]. Метод поддерживается только для материалов [page:MeshNodeMaterial] и [page:MeshStandardMaterial].

[method:MeshNodeMaterial createDiffuseMaterial]([param:String name], [param:Color color], [param:Float opacity], [param:String profile])

  • [page:String name] — имя материала.
  • [page:Color color] — диффузный цвет материала.
  • [page:Float opacity] — прозрачность материала.
  • [page:String profile] — (необ.) профиль материала, определяет из каких нод будет составлен граф материала. Один из `"blender"`, `"max"`, `"maya"`. По умолчанию `"blender"`.

Создаёт диффузный нодовый материал («ламберт») с указанными параметрами `color` и `opacity`.

[method:MeshNodeMaterial createEnvironmentMaterial]([param:String name], [param:Texture envTex], [param:Texture|Color bkgTexOrColor])

  • [page:String name] — имя материала.
  • [page:Texture envTex] — текстура используемая для освещения.
  • bkgTexOrColor — [page:Texture текстура] или [page:Color цвет] фона.

Создаёт нодовый материал, который используется для рендеринга освещения от окружения и фона.

[method:MeshNodeMaterial createStandardPBRMaterial]([param:String profile], [param:Object params])

  • [page:String profile] — (необ.) профиль материала, определяет из каких нод будет составлен граф материала. Один из `"blender"`, `"max"`, `"maya"`. По умолчанию `"blender"`.
  • [page:Object params] — (необ.) объект с параметрами материала.

Создаёт нодовый PBR-материал с указанными параметрами:

[page:Color color]
Базовый цвет материала. По умолчанию `'white'`.
[page:Float opacity]
Прозрачность материала. По умолчанию `1.0` (непрозрачный).
[page:Float metalness]
Металличность материала. По умолчанию `0` (не металл).
[page:Float roughness]
Шероховатость материала. По умолчанию `1` (максимальная шероховатость).
[page:Color emissive]
Эмиссивный цвет материала. По умолчанию `'black'`.
[page:Float emissiveIntensity]
Интенсивность эмиссивного цвета. По умолчанию `1`.
