[name]

[name] внутренне используется для реализации отображения теней с помощью [page:PointLight] и [page:RectAreaLight] источников освещения.

Можно также использовать для настройки отбрасывания тени объектом, указав экземпляр [name] в свойстве [page:Object3D.customDistanceMaterial].

Конструктор

[name]([param:Object parameters])

[page:Object parameters] — (необ.) объект с одним или несколькими свойствами, определяющими внешний вид материала. Сюда можно передать любое свойство материала (включая любое свойство, унаследованное от [page:Material]).

Свойства

Общие свойства смотрите в базовом классе [page:Material].

[property:Float farDistance]

Дальнее значение внутренней теневой камеры источника освещения.

[property:Boolean fog]

Влияет ли на материал туман. По умолчанию `false`.

[property:Texture map]

Карта цветов. Может иметь дополнительный альфа-канал, используемый в сочетании со свойствами [page:Material.transparent .transparent] и [page:Material.alphaTest .alphaTest]. По умолчанию `null`.

[property:Float nearDistance]

Ближнее значение внутренней теневой камеры источника освещения.

[property:Vector3 referencePosition]

Положение источника освещения в мировой системе координат.

[property:Float slopeScaledBias]

Адаптивное смещение, которое зависит от наклона полигона относительно камеры. Применяется только если параметр [page:.useSlopeScaledBias] установлен в `true`. По умолчанию `0`. Для материалов, используемых для наложения теней, данный параметр устанавливается автоматически на основе [page:LightShadow.slopeScaledBias]. Исключением являются ESM-тени, для которых `slopeScaledBias` устанавливается в `0.5`.

[property:Boolean useSlopeScaledBias]

Включает или выключает [page:.slopeScaledBias]. По умолчанию `false`. Для материалов, используемых для наложения теней, данный параметр устанавливается автоматически и всегда равен `true`.
