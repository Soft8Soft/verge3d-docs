[name]

Материал для использования вместе со [page:Sprite спрайтами].

Пример

const map = new v3d.TextureLoader().load('mysprite.png'); const material = new v3d.SpriteMaterial({ map: map, color: 0xffffff }); const sprite = new v3d.Sprite(material); sprite.scale.set(200, 200, 1) app.scene.add(sprite);

Конструктор

[name]([param:Object parameters])

[page:Object parameters] — (необ.) объект с одним или несколькими свойствами, определяющими внешний вид материала. Сюда можно передать любое свойство материала (включая любое свойство, унаследованное от [page:Material]).

Исключением является свойство [page:Hexadecimal color], которое может быть передано в виде шестнадцатеричной строки и по умолчанию имеет значение `0xffffff` (белый). Для него производится вызов метода [page:Color.set](color).

Данные материалы не обрезаются при использовании [page:Material.clippingPlanes].

Свойства

Общие свойства смотрите в базовом классе [page:Material].

[property:Color color]

[page:Color Цвет] материала, по умолчанию используется белый (`0xffffff`). Текстура [page:.map] умножается на этот цвет.

[property:Boolean fog]

Будет ли туман влиять на данный материал. По умолчанию `true`.

[property:Boolean isSpriteMaterial]

Флаг, указывающий является ли объект экземпляром класса [name]. Только для чтения.

[property:Texture map]

Карта цветов. Может иметь дополнительный альфа-канал, используемый в сочетании со свойствами [page:Material.transparent .transparent] и [page:Material.alphaTest .alphaTest]. По умолчанию `null`.

[property:Float rotation]

Вращение спрайта в радианах. По умолчанию `0`.

[property:Boolean sizeAttenuation]

Зависит ли размер спрайта от глубины камеры (только для перспективных камер). По умолчанию `true`.

[property:Boolean transparent]

Является ли материал прозрачным. По умолчанию `true`.
