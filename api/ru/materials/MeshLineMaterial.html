[name]

Специальный материал для рисования линий. Предназначен для использования с мешами [page:MeshLine] и [page:MeshLineIndexed].

Конструктор

[name]([page:Material parameters])

[page:Material parameters] — (необ.) объект с одним или несколькими свойствами, определяющими внешний вид материала. Сюда можно передать любое свойство материала (включая любое свойство, унаследованное от [page:Material]).

Свойства

Общие свойства смотрите в базовом классе [page:RawShaderMaterial].

[property:Float alphaTest]

Пороговое альфа-значение для отбрасывания (от `0` до `1`).

[property:Color color]

Цвет линии.

[property:Boolean isMeshLineMaterial]

Используется для проверки того, является ли данный или производные классы материалами линии меша. Всегда `true`. Не следует изменять это значение, так как оно используется внутри движка с целью оптимизации.

[property:Float lineWidth]

Ширина линии (если [page:.sizeAttenuation sizeAttenuation] равен true, то это мировые единицы; в противном случае - пиксели экрана).

[property:Texture map]

Текстура, управляющая цветом вдоль линии (требуется, чтобы [page:.useMap useMap] имел значение `true`).

[property:Float opacity]

Значение альфа-канала линии (от `0` до `1`).

[property:Vector2 repeat]

Вектор для масштабирования UV-координат [page:.map map].

[property:Vector2 resolution]

Вектор, определяющий размер холста.

[property:Float sizeAttenuation]

Сделать ширину линии постоянной (если `0`) или нет (если `1`).

[property:Boolean useMap]

Использовать ли текстуру [page:.map map].

[property:Float visibility]

Управление видимостью частиц вдоль линии (от `0` до `1`) путем изменения значения альфа-канала.
