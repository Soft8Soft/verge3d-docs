[page:Object3D] →

[name]

Отображает вспомогательный объект в форме конуса для [page:SpotLight].

Пример

const spotLight = new v3d.SpotLight(0xffffff); spotLight.position.set(10, 10, 10); app.scene.add(spotLight); const spotLightHelper = new v3d.SpotLightHelper(spotLight); app.scene.add(spotLightHelper);

Конструктор

[name]([param:SpotLight light], [param:Color|Integer|String color])

  • [page:SpotLight light] — [page:SpotLight] для визуализации.
  • [page:Color color] — (необ.) если не задан, помощник использует цвет света.

Свойства

Общие свойства см. в базовом классе [page:Object3D].

[property:LineSegments cone]

[page:LineSegments] используется для визуализации света.

[property:SpotLight light]

Ссылка на визуализируемый [page:SpotLight].

[property:Object matrix]

Ссылка на [page:Object3D.matrixWorld matrixWorld] источника-прожектора.

[property:Object matrixAutoUpdate]

См. [page:Object3D.matrixAutoUpdate]. Установлено значение в `false`, так как помощник использует [page:Object3D.matrixWorld matrixWorld] источника-прожектора.

[property:Color color]

Параметр цвета, передаваемый в конструкторе. По умолчанию `undefined`. Если этот параметр изменить, цвет помощника будет обновлен при следующем вызове [page:.update update].

Методы

Общие методы см. в базовом классе [page:Object3D].

[method:undefined dispose]()

Освобождает все связанные с GPU ресурсы, используемые экземпляром [name]. Этот метод следует вызвать, если [name] больше не используется в приложении.

[method:undefined update]()

Обновляет помощника света.
