[page:Object3D] → [page:Line] → [page:LineSegments] →

[name]

Объект оси для визуализации 3 осей простым способом. Ось X имеет красный цвет. Ось Y - зеленый. Ось Z - синий.

Пример

const axesHelper = new v3d.AxesHelper(2); app.scene.add(axesHelper);

Конструктор

[name]([param:Float size])

[page:Float size] — (необ.) размер линий, представляющих оси. По умолчанию `1`.

Свойства

Общие свойства см. в базовом классе [page:LineSegments].

Методы

Общие методы см. в базовом классе [page:LineSegments].

[method:undefined dispose]()

Освобождает все связанные с GPU ресурсы, используемые экземпляром [name]. Этот метод следует вызвать, если [name] больше не используется в приложении.
