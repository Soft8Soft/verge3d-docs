[page:Object3D] → [page:Line] →

[name]

Вспомогательный объект для визуализации [page:RectAreaLight].

Пример

const light = new v3d.RectAreaLight(0xffffbb, 1.0, 5, 5); const helper = new RectAreaLightHelper(light); light.add(helper); // добавляется как дочерний

Конструктор

[name]([param:RectAreaLight light], [param:Color|Integer|String color])

  • [page:RectAreaLight light] — свет, который необходимо визуализировать.
  • [page:Color color] — (необ.) цвет; если не задан, помощник воспользуется цветом источника освещения.

Свойства

Общие свойства смотрите в базовом классе [page:Line].

[property:RectAreaLight light]

Визуализируемый [page:RectAreaLight].

[property:Color color]

Параметр цвета, передаваемый в конструкторе. По умолчанию `undefined`.

Методы

Общие методы смотрите в базовом классе [page:Line].

[method:undefined dispose]()

Удаляет объект из памяти. Вы должны вызвать этот вызов, когда вы хотите удалить [name] во время работы приложения.
