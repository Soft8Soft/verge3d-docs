[name]

3Д-объект в виде стрелки для визуализации направлений.

Пример

const dir = new v3d.Vector3(1, 2, 0); // нормализуем вектор направления (делаем его длину равной 1) dir.normalize(); const origin = new v3d.Vector3(0, 0, 0); const length = 1; const hex = 0xffff00; const arrowHelper = new v3d.ArrowHelper(dir, origin, length, hex); app.scene.add(arrowHelper);

Конструктор

[name]([param:Vector3 dir], [param:Vector3 origin], [param:Float length], [param:Color|Integer|String color], [param:Float headLength], [param:Float headWidth])

  • [page:Vector3 dir] — направление от начала координат. Должен быть единичным вектором.
  • [page:Vector3 origin] — точка, в которой начинается стрелка.
  • [page:Float length] — длина стрелки. По умолчанию `1`.
  • [page:Integer color] — шестнадцатеричное значение для определения цвета. По умолчанию `0xffff00` (жёлтый).
  • [page:Float headLength] — длина наконечника стрелки. По умолчанию 0.2 от длины.
  • [page:Float headWidth] — ширина наконечника стрелки. По умолчанию 0.2 от headLength.

Свойства

Общие свойства см. в базовом классе [page:Object3D].

[property:Line line]

Содержит линейную часть стрелки.

[property:Mesh cone]

Содержит конусную часть стрелки.

Методы

Общие методы см. в базовом классе [page:Object3D].

[method:undefined setColor]([param:Color color])

color — цвет.

Устанавливает цвет стрелки.

[method:undefined setLength]([param:Float length], [param:Float headLength], [param:Float headWidth])

  • length — длина.
  • headLength — длина наконечника стрелки.
  • headWidth — ширина наконечника стрелки.

Устанавливает длину стрелки.

[method:undefined setDirection]([param:Vector3 dir])

dir — желаемое направление. Должно быть единичным вектором.

Устанавливает направление стрелки.
