[page:Object3D] → [page:Mesh] →

[name]

Отображает вспомогательный объект, состоящий из сферического [page:Mesh меша] для визуализации [page:PointLight].

Пример

const pointLight = new v3d.PointLight(0xff0000, 1, 100); pointLight.position.set(10, 10, 10); app.scene.add(pointLight); const sphereSize = 1; const pointLightHelper = new v3d.PointLightHelper(pointLight, sphereSize); app.scene.add(pointLightHelper);

Конструктор

[name]([param:PointLight light], [param:Float sphereSize], [param:Color|Integer|String color])

  • [page:PointLight light] — источник освещения, который необходимо визуализировать.
  • [page:Float sphereSize] — (необ.) размер сферы помощника. По умолчанию `1`.
  • [page:Color color] — (необ.) если не задан, помощник возьмёт цвет источника освещения.

Свойства

Общие свойства см. в базовом классе [page:Mesh].

[property:PointLight light]

[page:PointLight], который визуализируется.

[property:Object matrix]

Ссылка на [page:Object3D.matrixWorld matrixWorld] точечного источника.

[property:Object matrixAutoUpdate]

См. [page:Object3D.matrixAutoUpdate]. Установлено значение `false`, так как помощник использует [page:Object3D.matrixWorld matrixWorld] точечного источника.

[property:hex color]

Параметр цвета, передаваемый в конструкторе. По умолчанию `undefined`. Если этот параметр изменить, цвет помощника будет обновлен при следующем вызове [page:.update update].

Методы

Общие методы см. в базовом классе [page:Mesh].

[method:undefined dispose]()

Освобождает все связанные с GPU ресурсы, используемые экземпляром [name]. Этот метод следует вызвать, если [name] больше не используется в приложении.

[method:undefined update]()

Обновляет помощника в соответствии с позицией [page:.light].
