[name]

Специальный рендер таргет, позволяющий фрагментному шейдеру выводить в несколько текстур одновременно. Данный подход полезен для реализации продвинутых техник рендеринга, наподобие пост-процессинга и отложенного рендеринга.

[name] может использоваться только с контекстом WebGL 2.

Конструктор

[name]([param:Integer width], [param:Integer height], [param:Integer count], [param:Object options])

  • [page:Integer width] — ширина рендер таргета. По умолчанию `1`.
  • [page:Integer height] — высота рендер таргета. По умолчанию `1`.
  • [page:Integer count] — количество рендер таргетов. По умолчанию `1`.
  • [page:Object options] — (необ.) объект с текстурными параметрами для генерации текстур таргета, а также флаги depthBuffer/stencilBuffer.

Объяснение текстурных параметров ищите в разделе [page:Texture Texture]. Список возможных опций находится в разделе [page:WebGLRenderTarget WebGLRenderTarget].

Свойства

[property:Boolean isWebGLMultipleRenderTargets]

Флаг, указывающий что данный объект является экземпляром класса [name]. Только для чтения.

[property:Array texture]

Свойство текстуры базового класса заменяется массивом. Этот массив содержит ссылки на [page:WebGLRenderTarget.texture текстуры] соответствующих рендер таргетов.

Свойства [page:WebGLRenderTarget WebGLRenderTarget] также доступны для данного класса.
