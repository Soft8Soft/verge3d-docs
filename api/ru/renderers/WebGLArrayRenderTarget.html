[name]

Этот класс служит для создания массива текстур.

Конструктор

[name]([param:Integer width], [param:Integer height], [param:Integer depth])

  • [page:Integer width] — ширина рендер таргета в пикселях. По умолчанию `1`.
  • [page:Integer height] — высота рендер таргета в пикселях. По умолчанию `1`.
  • [page:Integer depth] — глубина/количество слоёв рендер таргета. По умолчанию `1`.

Создаёт новый [name].

Свойства

Унаследованные свойства смотрите в [page:WebGLRenderTarget].

[property:Integer depth]

Глубина/количество слоёв рендер таргета.

[property:DataArrayTexture texture]

Свойство текстуры базового класса, переопределённое на [page:DataArrayTexture].
