[name]

Рендер таргет это буфер куда видеокарта выводит пиксели для сцены, которая рендерится в фоновом режиме. Он используется в различных эффектах, например, для применения постобработки к отрисованному изображению перед его выводом на экран.

Конструктор

[name]([param:Float width], [param:Float height], [param:Object options])

[page:Float width]
Ширина рендер таргета.
[page:Float height]
Высота рендер таргета.
[page:Object options]
Необязательный объект, содержащий параметры текстуры для целевой текстуры и флаги depthBuffer/stencilBuffer. Объяснение параметров текстуры см. в разделе [page:Texture Texture]. Ниже перечислены допустимые параметры:
[page:Constant wrapS]
По умолчанию [page:Textures ClampToEdgeWrapping].
[page:Constant wrapT]
По умолчанию [page:Textures ClampToEdgeWrapping].
[page:Constant magFilter]
По умолчанию [page:Textures LinearFilter].
[page:Constant minFilter]
По умолчанию [page:Textures LinearFilter].
[page:Boolean generateMipmaps]
По умолчанию `false`.
[page:Constant format]
По умолчанию [page:Textures RGBAFormat].
[page:Constant type]
По умолчанию [page:Textures UnsignedByteType].
[page:Integer anisotropy]
По умолчанию `1`. See [page:Texture.anisotropy].
[page:Constant encoding]
По умолчанию [page:Textures LinearEncoding].
[page:Boolean depthBuffer]
По умолчанию `true`.
[page:Boolean stencilBuffer]
По умолчанию `false`.
[page:Integer samples]
По умолчанию `0`.

Создаёт новый [name].

Свойства

[property:Boolean isWebGLRenderTarget]

Флаг, указывающий что данный объект является экземпляром [name]. Только для чтения.

[property:Float width]

Ширина рендер таргета.

[property:Float height]

Высота рендер таргета.

[property:Vector4 scissor]

Прямоугольная область внутри вьюпорта. Фрагменты, находящиеся за пределами этой области, будут проигнорированы.

[property:Boolean scissorTest]

Указывает, активен или нет тест ножниц.

[property:Vector4 viewport]

Вьюпорт рендер таргета.

[property:Texture texture]

Этот экземпляр текстуры содержит отрисованные пиксели. Используйте его в качестве исходного материала для дальнейшей обработки.

[property:Boolean depthBuffer]

Осуществляется ли рендеринг в буфер глубины. По умолчанию `true`.

[property:Boolean stencilBuffer]

Рендеринг в буфер шаблона. По умолчанию `false`.

[property:DepthTexture depthTexture]

Если установлено, то глубина сцены будет отрисовываться на эту текстуру. По умолчанию `null`.

[property:Integer samples]

Указывает на количество семплов для мультисемплинга (MSAA). Может использоваться только с WebGL 2. По умолчанию `0`.

Методы

[method:undefined setSize]([param:Float width], [param:Float height])

Устанавливает размер рендер таргета.

[method:WebGLRenderTarget clone]()

Создает копию рендер таргета.

[method:WebGLRenderTarget copy]([param:WebGLRenderTarget source])

Устанавливает настройки с другого рендер таргета.

[method:undefined dispose]()

Освобождает связанные с GPU ресурсы рендер таргета. Этот метод следует вызвать, если экземпляр класса больше не используется в приложении

Методы [page:EventDispatcher EventDispatcher] также доступны для этого класса.
