[name]

Используется классом [page:CubeCamera] в качестве [page:WebGLRenderTarget рендер таргета].

Конструктор

[name]([param:Integer size], [param:Object options])

[page:Integer size]
размер в пикселях. По умолчанию `1`.
[page:Object options]

необязательный объект, содержащий параметры текстуры для автогенерируемой целевой текстуры и булевых значений depthBuffer/stencilBuffer. Описание параметров текстуры см. в разделе [page:Texture Texture]. Ниже перечислены допустимые параметры:

[page:Constant wrapS]
По умолчанию [page:Textures ClampToEdgeWrapping].
[page:Constant wrapT]
По умолчанию [page:Textures ClampToEdgeWrapping].
[page:Constant magFilter]
По умолчанию [page:Textures LinearFilter].
[page:Constant minFilter]
По умолчанию [page:Textures LinearFilter].
[page:Boolean generateMipmaps]
По умолчанию `false`.
[page:Constant format]
По умолчанию [page:Textures RGBAFormat].
[page:Constant type]
По умолчанию [page:Textures UnsignedByteType].
[page:Integer anisotropy]
По умолчанию `1`. See [page:Texture.anisotropy]
[page:Constant encoding]
По умолчанию [page:Textures LinearEncoding].
[page:Boolean depthBuffer]
По умолчанию `true`.
[page:Boolean stencilBuffer]
По умолчанию `false`.

Создает новый [name].

Методы

Смотрите методы базового класса [page:WebGLRenderTarget].

[method:WebGLCubeRenderTarget fromEquirectangularTexture]([param:WebGLRenderer renderer], [param:Texture texture])

  • [page:WebGLRenderer renderer] — рендерер.
  • [page:Texture texture] — текстура с равнопромежуточной проекцией.

Используйте этот метод, если вы хотите преобразовать текстуру с равнопромежуточной проекцией в кубическую карту.

[method:undefined clear]([param:WebGLRenderer renderer], [param:Boolean color], [param:Boolean depth], [param:Boolean stencil])

Используйте эту функцию, чтобы очистить буферы цвета, глубины и/или шаблона. Цветовой буфер устанавливается в текущий цвет очистки рендерера. Все аргументы имеют значение `true` по умолчанию.
