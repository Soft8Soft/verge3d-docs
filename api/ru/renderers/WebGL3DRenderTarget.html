[name]

Трёхмерный рендер таргет.

Конструктор

[name]([param:Integer width], [param:Integer height], [param:Integer depth])

  • [page:Integer width] — ширина рендер таргета в пикселях. По умолчанию `1`.
  • [page:Integer height] — высота рендер таргета в пикселях. По умолчанию `1`.
  • [page:Integer depth] — глубина рендер таргета. По умолчанию `1`.

Создаёт новый [name].
