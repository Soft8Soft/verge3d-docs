[name]

Класс для генерации геометрии цилиндра.

Пример

const geometry = new v3d.CylinderGeometry(2, 2, 4); const material = new v3d.MeshStandardMaterial({color: 0x8458b3}); const cylinder = new v3d.Mesh(geometry, material); app.scene.add(cylinder);

Конструктор

[name]([param:Float radiusTop], [param:Float radiusBottom], [param:Float height], [param:Integer radialSegments], [param:Integer heightSegments], [param:Boolean openEnded], [param:Float thetaStart], [param:Float thetaLength])

  • radiusTop — радиус цилиндра в верхней части. По умолчанию равен 1.
  • radiusBottom — радиус цилиндра в нижней части. По умолчанию равен 1.
  • height — высота цилиндра. По умолчанию - 1.
  • radialSegments — количество сегментированных граней по окружности цилиндра. По умолчанию `32`.
  • heightSegments — количество рядов граней по высоте цилиндра. По умолчанию `1`.
  • openEnded — логическое значение, указывающее, являются ли концы цилиндра открытыми или закрытыми. По умолчанию `false`, то есть закрытые.
  • thetaStart — начальный угол для первого сегмента, по умолчанию `0` (положение на «три часа»).
  • thetaLength — центральный угол, часто называемый тета, кругового сектора. По умолчанию 2π (`2*Math.PI`), что позволяет получить полный цилиндр.

Процедурная геометрия может использоваться для обучения основам программирования, однако в реальной жизни используется редко. В большинстве случаев имеет смысл сделать модель цилиндра в пакете моделирования и загрузить в «Вердж3Д» с помощью glTF.

Объект с параметрами, указанными в конструкторе. Модификация свойств этого объекта после вызова конструктора не изменяет получившуюся геометрию.
