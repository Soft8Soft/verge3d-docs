[name]

Класс для генерации геометрии икосаэдра.

Пример

const geometry = new v3d.IcosahedronGeometry(2); const material = new v3d.MeshStandardMaterial({ color: 0xffff00 }); const ico = new v3d.Mesh(geometry, material); app.scene.add(ico);

Конструктор

[name]([param:Float radius], [param:Integer detail])

  • radius — по умолчанию `1`.
  • detail — по умолчанию `0`. При установке этого значения больше 0 добавляется больше вершин, в результате чего он перестает быть икосаэдром. Когда значение параметра больше 1, фактически получается сфера.

Процедурная геометрия может использоваться для обучения основам программирования, однако в реальной жизни используется редко. В большинстве случаев имеет смысл сделать модель икосаэдра в пакете моделирования и загрузить в «Вердж3Д» с помощью glTF.

Свойства

Смотрите свойства базового класса [page:BufferGeometry].

[property:Object parameters]

Объект с параметрами, указанными в конструкторе. Модификация свойств этого объекта после вызова конструктора не изменяет получившуюся геометрию.
