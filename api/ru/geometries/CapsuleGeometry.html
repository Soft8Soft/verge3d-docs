[name]

[name] это класс для создания геометрии капсулы с указанными радиусом и высотой. Капсула конструируется как поверхность вращения.

Пример

const geometry = new v3d.CapsuleGeometry(1, 1, 4, 8); const material = new v3d.MeshBasicMaterial({color: 0x00ff00}); const capsule = new v3d.Mesh(geometry, material); app.scene.add(capsule);

Конструктор

[name]([param:Float radius], [param:Float length], [param:Integer capSubdivisions], [param:Integer radialSegments])

  • radius — необязательный радиус капсулы. По умолчанию `1`.
  • length — высота средней части капсулы. По умолчанию `1`.
  • capSegments — количество дуговых сегментов для крышек. По умолчанию `4`.
  • radialSegments — количество сегментов вдоль окружности капсулы. По умолчанию `8`.

Процедурная геометрия может использоваться для обучения основам программирования, однако в реальной жизни используется редко. В большинстве случаев имеет смысл сделать модель капсулы в пакете моделирования и загрузить в «Вердж3Д» с помощью glTF.

Свойства

Смотрите свойства базового класса [page:BufferGeometry].

[property:Object parameters]

Объект с параметрами, указанными в конструкторе. Модификация свойств этого объекта после вызова конструктора не изменяет получившуюся геометрию.
