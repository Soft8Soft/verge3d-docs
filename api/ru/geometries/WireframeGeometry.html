[page:BufferGeometry] →

[name]

Используется в качестве вспомогательного объекта для отображения [page:BufferGeometry геометрии] в виде сетки.

Пример

const geometry = new v3d.SphereGeometry(3, 50, 30); const wireframe = new v3d.WireframeGeometry(geometry); const line = new v3d.LineSegments(wireframe); line.material.depthTest = false; line.material.opacity = 0.5; line.material.transparent = true; app.scene.add(line);

Конструктор

[name]([param:BufferGeometry geometry])

geometry — любой геометрический объект.
