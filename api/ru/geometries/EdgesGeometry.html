[page:BufferGeometry] →

[name]

Его можно использовать в качестве вспомогательного объекта для просмотра рёбер [page:BufferGeometry геометрии].

Пример

const geometry = new v3d.BoxGeometry(3, 3, 3); const edges = new v3d.EdgesGeometry(geometry); const line = new v3d.LineSegments(edges, new v3d.LineBasicMaterial({ color: 0xffffff })); app.scene.add(line);

Конструктор

[name]([param:BufferGeometry geometry], [param:Integer thresholdAngle])

  • geometry — любой геометрический объект.
  • thresholdAngle — грань отображается только в том случае, если угол (в градусах) между нормалями смежных граней превышает это значение. По умолчанию `1` градус.

Свойства

Смотрите свойства базового класса [page:BufferGeometry].

[property:Object parameters]

Объект с параметрами, указанными в конструкторе. Модификация свойств этого объекта после вызова конструктора не изменяет получившуюся геометрию.
