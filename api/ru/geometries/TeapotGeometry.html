[name]

Класс для генерации геометрии чайника Юты.

Пример

const geometry = new v3d.TeapotGeometry(2); const material = v3d.MaterialUtils.createStandardPBRMaterial('blender', { color: 'gold', roughness: 0.2, metalness: 1 }); const teapot = new v3d.Mesh(geometry, material); app.scene.add(teapot);

Конструктор

[name]([param:Float size], [param:Integer segments], [param:Boolean bottom], [param:Boolean lid], [param:Float body], [param:Boolean fitLid], [param:Boolean blinn])

  • [page:Float size] — радиус чайника. Значение по умолчанию `1`.
  • [page:Integer segments] — количество сегментов, используемых для генерации чайника. Значение по умолчанию `10`.
  • [page:Boolean bottom] — создать геометрию дна. Значение по умолчанию `true`.
  • [page:Boolean lid] — создать геометрию крышки. Значение по умолчанию `true`.
  • [page:Boolean body] — создать геометрию тела чайник. Значение по умолчанию `true`.
  • [page:Boolean fitLid] — растянуть крышку, чтобы закрыть шов. Значение по умолчанию `false`.
  • [page:Boolean blinn] — масштабирование Джима Блинна. Применяется для улучшения внешнего вида чайника. Значение по умолчанию `true`.

Процедурная геометрия может использоваться для обучения основам программирования, однако в реальной жизни используется редко. В большинстве случаев имеет смысл сделать модель чайника в пакете моделирования и загрузить в «Вердж3Д» с помощью glTF.
