[name]

Класс для создания геометрии плоскости.

Пример

const geometry = new v3d.PlaneGeometry(1, 1); const material = new v3d.MeshBasicMaterial({color: 0xffff00, side: v3d.DoubleSide}); const plane = new v3d.Mesh(geometry, material); app.scene.add(plane);

Конструктор

[name]([param:Float width], [param:Float height], [param:Integer widthSegments], [param:Integer heightSegments])

  • width — ширина по оси X. По умолчанию `1`.
  • height — высота по оси Y. По умолчанию `1`.
  • widthSegments — (необ.) по умолчанию `1`.
  • heightSegments — (необ.) по умолчанию `1`.

Процедурная геометрия может использоваться для обучения основам программирования, однако в реальной жизни используется редко. В большинстве случаев имеет смысл сделать плоскость в пакете моделирования и загрузить в «Вердж3Д» с помощью glTF.

Свойства

Смотрите свойства базового класса [page:BufferGeometry].

[property:Object parameters]

Объект с параметрами, указанными в конструкторе. Модификация свойств этого объекта после вызова конструктора не изменяет получившуюся геометрию.
