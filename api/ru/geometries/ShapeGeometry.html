[name]

Создает одностороннюю полигональную геометрию из одной или нескольких контурных фигур.

Пример

const x = 0, y = 0; const heartShape = new v3d.Shape(); heartShape.moveTo(x + 5, y + 5); heartShape.bezierCurveTo(x + 5, y + 5, x + 4, y, x, y); heartShape.bezierCurveTo(x - 6, y, x - 6, y + 7,x - 6, y + 7); heartShape.bezierCurveTo(x - 6, y + 11, x - 3, y + 15.4, x + 5, y + 19); heartShape.bezierCurveTo(x + 12, y + 15.4, x + 16, y + 11, x + 16, y + 7); heartShape.bezierCurveTo(x + 16, y + 7, x + 16, y, x + 10, y); heartShape.bezierCurveTo(x + 7, y, x + 5, y + 5, x + 5, y + 5); const geometry = new v3d.ShapeGeometry(heartShape); const material = new v3d.MeshBasicMaterial({ color: 0x0000ff }); const mesh = new v3d.Mesh(geometry, material) ; app.scene.add(mesh);

Конструктор

[name]([param:Array shapes], [param:Integer curveSegments])

  • [page:Array shapes] — массив фигур или одной [page:Shape фигуры]. По умолчанию используется треугольник.
  • [page:Integer curveSegments] — количество сегментов в одной фигуре. По умолчанию `12`.

Процедурная геометрия может использоваться для обучения основам программирования, однако в реальной жизни используется редко. В большинстве случаев имеет смысл сделать фигурную геометрию в пакете моделирования и загрузить в «Вердж3Д» с помощью glTF.

Свойства

Смотрите свойства базового класса [page:BufferGeometry].

[property:Object parameters]

Объект с параметрами, указанными в конструкторе. Модификация свойств этого объекта после вызова конструктора не изменяет получившуюся геометрию.
