[name]

[name] — это многократно используемый набор дорожек ключевых кадров, которые представляют анимацию.

Обзор элементов анимационной системы «Вердж3Д» находится в разделе Анимационная система настоящего руководства.

Конструктор

[name]([param:String name], [param:Float duration], [param:Array tracks], [param:Constant blendMode])

  • [page:String name] — название для данного клипа.
  • [page:Float duration] — продолжительность данного клипа (в секундах). Если передано отрицательное значение, длительность будет вычислена из переданного массива `tracks`.
  • [page:Array tracks] — массив [page:KeyframeTrack KeyframeTracks].
  • [page:Constant blendMode] — (необ.) определят как анимация смешивается/объединяется, когда две или более анимации проигрываются одновременно. По умолчанию `v3d.NormalAnimationBlendMode`.

Свойства

[property:Constant blendMode]

Определят как анимация смешивается/объединяется, когда две или более анимации проигрываются одновременно. Допустимые значения: `NormalAnimationBlendMode` (по умолчанию) и `AdditiveAnimationBlendMode`.

[property:Float duration]

Продолжительность данного клипа (в секундах). Она может быть вычислена из массива [page:.tracks tracks tracks] через [page:.resetDuration resetDuration].

[property:String name]

Наименование для данного клипа. Определенный клип можно искать через [page:.findByName findByName].

[property:Array tracks]

Массив, содержащий [page:KeyframeTrack] для каждого свойства, которое анимируется данным клипом.

[property:String uuid]

[link:https://ru.wikipedia.org/wiki/UUID UUID] данного экземпляра клипа. Он присваивается автоматически и не подлежит редактированию.

Методы

[method:AnimationClip clone]()

Возвращает копию данного клипа.

[method:this optimize]()

Оптимизирует каждую дорожку, удаляя эквивалентные последовательные ключи (которые часто встречаются в целевых последовательностях морфа).

[method:this resetDuration]()

Устанавливает [page:.duration duration duration] клипа на длительность его самого длинного [page:KeyframeTrack].

[method:this trim]()

Обрезает все дорожки до длительности клипа.

[method:Boolean validate]()

Выполняет минимальную проверку каждой дорожки в клипе. Возвращает `true`, если все дорожки действительны.

Статические методы

[method:Array CreateClipsFromMorphTargetSequences]([param:String name], [param:Array morphTargetSequence], [param:Float fps], [param:Boolean noLoop])

Возвращает массив новых AnimationClips, созданных из последовательности [page:BufferGeometry.morphTargets морф таргетов] геометрии, пытаясь отсортировать их имена на основе анимационных групп, таких как "Walk_001, Walk_002, Run_001, Run_002 ...".

[method:AnimationClip CreateFromMorphTargetSequence]([param:String name], [param:Array morphTargetSequence], [param:Float fps], [param:Boolean noLoop])

Возвращает новый AnimationClip из переданного массива [page:BufferGeometry.morphTargets морф таргетов] геометрии, принимая имя и количество кадров в секунду.

Примечание: Параметр fps является обязательным, но скорость анимации можно переопределить в `AnimationAction` через [page:AnimationAction.setDuration animationAction.setDuration].

[method:AnimationClip findByName]([param:Object objectOrClipArray], [param:String name])

Ищет AnimationClip по имени, принимая в качестве первого параметра либо массив AnimationClips, либо сетку или геометрию, содержащую массив с именем "animations".
