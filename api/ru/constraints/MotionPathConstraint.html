[page:Constraint] →

[name]

Ограничитель, который ограничивает положение объекта в пространстве своего родителя.

Чтобы повлиять на какой-либо объект, экземпляр [name] должен быть добавлен к массиву [page:Object3D.constraints].

Конструктор

[name]()

Конструктор не принимает на вход никаких аргументов.

Свойства

Общие свойства смотрите в базовом классе [page:Constraint].

[property:Boolean bank]

Позволяет совершать крен. Крен означает, что объект наклоняется к центру кривизны кривой, по которой он движется, подобно мотоциклу, входящему в поворот, то есть это своего рода крен влево-вправо. По умолчанию `false`.

[property:Float bankScale]

Масштабирует угол крена. По умолчанию `1`.

[property:Float bankLimit]

Максимально допустимый угол крена в радианах. По умолчанию `Infinity`.

[property:Array chordLengths]

[page:Array Массив] сумм длин хорд. Длины хорд хранятся в виде:

[lengthOfChord1, lengthOfChord1 + lengthOfChord2, ...]

Последний элемент соответствует полной длине кривой. Замечание: не используется когда [page:.useChordLength useChordLength] установлен в `false`. По умолчанию `[]`.

[property:Integer chordsNum]

Общее количество хорд на кривой, используемое при включённом флаге [page:MotionPathConstraint.useChordLength useChordLength]. Чем больше это число, тем равномернее будет движение объекта. Если `chordsNum <= 0`, данное число будет рассчитано автоматически. Замечание: всегда вызывайте метод [page:.init init] для применения изменений. По умолчанию `0`.

[property:Array cvs]

Упакованный [page:Array массив] контрольных точек NURBS-кривой. «Упакованный» означает, что контрольные точки хранятся следующим образом:

[point_1.x, point_1.y, point_1.z, point_2.x, point_2.y, point_2.z, ...]

Замечание: всегда вызывайте метод [page:.init init] для применения изменений. По умолчанию `[]`.

[property:Integer degree]

Степень NURBS-кривизны, т.е. степень кривизны пути. Замечание: всегда вызывайте метод [page:.init init] для применения изменений. По умолчанию `3`.

[property:Boolean fixCameraLightRotation]

В «Вердж3Д» используется правосторонняя систему координат с осью Y, направленной вверх, но в «Блендере» и «3дс Максе» используется правосторонняя система координат с осью Z, направленной вверх (см. «Вердж3Д Вики»). Поэтому, чтобы исправить вращение для камер и света, необходимо устанавливать флаг `fixCameraLightRotation = true`. По умолчанию `false`.

[property:Float fixedValue]

Объект останется заблокированным в одной точке вдоль кривой независимо от анимации. По умолчанию `0.0`.

[property:Boolean follow]

Если включено, вычисляет ориентацию объекта (вращение) по мере его движения вдоль кривой. По умолчанию `true`.

[property:String frontAxis]

Ось ограничиваемого объекта, соответствующая фронтальному вектору, т.е. ось соответствующая тангенте к кривой. Одна из: `'X'`, `'-X'`, `'Y'`, `'-Y'`, `'Z'`, `'-Z'`. По умолчанию `'Z'`.

[property:Float influence]

Процент влияния, которое ограничитель оказывает на ограничиваемый объект. По умолчанию `1.0` (100%).

[property:Boolean isMotionPathConstraint]

Указывает, что данный объект является экземпляром класса [name]. Только для чтения.

[property:Array knots]

[page:Array Массив] узловых точек NURBS-кривой. Замечание: длина массива всегда равна `количеству контрольных точек + степень + 1`. Замечание: всегда вызывайте метод [page:.init init] для применения изменений. По умолчанию `[]`.

[property:Integer objOffsetMode]

Как будет добавляться смещение к перемещению ограничиваемого объекта:
`0` — трансформации перемещения и поворота будут применяться независимо (поведение «3дс Макса»).
`1` — трансформация будет применяться как умножение матрицы (поведение «Блендера»).
По умолчанию `0`.

[property:Integer objOffsetRotMode]

Как будет добавляться смещение поворота к повороту ограничиваемого объекта:
`0` — будет применяться только поворот ограничителя (поведение «3дс Макса» и «Майи»).
`1` — сначала применяется поворот ограничителя, а затем смещение поворота (поведение «Блендера»).
По умолчанию `0`.

[property:Float offsetValue]

Дополнительное смещение к [page:.value value]. Замечание: не работает если [page:.useFixedLocation useFixedLocation] равно `true`. По умолчанию `0.0`.

[property:Array pointsTilt]

[page:Array Массив] углов наклона (углы крена, углы поворота) в радианах в каждой контрольной точке кривой. Является альтернативой [page:.bank bank]. Значения сохраняются в форме:

[tiltAngleForFirstPoint, tiltAngleForSecondPoint, ...]

Замечание: не работает если [page:.usePointsTilt usePointsTilt] равен `false`. Замечание: всегда вызывайте метод [page:.init init] для применения изменений. По умолчанию `[]`.

[property:String type]

Тип ограничителя. Равен `"MotionPathConstraint"`.

[property:String upAxis]

Ось ограничиваемого объекта, которая максимально выровнена с осью [page:.worldUpVector worldUpVector]. Может быть одной из `"X"`, `"-X"`, `"Y"`, `"-Y"`, `"Z"`, `"-Z"`. По умолчанию - `"Y"`.

[property:Boolean useChordLength]

Установите в `true`, чтобы двигать объект равномерно вдоль кривой. По умолчанию `false`.

[property:Boolean useClampValue]

Если равен `true`, параметр [page:.value value] будет ограничен интервалом `[0.0, 1.0]`. Замечание: не работает, если [page:.useCyclic useCyclic] равен `true`. По умолчанию `false`.

[property:Boolean useCyclic]

Установите в `true`, чтобы сделать параметр [page:.value value] цикличным, например если [page:.value value] = 1.6 то он станет `0.6`, если [page:.value value] = -1.6 то он станет `0.4`. По умолчанию `false`.

[property:Boolean useFixedLocation]

Установите в `true`, чтобы объект всегда фиксировался одной точкой на кривой, независимо от анимации, определённой в [page:.fixedValue fixedValue]. По умолчанию `false`.

[property:Boolean useObjOffset]

Включить или выключить смещение объекта. По умолчанию `false`.

[property:Boolean usePointsTilt]

Аналогичен [page:.bank bank], но используется в случае, если определён массив [page:.pointsTilt pointsTilt]. Замечание: не работает если [page:.bank bank] равен `true`. По умолчанию `false`.

[property:Boolean usePosOffset]

Включает/выключает смещение позиции объекта. Замечание: работает только если [page:.useObjOffset useObjOffset] равен `true`. По умолчанию `true`.

[property:Boolean useRelative]

Если равно `true`, объект следует пути со смещением расстояния, основанным на его исходном положении в мировой системе координат, сохранённом при первом вызове функции [page:.update update]. Замечание: работает только если [page:.useObjOffset useObjOffset] равен `true`. По умолчанию `false`.

[property:Float value]

Текущее значение ограничителя. Должно быть в интервале `[0.0, 1.0]` если параметр [page:.useCyclic useCyclic] равен `false`. По умолчанию `0.0`.

[property:Array weights]

[page:Array Массив] весов для каждой контрольной точки. Замечание: всегда вызывайте метод [page:.init init] для применения изменений. По умолчанию `[]`.

[property:Vector3 worldUpVector]

[page:Vector3 Вектор] в мировой системе координат, относительно которого выравнивается вектор [page:.upAxis upAxis]. По умолчанию `(0, 1, 0)`.
