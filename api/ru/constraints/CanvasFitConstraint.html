[name]

Ограничитель, который фиксирует дочерние объекты камеры (такие как кнопки, панели и надписи), независимо от разрешения экрана и используемого устройства.

Чтобы повлиять на какой-либо объект, экземпляр [name] должен быть добавлен к массиву [page:Object3D.constraints].

Конструктор

[name]([page:Object3D target])

[page:Object3D target] — целевой объект ограничителя.

Свойства

Общие свойства смотрите в базовом классе [page:TargetConstraint].

[property:String edgeH]

Горизонтальная граница экрана для фиксации. По умолчанию `'NONE'`.

  • `'LEFT'` — левый край.
  • `'RIGHT'` — правый край.
  • `'STRETCH'` — растянуть от левого до правого края.
  • `'NONE'` — не фиксировать.

[property:String edgeV]

Вертикальная граница экрана для фиксации. По умолчанию `'NONE'`.

  • `'TOP'` — верхний край.
  • `'BOTTOM'` — нижний край.
  • `'STRETCH'` — растянуть от верха до низа.
  • `'NONE'` — не фиксировать.

[property:Float offset]

Дополнительное смещение для фиксации (может быть отрицательным). По умолчанию `0.0`.

[property:Boolean isCanvasFitConstraint]

Указывает, что данный объект является экземпляром класса [name]. Только для чтения.

[property:String type]

Тип ограничителя. Равен `"CanvasFitConstraint"`.

[property:String fitShape]

Ограничивающий объём фиксируемого объекта. По умолчанию `'BOX'`.

  • `'SPHERE'` — ограничивающая сфера.
  • `'BOX'` — ограничивающий бокс.
  • `'POINT'` — объём нулевого размера (точка).
