[name]

Ограничитель, который заставляет ограничиваемый объект наследовать положение цели.

Чтобы повлиять на какой-либо объект, экземпляр [name] должен быть добавлен к массиву [page:Object3D.constraints].

Конструктор

[name]([page:Object3D target])

[page:Object3D target] — целевой объект ограничителя.

Свойства

Общие свойства смотрите в базовом классе [page:TargetConstraint].

[property:Float influence]

Процент влияния, которое ограничитель оказывает на ограничиваемый объект. По умолчанию `1.0` (100%).

[property:Boolean invertX]

Инвертирует ось X. По умолчанию `false`.

[property:Boolean invertY]

Инвертирует ось Y. По умолчанию `false`.

[property:Boolean invertZ]

Инвертирует ось Z. По умолчанию `false`.

[property:Boolean isCopyLocationConstraint]

Указывает, что данный объект является экземпляром класса [name]. Только для чтения.

[property:String type]

Тип ограничителя. Равен `"CopyLocationConstraint"`.

[property:Boolean useOffset]

Если `true`, перемещает ограничиваемый объект относительно перемещения целевого объекта. По умолчанию `false`.

[property:Boolean useX]

Действует ли ограничитель вдоль оси X. По умолчанию `true`.

[property:Boolean useY]

Действует ли ограничитель вдоль оси Y. По умолчанию `true`.

[property:Boolean useZ]

Действует ли ограничитель вдоль оси Z. По умолчанию `true`.

Методы

Общие методы смотрите в базовом классе [page:TargetConstraint].

Пазлы

Используйте пазл copy transform, чтобы применять [name] без необходимости писать код.
