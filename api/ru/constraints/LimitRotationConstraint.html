[page:Constraint] →

[name]

Ограничитель, который ограничивает вращение объекта в пространстве его родителя.

Чтобы повлиять на какой-либо объект, экземпляр [name] должен быть добавлен к массиву [page:Object3D.constraints].

Конструктор

[name]()

Конструктор не принимает аргументов.

Свойства

Общие свойства смотрите в базовом классе [page:Constraint].

[property:String axis]

Ось, вокруг которой следует ограничить вращение. Может быть одной из `"X"`, `"Y"`, `"Z"`. По умолчанию — `"Y"`.

[property:Boolean isLimitRotationConstraint]

Указывает, что данный объект является экземпляром класса [name]. Только для чтения.

[property:Float max]

Максимально допустимый угол Эйлера вокруг соответствующей оси для ограничения вращения объекта. По умолчанию `2π`.

[property:Float min]

Минимально допустимый угол Эйлера вокруг соответствующей оси для ограничения вращения объекта. По умолчанию равен `0`.

[property:String type]

Тип ограничителя. Равен `"LimitRotationConstraint"`.

Методы

Общие методы смотрите в базовом классе [page:Constraint].

Пазлы

Используйте пазл limit transform, чтобы применять [name] без необходимости писать код.
