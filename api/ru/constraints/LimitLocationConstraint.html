[page:Constraint] →

[name]

Ограничитель, который ограничивает положение объекта в пространстве своего родителя.

Чтобы повлиять на какой-либо объект, экземпляр [name] должен быть добавлен к массиву [page:Object3D.constraints].

Конструктор

[name]()

Конструктор не принимает на вход никаких аргументов.

Свойства

Общие свойства смотрите в базовом классе [page:Constraint].

[property:Boolean isLimitLocationConstraint]

Используется для проверки того, являются ли данный или производные классы ограничителями местоположения. По умолчанию `true`.

[property:Vector3 max]

[page:Vector3], содержащий максимальные значения положения объекта по соответствующим осям. По умолчанию — `(Infinity, Infinity, Infinity)`.

[property:Vector3 min]

[page:Vector3], содержащий минимальные значения положения объекта по соответствующим осям. По умолчанию — `(-Infinity, -Infinity, -Infinity)`.

[property:String type]

Тип ограничителя. Равен `"LimitLocationConstraint"`.

Методы

Общие методы смотрите в базовом классе [page:Constraint].

Пазлы

Используйте пазл limit transform, чтобы применять [name] без необходимости писать код.
