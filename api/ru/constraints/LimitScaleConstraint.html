[page:Constraint] →

[name]

Ограничитель, который ограничивает масштабирование объекта в пространстве его родителя.

Чтобы повлиять на какой-либо объект, экземпляр [name] должен быть добавлен к массиву [page:Object3D.constraints].

Конструктор

[name]()

Конструктор не принимает на вход никаких аргументов.

Свойства

Общие свойства смотрите в базовом классе [page:Constraint].

[property:Boolean isLimitScaleConstraint]

Указывает, что данный объект является экземпляром класса [name]. Только для чтения.

[property:Vector3 max]

[page:Vector3 Вектор], содержащий максимальные значения масштаба по соответствующим осям для ограничения масштабирования объекта. По умолчанию `(Infinity, Infinity, Infinity`.

[property:Vector3 min]

[page:Vector3 Вектор], содержащий минимальные значения масштаба по соответствующим осям для ограничения масштабирования объекта. По умолчанию `(-Infinity, -Infinity, -Infinity)`.

[property:String type]

Тип ограничителя. Равен `"LimitScaleConstraint"`.

Методы

Общие методы смотрите в базовом классе [page:Constraint].

Пазлы

Используйте пазл limit transform, чтобы применять [name] без необходимости писать код.
