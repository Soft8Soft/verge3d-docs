[name]

Абстрактный базовый класс для ограничителей.

Конструктор

[name]()

Создает ограничитель общего вида (вызывать не имеет смысла).

Свойства

[property:Boolean isConstraint]

Указывает, что данный объект является экземпляром класса [name], либо унаследованных от него классов. Только для чтения.

[property:Boolean mute]

Отключает ограничитель, чтобы он не оказывал влияние на ограничиваемый объект. По умолчанию `false`.

[property:String name]

Имя ограничителя. По умолчанию пустая строка.

[property:String type]

Тип ограничителя. Равен `"Constraint"`.

Методы

[method:Constraint clone]()

Возвращает новый ограничитель с теми же параметрами, что и текущий.

[method:Constraint copy]([page:Constraint source])

Копирует параметры из указанного ограничителя `source` в текущий ограничитель.

[method:undefined update]([page:Object3D obj])

Обновляет трансформации указанного объекта, применяя к нему ограничитель.
