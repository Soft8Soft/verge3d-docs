[name]

Ограничитель, который заставляет объект вести себя как дочерний к целевому объекту, не будучи фактически дочерним по отношению к нему.

Чтобы повлиять на какой-либо объект, экземпляр [name] должен быть добавлен к массиву [page:Object3D.constraints].

Конструктор

[name]([page:Object3D target])

[page:Object3D target] — целевой объект ограничителя.

Свойства

Общие свойства смотрите в базовом классе [page:TargetConstraint].

[property:Boolean isChildOfConstraint]

Указывает, что данный объект является экземпляром класса [name]. Только для чтения.

[property:Matrix4 offsetMatrix]

Матрица смещения для ограничиваемого объекта. Применяется в родительском пространстве. По умолчанию — единичная матрица.

[property:String type]

Тип ограничителя. Равен `"ChildOfConstraint"`.
