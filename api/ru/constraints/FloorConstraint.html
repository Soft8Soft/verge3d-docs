[name]

Ограничение, которое ограничивает положение ограничиваемого объекта на основе положения цели. Таким образом, целевой объект ведет себя как "inivisible wall", "floor" и т.д.

Чтобы повлиять на какой-либо объект, экземпляр [name] должен быть добавлен к массиву [page:Object3D.constraints].

Конструктор

[name]([page:Object3D target])

[page:Object3D target] — целевой объект ограничителя.

Свойства

Общие свойства смотрите в базовом классе [page:TargetConstraint].

[property:String floorLocation]

Ось, вдоль которой будет применяться ограничитель. Может быть одной из `"X"`, `"-X"`, `"Y"`, `"-Y"`, `"Z"`, `"-Z"`. Положительное значение означает, что положение ограниченного объекта вдоль этой оси может быть только выше значения [page:.offset]. Отрицательное — только ниже значения [page:.offset]. По умолчанию - `"Y"`.

[property:Boolean isFloorConstraint]

Указывает, что данный объект является экземпляром класса [name]. Только для чтения.

[property:Float offset]

Предельное значение по оси [page:.floorLocation]. По умолчанию равно `0`.

[property:String type]

Тип ограничения. Равен `"FloorConstraint"`.

[property:Boolean useRotation]

Если равно `true`, ограничитель учитывает поворот целевого объекта. Это позволяет иметь плоскости «пола» иметь какой угодно поворот. По умолчанию `false`.
