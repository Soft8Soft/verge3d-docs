[name]

Абстрактный базовый класс для ограничителей, которые зависят от целевого объекта.

Конструктор

[name]([page:Object3D target])

[page:Object3D target] — целевой объект ограничителя.

Создает целевой ограничитель общего вида (вызывать не имеет смысла).

Свойства

Общие свойства смотрите в базовом классе [page:Constraint].

[property:Boolean isTargetConstraint]

Указывает, что данный объект является экземпляром класса [name], либо унаследованных от него классов. Только для чтения.

[property:Object3D target]

Целевой объект, от которой зависит данный ограничитель. Должно быть [page:Object3D].

[property:String type]

Тип ограничителя. Равен `"TargetConstraint"`.
