[name]

Ограничитель, который заставляет объект наследовать вращение цели.

Чтобы повлиять на какой-либо объект, экземпляр [name] должен быть добавлен к массиву [page:Object3D.constraints].

Конструктор

[name]([page:Object3D target])

[page:Object3D target] — целевой объект ограничителя.

Свойства

Общие свойства смотрите в базовом классе [page:TargetConstraint].

[property:Boolean fixCameraLightRotation]

В «Вердж3Д» используется правосторонняя систему координат с осью Y, направленной вверх, но в «Блендере» и «3дс Максе» используется правосторонняя система координат с осью Z, направленной вверх (см. «Вердж3Д Вики»). Поэтому, чтобы исправить вращение для камер и света, необходимо устанавливать флаг `fixCameraLightRotation = true`. По умолчанию `false`.

[property:Float influence]

Процент влияния, которое ограничитель оказывает на ограничиваемый объект. По умолчанию `1.0` (100%).

[property:Boolean isCopyRotationConstraint]

Указывает, что данный объект является экземпляром класса [name]. Только для чтения.

[property:String mixMode]

Указывает, каким образом новый поворот сочетается со старым. По умолчанию `"REPLACE"`.

`"AFTER"`
Новый поворот добавляется к уже существующему.
`"BEFORE"`
Новый поворот добавляется перед уже существующим.
`"REPLACE"`
Новый поворот полностью заменяет существующий.

[property:String type]

Тип ограничителя. Равен `"CopyRotationConstraint"`.

Методы

Общие методы смотрите в базовом классе [page:TargetConstraint].

Пазлы

Используйте пазл copy transform, чтобы применять [name] без необходимости писать код.
