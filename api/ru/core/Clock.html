[name]

Объект для отслеживания времени. Он использует [link:https://developer.mozilla.org/ru/docs/Web/API/Performance/now performance.now], если он доступен, в противном случае он возвращается к менее точному [link:https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Global_Objects/Date/now Date.now].

Конструктор

[name]([param:Boolean autoStart])

autoStart — (необ.) нужно ли автоматически запускать часы. По умолчанию `true`.

Свойства

[property:Boolean autoStart]

Если установлено, часы запускаются автоматически при первом вызове [page:.getDelta](). По умолчанию `true`.

[property:Float startTime]

Содержит время, когда метод [page:.start] часов был вызван в последний раз. По умолчанию `0`.

[property:Float oldTime]

Содержит время, в которое последний раз вызывались методы [page:.start], [page:.getElapsedTime] или [page:.getDelta]. По умолчанию `0`.

[property:Float elapsedTime]

Отслеживает общее время работы часов. По умолчанию `0`.

[property:Boolean running]

Указывает, идут часы или нет. По умолчанию `false`.

Методы

[method:undefined start]()

Запускает часы. Также устанавливает [page:.startTime] и [page:.oldTime] в текущее время, а также устанавливает [page:.elapsedTime] равным `0` и [page:.running] равным `true`.

[method:undefined stop]()

Останавливает часы и устанавливает [page:.oldTime] в текущее время.

[method:Float getElapsedTime]()

Получает секунды, прошедшие с момента запуска часов, и устанавливает [page:.oldTime] в текущее время. Если [page:.autoStart] имеет значение `true` и часы не запущены, также запускает часы.

[method:Float getDelta]()

Получает секунды, прошедшие с момента установки [page:.oldTime] и устанавливает [page:.oldTime] в текущее время. Если [page:.autoStart] имеет значение `true` и часы не запущены, также запускает часы.

Пазлы

«Вердж3Д» поддерживает ряд пазлов времени для управления часами без программирования.
