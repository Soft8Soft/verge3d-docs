[name]

Этот класс предназначен для осуществления [link:https://ru.wikipedia.org/wiki/Рейкастинг рейкастинга]. Рейкастинг используется для пикинга объектов (определение объектов в 3Д-пространстве, над которыми находится курсор мыши), а также для других целей.

Пример

const raycaster = new v3d.Raycaster(); let pointer = null; function onPointerMove(event) { pointer = pointer || new v3d.Vector2(-1, -1); // рассчитываем позицию курсора в нормализованных координатах устройства // (-1 to +1) для обоих компонентов pointer.x = (event.offsetX / app.getWidth()) * 2 - 1; pointer.y = -(event.offsetY / app.getHeight()) * 2 + 1; } function pick() { // не используем позицию без инициализации if (!pointer) return; // обновляем луч на основе камеры и позиции курсора raycaster.setFromCamera(pointer, app.camera); // определяем объекты, пересекающие луч const intersects = raycaster.intersectObjects(app.scene.children); for (let i = 0; i < intersects.length; i++) { intersects[i].object.visible = false; } } app.container.addEventListener('pointermove', onPointerMove); app.renderCallbacks.push(pick);

Конструктор

[name]([param:Vector3 origin], [param:Vector3 direction], [param:Float near], [param:Float far]) {

  • [page:Vector3 origin] — вектор начала координат, из которого отбрасывается луч.
  • [page:Vector3 direction] — вектор направления, задающий направление луча. Должен быть нормализован.
  • [page:Float near] — возвращаемые результаты будут находиться дальше, чем near. Near не может быть отрицательным. Значение по умолчанию `0`.
  • [page:Float far] — возвращаемые результаты будут находиться ближе, чем far. Far не может быть меньше, чем near. Значение по умолчанию `Infinity` (бесконечность).

Создает новый [name]-объект.

Свойства

[property:Float far]

Максимальная дальность луча. Это значение указывает расстояние, на котором объекты могут быть отброшены. Это значение не должно быть отрицательным и должно быть больше, чем свойство near.

[property:Float near]

Минимальная дальность луча. Это значение указывает расстояние, на котором объекты могут быть отброшены. Это значение не должно быть отрицательным и должно быть меньше, чем свойство far.

[property:Camera camera]

Камера, которую следует использовать при создании лучей для объектов, зависящих от вида, таких как объекты с билбордами, например [page:Sprites]. Это поле может быть задано вручную или устанавливается при вызове [page:.setFromCamera](). По умолчанию имеет значение `null`.

[property:Layers layers]

Используется [name] для выборочного игнорирования 3Д-объектов при выполнении тестов пересечения. Следующий код гарантирует, что экземпляр [name] будет учитывать только 3Д-объекты на слое `1`.

raycaster.layers.set(1); object.layers.enable(1);

[property:Object params]

Объект со следующими свойствами:

{ Mesh: { omitGeometry: false }, Line: { threshold: 1 }, LOD: {}, Points: { threshold: 1 }, Sprite: {}, checkVisibility: true }

Где `threshold` — это точность рейкастинга при пересечении объектов в мировых единицах. Указание `omitGeometry=true` позволяет направлять лучи только на ограничители мешей (а не на саму геометрию), что обеспечивает высокую производительность. Параметр `checkVisiblity` позволяет включать/отключать наведение лучей на невидимые объекты.

[property:Ray ray]

[page:Ray Луч] используемый для рейкастинга.

Методы

[method:undefined set]([param:Vector3 origin], [param:Vector3 direction])

  • [page:Vector3 origin] — вектор начала, из которого отбрасывается луч.
  • [page:Vector3 direction] — нормализованный вектор направления, задающий направление луча.

Обновляет луч с новым началом и направлением. Обратите внимание, что этот метод только копирует значения из аргументов.

[method:undefined setFromCamera]([param:Vector2 coords], [param:Camera camera])

  • [page:Vector2 coords] — 2Д-координаты мыши в нормализованных координатах устройства (NDC) — компоненты X и Y должны быть в пределах от -1 до 1.
  • [page:Camera camera] — камера, из которой должен исходить луч.

Обновляет луч с новым началом и направлением.

[method:Array intersectObject]([param:Object3D object], [param:Boolean recursive], [param:Array optionalTarget])

  • [page:Object3D object] — объект, который нужно проверить на пересечение с лучом.
  • [page:Boolean recursive] — если `true`, то проверяются также все потомки. В противном случае проверяется только пересечение с объектом. По умолчанию `true`.
  • [page:Array optionalTarget] — (необ.) цель для установки результата. В противном случае создается новый [page:Array]. Если задан, то перед каждым вызовом необходимо очищать этот массив (т.е. `array.length = 0;`).

Проверяет все пересечения между лучом и объектом с потомками или без них. Пересечения возвращаются отсортированными по расстоянию, сначала ближайшие. Возвращается массив пересечений...

[{ distance, point, face, faceIndex, object }, ...]
  • [page:Float distance] – расстояние между началом луча и точкой пересечения.
  • [page:Vector3 point] – точка пересечения, в мировых координатах.
  • [page:Face3 face] – пересекаемая поверхность.
  • [page:Integer faceIndex] – индекс пересекаемой грани.
  • [page:Object3D object] – пересекаемый объект.
  • [page:Vector2 uv] — U,V координаты в точке пересечения.
  • [page:Vector2 uv2] — второй набор координат U,V в точке пересечения.

[name] делегирует метод [page:Object3D.raycast raycast] переданного объекта, когда оценивает, пересекает ли луч объект или нет. Это позволяет [page:Mesh meshes] реагировать на отбрасывание лучей иначе, чем [page:Line lines] и [page:Points pointclouds].

Обратите внимание, что для мешей грани должны быть направлены к ориджину [page:.ray ray], чтобы быть обнаруженными; пересечения луча, проходящего через заднюю часть грани, не будут обнаружены. Чтобы направить луч на обе грани объекта, нужно установить свойство [page:Mesh.material material] [page:Material.side side] в `v3d.DoubleSide`.

[method:Array intersectObjects]([param:Array objects], [param:Boolean recursive], [param:Array optionalTarget])

  • [page:Array objects] — объекты для проверки пересечения с лучом.
  • [page:Boolean recursive] — Если `true`, то также проверяются все потомки объектов. В противном случае проверяется только пересечение с объектами. По умолчанию `true`.
  • [page:Array optionalTarget] — (необ.) цель для установки результата. В противном случае создается новый [page:Array]. Если задан, то перед каждым вызовом необходимо очищать этот массив (т.е. `array.length = 0;`).

Проверяет все пересечения между лучом и объектами с потомками или без них. Пересечения возвращаются отсортированными по расстоянию, сначала возвращаются ближайшие. Пересечения имеют ту же форму, что и те, которые возвращает [page:.intersectObject].
