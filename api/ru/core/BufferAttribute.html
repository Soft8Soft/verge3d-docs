[name]

Этот класс хранит данные для атрибутов (таких как позиции вершин, индексы граней, нормали, цвета, UV и любые пользовательские атрибуты), связанных с [page:BufferGeometry], что позволяет более эффективно передавать данные на GPU. Подробности и пример использования см. на указанной странице.

При работе с векторными данными, также будет полезным использовать вспомогательные методы .fromBufferAttribute(attribute, index) классов [page:Vector2.fromBufferAttribute Vector2], [page:Vector3.fromBufferAttribute Vector3], [page:Vector4.fromBufferAttribute Vector4] и [page:Color.fromBufferAttribute Color].

Конструктор

[name]([param:TypedArray array], [param:Integer itemSize], [param:Boolean normalized])

  • [page:TypedArray array] — должен быть [page:TypedArray]. Используется для инстанцирования буфера. Этот массив должен иметь `itemSize * numVertices` элементов, где numVertices — количество вершин в ассоциированной [page:BufferGeometry BufferGeometry].
  • [page:Integer itemSize] — количество значений массива, которые должны быть связаны с конкретной вершиной. Например, если этот атрибут хранит трехкомпонентный вектор (такой как позиция, нормаль или цвет), то itemSize должен быть равен 3.
  • [page:Boolean normalized] — (необ.) применяется только к целочисленным данным. Указывает, как базовые данные в буфере отображаются на значения в коде GLSL. Например, если [page:TypedArray array] является экземпляром UInt16Array, и [page:Boolean normalized] равно `true`, значения 0 - +65535 в данных массива будут отображены на `0.0f - +1.0f` в атрибуте GLSL. Массив Int16Array (знаковый) будет отображать значения `-32767 - +32767` на `-1.0f - +1.0f`. Если [page:Boolean normalized] равно `false`, значения будут преобразованы в числа с плавающей запятой без изменений, т.е. `32767` станет `32767.0f`.

Свойства

[property:TypedArray array]

[page:TypedArray Типизированный] массив, содержащий данные, хранящиеся в буфере.

[property:Integer count]

Содержит длину массива [page:BufferAttribute.array array], разделенную на [page:BufferAttribute.itemSize itemSize].

Если в буфере хранится трехкомпонентный вектор (такой как позиция, нормаль или цвет), то подсчитывается количество таких векторов.

[property:Boolean isBufferAttribute]

Указывает, что данный объект является экземпляром [name]. Только для чтения.

[property:Integer itemSize]

Длина векторов, которые хранятся в массиве [page:BufferAttribute.array array].

[property:String name]

Необязательное имя для данного экземпляра атрибута. По умолчанию пустая строка.

[property:Boolean needsUpdate]

Флаг, указывающий на то, что данный атрибут изменился и должен быть повторно отправлен на GPU. Установите это значение в `true` при изменении значения массива.

Установка этого значения в `true` также увеличивает версию [page:BufferAttribute.version].

[property:Boolean normalized]

Указывает, как данные в буфере отображаются на значения в коде шейдера GLSL. Подробности см. в конструкторе выше.

[property:Function onUploadCallback]

Функция обратного вызова, которая выполняется после того, как рендерер передал данные массива атрибутов на GPU.

[property:Object updateRange]

Объект, содержащий:

  • [page:Integer offset]: По умолчанию `0`. Позиция, с которой следует начать обновление.
  • [page:Integer count]: По умолчанию `-1`, что означает не использовать диапазоны обновления.

Это можно использовать для обновления только некоторых компонентов хранимых векторов (например, только компонента, связанного с цветом).

[property:Usage usage]

Определяет предполагаемую схему использования хранилища данных в целях оптимизации. Соответствует параметру `usage` в [link:https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext/bufferData WebGLRenderingContext.bufferData](). По умолчанию [page:Core StaticDrawUsage]. Остальные значения параметра см. в разделе [page:Core константы].

После первого использования буфера, параметр usage не может быть изменён. Вместо этого создайте новый и установите нужное значение параметра перед первым кадром отрисовки.

[property:Integer version]

Номер версии, увеличивающийся каждый раз, когда свойство [page:BufferAttribute.needsUpdate needsUpdate] установлено в `true`.

Методы

[method:this applyMatrix3]([param:Matrix3 m])

Применяет матрицу [page:Matrix3 m] к каждому элементу Vector3 данного BufferAttribute.

[method:this applyMatrix4]([param:Matrix4 m])

Применяет матрицу [page:Matrix4 m] к каждому элементу Vector3 данного BufferAttribute.

[method:this applyNormalMatrix]([param:Matrix3 m])

Применяет нормальную матрицу [page:Matrix3 m] к каждому элементу Vector3 данного BufferAttribute.

[method:this transformDirection]([param:Matrix4 m])

Применяет матрицу [page:Matrix4 m] к каждому элементу Vector3 этого BufferAttribute, интерпретируя элементы как векторы направления.

[method:BufferAttribute clone]()

Возвращает копию этого BufferAttribute.

[method:BufferAttribute copy]([param:BufferAttribute bufferAttribute])

Копирует другой BufferAttribute в текущий BufferAttribute.

[method:BufferAttribute copyArray](array)

Копирует указанный массив (который может быть обычным массивом или TypedArray) в свойство [page:BufferAttribute.array array].

Смотрите [link:https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/set TypedArray.set], содержащий требования при копировании TypedArray.

[method:this copyAt] ([param:Integer index1], [param:BufferAttribute bufferAttribute], [param:Integer index2])

Копирует вектор из bufferAttribute[index2] в [page:BufferAttribute.array array][index1].

[method:Float getX]([param:Integer index])

Возвращает x-компоненту вектора по заданному индексу.

[method:Float getY]([param:Integer index])

Возвращает y-компоненту вектора по заданному индексу.

[method:Float getZ]([param:Integer index])

Возвращает z-компоненту вектора по заданному индексу.

[method:Float getW]([param:Integer index])

Возвращает w-компоненту вектора по заданному индексу.

[method:this onUpload]([param:Function callback])

Устанавливает значение свойства onUploadCallback.

[method:this set] ([param:Array value], [param:Integer offset])

  • value — [page:Array] или [page:TypedArray], из которого копируются значения.
  • offset — (необ.) индекс массива [page:BufferAttribute.array array], с которого следует начать копирование.

Вызывает [link:https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/set TypedArray.set]([page:Array value], [page:Integer offset]) на массиве [page:BufferAttribute.array array].

В частности, смотрите на странице выше требования, предъявляемые к [page:TypedArray].

[method:this setUsage] ([param:Usage value])

Устанавливает значение [page:BufferAttribute.usage usage]. Значения параметра см. в разделе [page:Core константы].

После первого использования буфера, параметр usage не может быть изменён. Вместо этого создайте новый и установите нужное значение параметра перед первым кадром отрисовки.

[method:this setX]([param:Integer index], [param:Float x])

Устанавливает x-компонент вектора по заданному индексу.

[method:this setY]([param:Integer index], [param:Float y])

Устанавливает компонент y вектора по заданному индексу.

[method:this setZ]([param:Integer index], [param:Float z])

Устанавливает компонент z вектора по заданному индексу.

[method:this setW]([param:Integer index], [param:Float w])

Устанавливает w-компоненту вектора по заданному индексу.

[method:this setXY]([param:Integer index], [param:Float x], [param:Float y])

Устанавливает x и y компоненты вектора по заданному индексу.

[method:this setXYZ]([param:Integer index], [param:Float x], [param:Float y], [param:Float z])

Устанавливает x, y и z компоненты вектора по заданному индексу.

[method:this setXYZW]([param:Integer index], [param:Float x], [param:Float y], [param:Float z], [param:Float w])

Устанавливает x, y, z и w компоненты вектора по заданному индексу.
