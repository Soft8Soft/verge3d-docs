[name]

FPS-контролы позволяют камере двигаться по сцене подобно персонажу в режиме от первого лица.

Конструктор

[name]([page:Camera object], [page:HTMLDOMElement domElement])

[page:Camera object]
Камера, которой необходимо управлять (обязательный).
[page:HTMLDOMElement domElement]
Элемент HTML, используемый для прослушивания событий (необ.). По умолчанию это весь документ, однако если вы хотите, чтобы элементы управления работали только над определенным элементом (например, холстом), вы можете указать его здесь.

Свойства

[property:Array collisionMeshes]

Массив [page:Object3D объектов] для ограничения движения камеры.

[property:HTMLElement domElement]

HTML-элемент, используемый для прослушивания событий мыши/тачскрина. Он должен быть передан в конструкторе; изменение его здесь не приведет к установке новых обработчиков событий. По умолчанию используется весь документ.

[property:Boolean enabled]

Включены ли элементы управления или нет.

[property:Boolean enableCollisions]

Нужно или нет ограничивать движение камеры. По умолчанию `true`.

[property:Boolean enableCtrlZoom]

Установите в `true`, чтобы осуществлять зум только при нажатой клавише ctrl (подобно тому как это сделано в Google Maps). По умолчанию `false`.

[property:Boolean enableDamping]

Установите значение `true`, чтобы включить демпфирование (инерцию), которое можно использовать для придания чувства веса элементам управления. По умолчанию установлено значение `true`.

Обратите внимание, что если эта функция включена, необходимо вызвать [page:.update]() в цикле анимации.

[property:Boolean enableKeys]

Включает или отключает управление с клавиатуры. По умолчанию `true`.

[property:Boolean enablePan]

Включает или отключает панорамирование камеры. По умолчанию `true`.

[property:Boolean enablePointerLock]

Включить функцию pointer lock для захвата курсора мыши при старте приложения. Пользователь должен нажать на любом месте экрана, чтобы захватить курсор и перемещаться в 3Д-пространстве без необходимости зажимать кнопки мыши. По умолчанию `false`.

[property:Boolean enableRotate]

Включает или отключает поворот камеры по горизонтали и вертикали. По умолчанию `true`.

Обратите внимание, что можно отключить одну ось, установив минимальное и максимальное значение [page:.minPolarAngle полярного] или [page:.minAzimuthAngle азимутального] углов в одно и то же значение, что приведет к фиксации вертикального или горизонтального вращения.

[property:Boolean enableZoom]

Включает или отключает зум (dollying) камеры. По умолчанию `true`.

[property:Float gazeLevel]

Устанавливает высоту уровня глаз ("уровень обзора"). По умолчанию `1.8`.

[property:Boolean inTween]

Флаг, указывающий, находится ли камера в режиме автоматического наведения (tweening).

[property:Camera object]

Управляемая камера.

[property:Float panInertia]

Инерция панорамирования, используемая если [page:.enableDamping] установлен в `true`. Обратите внимание, что для работы данной функции необходимо вызвать [page:.update]() в цикле анимации. По умолчанию `0.05`.

[property:Float panSpeedKey]

Скорость панорамирования (количество пикселей) при использовании курсорных клавиш клавиатуры. По умолчанию `0.15`.

[property:Float rotateInertia]

Инерция вращения, используемая если [page:.enableDamping] установлен в `true`. Обратите внимание, что для работы данной функции необходимо вызвать [page:.update]() в цикле анимации. По умолчанию `0.05`.

[property:Float rotateInertiaTouch]

Аналогично [page:.rotateInertia], но используется на устройствах с тачскрином. По умолчанию `0.05`.

[property:Float rotateSpeed]

Скорость вращения. По умолчанию `0.9`.

[property:Float rotateSpeedTouch]

Скорость вращения при использовании такскринов. По умолчанию `0.75`.

[property:Object screen]

Смещение и размер экрана.

[property:Float storyHeight]

Максимальный размер этажа. Укажите, если вам требуется иметь несколько этажей на сцене, например если предполагается перемещение по двухъярусному коттеджу или торговому центру. По умолчанию `3.0`.

[property:Float zoomSpeed]

Скорость зума/приближения. По умолчанию `30.0`.

[property:Float zoomSpeedKey]

Скорость зума/приближения при использовании курсорных клавиш клавиатуры. По умолчанию `0.2`.

[property:Float zoomInertia]

Инерция зума, используемая если [page:.enableDamping] установлен в `true`. Обратите внимание, что для работы данной функции необходимо вызвать [page:.update]() в цикле анимации. По умолчанию `0.05`.

Методы

[method:undefined dispose] ()

Удаляет все обработчики событий.

[method:undefined handleResize]()

Обновляет объект [page:.screen] на основе позиции и размеров элемента [page:.domElement].

[method:undefined tween] ([param:Vector3 toPosition], [param:Vector3 toTarget], [param:Float time], [param:Function finishCb], [param:Constant movementType])

toPosition
Новое положение камеры.
toTarget
Новая целевая точка.
time
Длина анимации перемещения.
finishCb
Функция обратного вызова, которая будет вызвана после завершения анимации перемещения.
movementType
Интерполяция движения. Может быть [page:Controls v3d.TweenLinear] (по умолчанию) или [page:Controls v3d.TweenSpherical].

Запускает автоматическое изменение текущего положения камеры и целевой точки на указанное новое положение и цель в течение указанного времени.

[method:undefined tweenZoomTo]([param:Vector3 toTarget], [param:Float toZoom], [param:Float time], [param:Function finishCb])

toTarget
Новое положение камеры.
toZoom
Новое значение зума.
time
Длина анимации перемещения.
finishCb
Функция обратного вызова, которая будет вызвана после завершения анимации перемещения.

Плавно изменяет целевую точку и зум [page:OrthographicCamera ортографической] камеры в течение указанного времени.

[method:Boolean update] ()

Обновить элементы управления. Должно вызываться после любого ручного изменения трансформации камеры, или в цикле обновления, если установлены [page:.autoRotate] или [page:.enableDamping].
