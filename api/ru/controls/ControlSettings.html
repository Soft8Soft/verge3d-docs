[name]

Класс для хранения и применения настроек управления камерой («контролов»).

Пример

const aspect = app.container.offsetWidth / app.container.offsetHeight; const camera = new v3d.PerspectiveCamera(45, aspect, 1, 1000); camera.position.z = -5; camera.controlSettings = new v3d.ControlSettings('ORBIT'); app.scene.add(camera); // устанавливает активную камеру и назначает контролы в приложении app.setCamera(camera);

Конструктор

[name]([param:String type], [param:Boolean enablePan], [param:Float rotateSpeed], [param:Float moveSpeed])

  • [page:String type] — тип контролов: `'ORBIT'`, `'FIRST_PERSON'` или `'FLYING'`. Необязательный, по умолчанию `'ORBIT'`.
  • [page:Boolean enablePan] — create camera controls with panning enabled. Необязательный, по умолчанию `'true'`.
  • [page:Float rotateSpeed] — camera rotation speed. Необязательный, по умолчанию `1`.
  • [page:Float moveSpeed] — camera movement speed. Необязательный, по умолчанию `1`.

Создаёт новый объект с настройками управления камерой.

Свойства

[property:Boolean enableKeys]

Включает или выключает возможность управления с клавиатуры. По умолчанию `true`.

[property:Boolean enablePan]

Включает или выключает панорамирование камеры. По умолчанию `true`.

[property:Boolean enableRotate]

Включает или выключает горизонтальный и вертикальный поворот камеры. По умолчанию `true`.

[property:Boolean enableZoom]

Включает или выключает зум (или движение вперёд-назад) камеры.

[property:Float moveSpeed]

Фактор скорости перемещения. При [page:.assignToControls назначении] настроек на объекте контролов, будет влиять одновременно на панорамирование и зум. По умолчанию `1`.

[property:Boolean orbitEnableTurnover]

Включает или выключает возможность поворота камеры через голову. По умолчанию `false`.

[property:Float orbitMaxAzimuthAngle]

Как сильно можно крутить орбитальную камеру по горизонтали (верхний лимит). Допустимый диапазон: от `-Math.PI` до `Math.PI` (или `Infinity` для отключения лимита). По умолчанию `Infinity`;

[property:Float orbitMaxDistance]

Как сильно можно отдалять орбитальную камеру (только для [page:PerspectiveCamera перспективных камер]). По умолчанию `Infinity`.

[property:Float orbitMaxPolarAngle]

Как сильно можно крутить камеру по вертикали (верхний лимит). Допустимый диапазон: от `0` до `Math.PI` радиан, по умолчанию `Math.PI`.

[property:Float orbitMaxZoom]

Максимальный зум (только для [page:OrthographicCamera ортогональных камер]). По умолчанию `Infinity`.

[property:Float orbitMinAzimuthAngle]

Как сильно можно крутить орбитальную камеру по горизонтали (нижний лимит). Допустимый диапазон: от `-Math.PI` to `Math.PI` (или `-Infinity` для отключения лимита). По умолчанию `-Infinity`;

[property:Float orbitMinDistance]

Как сильно можно приближать орбитальную камеру (только для [page:PerspectiveCamera перспективных камер]). По умолчанию `0`.

[property:Float orbitMinPolarAngle]

Как сильно можно крутить камеру по вертикали (нижний лимит). Допустимый диапазон: от `0` до `Math.PI` радиан, по умолчанию `0`.

[property:Float orbitMinZoom]

Минимальный зум (только для [page:OrthographicCamera ортогональных камер]). По умолчанию `0`.

[property:Float rotateSpeed]

Коэффициент скорости вращения. По умолчанию `1`.

[property:Boolean screenSpacePanning]

Определяет, как меняется положение камеры при панорамировании. Если `true`, камера движется в пространстве экрана. В противном случае камера движется в плоскости, ортогональной направлению вектора [page:Object3D.up up] камеры. По умолчанию `true`.

[property:String type]

Тип контролов: `"ORBIT"`, `"FIRST_PERSON"` или `"FLYING"`.

Методы

[method:undefined assignToControls]([param:Controls controls], [param:Scene scene])

  • [page:Controls controls] — объект контролов, например [page:OrbitControls].
  • [page:Scene scene] — сцена, на которой будут применяться настройки контролов, только для [page:FirstPersonControls].

Назначает настройки контролов на объект контролов.

[method:ControlSettings clone]()

Клонирует настройки контролов.

[method:ControlSettings copy]([param:ControlSettings source])

Копирует настройки контролов.
