[name]

Контролы камеры.

Константы управления

These constants define camera controls.

Настройка типов движений

v3d.TweenLinear v3d.TweenSpherical

Конструктор

[name]([param:Camera object], [param:HTMLElement domElement])

[page:Camera object]
Камера, которой необходимо управлять.
[page:HTMLElement domElement]
HTML-элемент, используемый для прослушивания событий (необ.). По умолчанию используется весь документ, однако если вы хотите, чтобы элементы управления работали только над определенным элементом (например, холстом), вы можете его здесь.

Создаёт объект [name]. Обратите внимание, что данный конструктор не следует вызывать напрямую. Вместо этого воспользуйтесь одним из дочерних классов: [page:OrbitControls], [page:FlyingControls] или [page:FirstPersonControls].

Свойства

[property:Boolean allowMouseOverIframes]

Разрешать или нет перемещение указателя мыши над элементами `<iframe>`, расположенными на странице, во время управления камерой. По умолчанию `false`. Учтите, что если вызывается метод [page:App.enableCSSRenderer](), это значение устанавливается в `true`.

Для того чтобы позволить перемещение указателя мыши над фреймами, внутренние обработчики событий вызывают [page:.lockIframeEvents]() при начале перемещения камеры и [page:.unlockIframeEvents]() по его окончании.

[property:HTMLElement domElement]

HTMLElement, используемый для прослушивания событий мыши/тачскрина. Параметр должен быть установлен в конструкторе, поскольку прямое его изменение не приведёт к переназначению обработчиков событий. По умолчанию используется весь документ.

[property:Boolean enabled]

Включает или выключает возможность управления камерой.

[property:Camera object]

Управляемая камера (или другой объект).

Методы

[method:undefined lockIframeEvents]()

Запретить всем `<iframe>`-элементам на странице перехватывать пользовательские события. Обычно данный метод вызывается внутренними обработчиками событий соответствующего класса контролов. Для того чтобы вызывать его вручную, установите [page:.allowMouseOverIframes] в `false`.

[method:Float unlockIframeEvents]()

Разрешить всем `<iframe>`-элементам на странице перехватывать пользовательские события. Обычно данный метод вызывается внутренними обработчиками событий соответствующего класса контролов. Для того чтобы вызывать его вручную, установите [page:.allowMouseOverIframes] в `false`.
