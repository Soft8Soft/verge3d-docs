[page:Controls] →

[name]

Орбитальные контролы позволяют камере двигаться по орбите вокруг целевого объекта.

Пример

const renderer = new v3d.WebGLRenderer(); renderer.setSize(window.innerWidth, window.innerHeight); document.body.appendChild(renderer.domElement); const scene = new v3d.Scene(); const camera = new v3d.PerspectiveCamera(45, window.innerWidth / window.innerHeight, 1, 10000); const controls = new v3d.OrbitControls(camera); // controls.update() должен быть вызван после любых изменений положения камеры camera.position.set(0, 20, 100); controls.update(); function animate() { requestAnimationFrame(animate); // требуется, если controls.enableDamping или controls.autoRotate установлены в true controls.update(); renderer.render(scene, camera); }

Конструктор

[name]([page:Camera object], [page:HTMLDOMElement domElement])

[page:Camera object]
Камера, которой необходимо управлять (обязательный).
[page:HTMLDOMElement domElement]
Элемент HTML, используемый для прослушивания событий (необ.). По умолчанию это весь документ, однако если вы хотите, чтобы элементы управления работали только над определенным элементом (например, холстом), вы можете указать его здесь.

Свойства

[property:Boolean autoRotate]

Установите значение `true` для автоматического вращения вокруг целевого объекта.

Обратите внимание, что если эта функция включена, вы должны вызвать [page:.update]() в цикле анимации.

[property:Float autoRotateSpeed]

Скорость вращения вокруг целевого объекта, если [property:Boolean autoRotate] равно `true`. По умолчанию `2.0`, что соответствует 30 секундам на оборот при частоте рендеринга 60 кадров/с.

Обратите внимание, что если включено [property:Boolean autoRotate], необходимо вызвать [page:.update]() в цикле анимации.

[property:HTMLElement domElement]

HTML-элемент, используемый для прослушивания событий мыши/тачскрина. Он должен быть передан в конструкторе; изменение его здесь не приведет к установке новых обработчиков событий. По умолчанию используется весь документ.

[property:Boolean enabled]

Включены ли элементы управления или нет.

[property:Boolean enableCtrlZoom]

Установите в `true`, чтобы осуществлять зум только при нажатой клавише ctrl (подобно тому как это сделано в Google Maps). По умолчанию `false`.

[property:Boolean enableDamping]

Установите значение `true`, чтобы включить демпфирование (инерцию), которое можно использовать для придания чувства веса элементам управления. По умолчанию установлено значение `true`.

Обратите внимание, что если эта функция включена, необходимо вызвать [page:.update]() в цикле анимации.

[property:Boolean enableKeys]

Включает или отключает управление с клавиатуры. По умолчанию `true`.

[property:Boolean enablePan]

Включает или отключает панорамирование камеры. По умолчанию `true`.

[property:Boolean enableRotate]

Включает или отключает поворот камеры по горизонтали и вертикали. По умолчанию `true`.

Обратите внимание, что можно отключить одну ось, установив минимальное и максимальное значение [page:.minPolarAngle полярного] или [page:.minAzimuthAngle азимутального] углов в одно и то же значение, что приведет к фиксации вертикального или горизонтального вращения.

[property:Boolean enableTurnover]

Включает или выключает возможность перемещения камеры через голову. По умолчанию `false`.

[property:Boolean enableZoom]

Включает или отключает зум (dollying) камеры. По умолчанию `true`.

[property:Boolean inTween]

Флаг, указывающий, находится ли камера в режиме автоматического наведения (tweening).

[property:Float maxAzimuthAngle]

Как далеко вы можете двигаться по горизонтали, верхний предел. Диапазон от `-Math.PI` до `Math.PI` (или `Infinity` для отключения предела). По умолчанию `Infinity` (бесконечность).

[property:Float maxDistance]

Как далеко вы можете отдалиться (только для [page:PerspectiveCamera]). По умолчанию `Infinity` (бесконечность).

[property:Float maxPolarAngle]

Как далеко вы можете двигаться по вертикали, верхний предел. Диапазон от `0` до `Math.PI` радиан, по умолчанию `Math.PI`.

[property:Float maxZoom]

Насколько можно уменьшить масштаб изображения (только для [page:OrthographicCamera]). По умолчанию `Infinity` (бесконечность).

[property:Float minAzimuthAngle]

Как далеко вы можете двигаться по горизонтали, нижний предел. Диапазон от `-Math.PI` до `Math.PI` (или `-Infinity` для отключения предела). По умолчанию `-Infinity` (бесконечность).

[property:Float minDistance]

Насколько близко вы можете приближаться (только для [page:PerspectiveCamera]). По умолчанию `0`.

[property:Float minPolarAngle]

Как далеко вы можете двигаться по вертикали, нижний предел. Диапазон от `0` до `Math.PI` радиан. По умолчанию `0`.

[property:Float minZoom]

Насколько сильно можно увеличить масштаб изображения (только для [page:OrthographicCamera]). По умолчанию `0`.

[property:Object mouseButtons]

Этот объект содержит ссылки на кнопки мыши, используемые для управления.

controls.mouseButtons = { ROTATE: v3d.MOUSE.LEFT, ZOOM: v3d.MOUSE.MIDDLE, PAN: v3d.MOUSE.RIGHT }

[property:Camera object]

Управляемая камера.

[property:Float panInertia]

Инерция панорамирования, используемая если [page:.enableDamping] установлен в `true`. Обратите внимание, что для работы данной функции необходимо вызвать [page:.update]() в цикле анимации. По умолчанию `0.05`.

[property:Float panSpeed]

Скорость панорамирования. По умолчанию `1.3`.

[property:Float panSpeedKey]

Скорость панорамирования (количество пикселей) при использовании курсорных клавиш клавиатуры. По умолчанию `15.0`.

[property:Vector3 position0]

Используется методами [page:.saveState] и [page:.reset].

[property:Float rotateInertia]

Инерция вращения, используемая если [page:.enableDamping] установлен в `true`. Обратите внимание, что для работы данной функции необходимо вызвать [page:.update]() в цикле анимации. По умолчанию `0.05`.

[property:Float rotateInertiaTouch]

Аналогично [page:.rotateInertia], но используется на устройствах с тачскрином. По умолчанию `0.05`.

[property:Float rotateSpeed]

Скорость вращения. По умолчанию `1.2`.

[property:Float rotateSpeedTouch]

Скорость вращения при использовании такскринов. По умолчанию `0.7`.

[property:Boolean screenSpacePanning]

Определяет, как меняется положение камеры при панорамировании. Если `true`, камера движется в пространстве экрана. В противном случае камера движется в плоскости, ортогональной направлению вектора [page:Object3D.up up] камеры. По умолчанию `true`.

[property:Vector3 target0]

Используется внутренними методами [page:.saveState] и [page:.reset].

[property:Object3D targetObj]

Объект, положение которого в мировом пространстве служит точкой фокуса элементов управления, а [page:.object] вращается вокруг него. Его можно обновить вручную в любой момент, чтобы изменить фокус элементов управления.

[property:Float zoom0]

Используется внутренними методами [page:.saveState] и [page:.reset].

[property:Float zoomSpeed]

Скорость зума/приближения. По умолчанию `5.0`.

[property:Float zoomSpeedTouch]

Скорость зума/приближения на устройствах с тачскрином. По умолчанию `1.0`.

[property:Float zoomInertia]

Инерция зума, используемая если [page:.enableDamping] установлен в `true`. Обратите внимание, что для работы данной функции необходимо вызвать [page:.update]() в цикле анимации. По умолчанию `0.05`.

[property:Float zoomInertiaTouch]

Аналогично [page:.zoomInertia], но используется на устройствах с тачскрином. По умолчанию `0.05`.

Методы

[method:undefined dispose] ()

Удаляет все обработчики событий.

[method:radians getAzimuthalAngle] ()

Получает текущее горизонтальное вращение, в радианах.

[method:Float getDistance]()

Получает текущее расстояние между камерой и целевым объектом.

[method:radians getPolarAngle]()

Получает текущее вертикальное вращение, в радианах.

[method:undefined reset]()

Возвращает элементы управления к их состоянию либо после последнего вызова [page:.saveState], либо к начальному состоянию.

[method:undefined saveState]()

Сохраняет текущее состояние контролов. Впоследствии его можно восстановить с помощью [page:.reset].

[method:undefined tween] ([param:Vector3 toPosition], [param:Vector3 toTarget], [param:Float time], [param:Function finishCb], [param:Constant movementType])

toPosition
Новое положение камеры.
toTarget
Новая целевая точка.
time
Длина анимации перемещения.
finishCb
Функция обратного вызова, которая будет вызвана после завершения анимации перемещения.
movementType
Интерполяция движения. Может быть [page:Controls v3d.TweenLinear] (по умолчанию) или [page:Controls v3d.TweenSpherical].

Запускает автоматическое изменение текущего положения камеры и целевой точки на указанное новое положение и цель в течение указанного времени.

[method:undefined tweenZoomTo]([param:Vector3 toTarget], [param:Float toZoom], [param:Float time], [param:Function finishCb])

toTarget
Новое положение камеры.
toZoom
Новое значение зума.
time
Длина анимации перемещения.
finishCb
Функция обратного вызова, которая будет вызвана после завершения анимации перемещения.

Плавно изменяет целевую точку и зум [page:OrthographicCamera ортографической] камеры в течение указанного времени.

[method:Boolean update] ()

Обновляет контролы. Должен вызываться после любого изменения трансформаций камеры, или в цикле обновления, если установлены [page:.autoRotate] или [page:.enableDamping].
