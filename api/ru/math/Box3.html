[name]

Определяет параллельный осям ограничивающий параллелепипед («бокс», AABB) в трехмерном пространстве.

Пример

const box = new v3d.Box3(); const mesh = new v3d.Mesh( new v3d.SphereGeometry(), new v3d.MeshBasicMaterial() ); // обновляем ограничивающий параллелепипед // требуется сделать однократно (для статической геометрии) mesh.geometry.computeBoundingBox(); // ... // в цикле анимации вычисляем ограничивающий параллелепипед в мировой системе координат box.copy(mesh.geometry.boundingBox).applyMatrix4(mesh.matrixWorld);

Конструктор

[name]([param:Vector3 min], [param:Vector3 max])

  • [page:Vector3 min] — (необ.) [page:Vector3], представляющий нижнюю (x, y, z) границу бокса. По умолчанию (+Infinity, +Infinity, +Infinity).
  • [page:Vector3 max] — (необ.) [page:Vector3], представляющий верхнюю (x, y, z) границу бокса. По умолчанию (-Infinity, -Infinity, -Infinity).

Создает [name], ограниченный min и max.

Свойства

[property:Boolean isBox3]

Флаг, указывающий что данный объект является экземпляром [name]. Только для чтения.

[property:Vector3 min]

[page:Vector3] представляющий нижнюю (x, y, z) границу бокса. По умолчанию `(+Infinity, +Infinity, +Infinity)`.

[property:Vector3 max]

[page:Vector3] представляющий верхнюю (x, y, z) границу бокса. По умолчанию `(-Infinity, -Infinity, -Infinity)`.

Методы

[method:this applyMatrix4]([param:Matrix4 matrix])

[page:Matrix4 matrix] — [page:Matrix4] для применения.

Преобразовывает текущий Box3 с помощью матрицы.

[method:Vector3 clampPoint]([param:Vector3 point], [param:Vector3 target])

  • [page:Vector3 point] — [page:Vector3] для ограничения.
  • [page:Vector3 target] — результат будет скопирован в этот Vector3.

Ограничивает [page:Vector3 точку] в границах бокса.

[method:Box3 clone]()

Возвращает новый [page:Box3] с теми же [page:.min min] и [page:.max max], что и текущий.

[method:Boolean containsBox]([param:Box3 box])

[page:Box3 box] — [page:Box3 Box3] для проверки на включение.

Возвращает `true`, если текущий бокс включает в себя [page:Box3 box]. Если текущий и [page:Box3 box] идентичны, эта функция также возвращает `true`.

[method:Boolean containsPoint]([param:Vector3 point])

[page:Vector3 point] — [page:Vector3] для проверки на включение.

Возвращает `true`, если указанная точка [page:Vector3 point] лежит внутри или на границах данного бокса.

[method:this copy]([param:Box3 box])

[page:Box3 box] — [page:Box3] для копирования.

Копирует значения [page:.min min] и [page:.max max] из [page:Box3 box] в текущий бокс.

[method:Float distanceToPoint]([param:Vector3 point])

[page:Vector3 point] — [page:Vector3 точка] до которой нужно измерить расстояние.

Возвращает расстояние от любого края бокса до указанной точки. Если точка лежит внутри бокса, расстояние будет равно `0`.

[method:Boolean equals]([param:Box3 box])

[page:Box3 box] — бокс для сравнения.

Возвращает `true`, если у текущего бокса и [page:Box3 box] одинаковые нижняя и верхняя границы.

[method:this expandByObject]([param:Object3D object], [param:Boolean precise])

  • [page:Object3D object] — [page:Object3D объект]-расширитель.
  • [page:Boolean precise] — (необ.) расширять как можно меньше за счёт усложнения и времени расчётов. По умолчанию `false`.

Расширяет границы текущего бокса, чтобы включить в него заданный [page:Object3D объект] и его дочерние объекты, с учётом их трансформаций в мировой системе координат. В случае если `precise` не равен `true`, метод может привести к созданию более крупного бокса, чем это необходимо.

[method:this expandByPoint]([param:Vector3 point])

[page:Vector3 point] — [page:Vector3 точка], которая должна быть включена в бокс.

Расширяет границы текущего бокса, чтобы включить [page:Vector3 точку].

[method:this expandByScalar]([param:Float scalar])

[page:Float scalar] — расстояние, на которое нужно увеличить бокс.

Расширяет каждое измерение бокса на [page:Float скалярную величину]. При задании отрицательного значения, размеры бокса сужаются.

[method:this expandByVector]([param:Vector3 vector])

[page:Vector3 vector] — [page:Vector3 вектор]-расширитель бокса.

Производит равностороннее расширение текущего бокса на [page:Vector3 вектор]. Ширина текущего бокса будет увеличена на x-компонент вектора в обоих направлениях. Высота текущего бокса будет увеличена на y-компонент вектора в обоих направлениях. Глубина текущего бокса будет увеличена на компонент z вектора в обоих направлениях.

[method:Sphere getBoundingSphere]([param:Sphere target])

[page:Sphere target] — результирующая сфера.

Получает [page:Sphere сферу], ограничивающую данный бокс.

[method:Vector3 getCenter]([param:Vector3 target])

[page:Vector3 target] — результат будет скопирован в этот вектор.

Возвращает центральную точку бокса в виде [page:Vector3 вектора].

[method:Vector3 getParameter]([param:Vector3 point], [param:Vector3 target])

  • [page:Vector3 point] — [page:Vector3 точка].
  • [page:Vector3 target] — результат будет скопирован в этот Vector3.

Возвращает положение точки в виде пропорции от ширины, высоты и глубины данного бокса.

[method:Vector3 getSize]([param:Vector3 target])

[page:Vector3 target] — результат будет скопирован в этот Vector3.

Возвращает ширину, высоту и глубину текущего бокса.

[method:this intersect]([param:Box3 box])

[page:Box3 box] — бокс для расчёта пересечения.

Вычисляет пересечение текущего бокса и [page:Box3 box], устанавливая верхнюю границу текущего бокса на меньшую из верхних границ двух боксов, а нижнюю границу текущего бокса на большую из нижних границ двух боксов. Если пересечения нет, делает текущий бокс пустым.

[method:Boolean intersectsBox]([param:Box3 box])

[page:Box3 box] — бокс для проверки пересечения.

Определяет, пересекает ли текущий бокс указанный [page:Box3 box].

[method:Boolean intersectsPlane]([param:Plane plane])

[page:Plane plane] — [page:Plane плоскость] для проверки пересечения.

Определяет, пересекает ли текущий бокс указанную [page:Plane плоскость].

[method:Boolean intersectsSphere]([param:Sphere sphere])

[page:Sphere sphere] — [page:Sphere сфера] для проверки пересечения.

Определяет, пересекает ли текущий бокс [page:Sphere сферу].

[method:Boolean intersectsTriangle]([param:Triangle triangle])

[page:Triangle triangle] — [page:Triangle треугольник] для проверки пересечения.

Определяет, пересекает ли текущий бокс указанный [page:Triangle треугольник].

[method:Boolean isEmpty]()

Возвращает `true`, если этот бокс не включает точки в своих границах. Обратите внимание, что бокс с равными нижней и верхней границами все еще включает одну точку, общую для обеих границ.

[method:this makeEmpty]()

Делает текущий бокс пустым.

[method:this scale]([param:Vector3 s])

[page:Vector3 s] — вектор для масштабирования.

Масштабирует текущий бокс с помощью указанного вектора.

[method:this set]([param:Vector3 min], [param:Vector3 max])

  • [page:Vector3 min] — [page:Vector3], представляющий нижнюю (x, y, z) границу бокса.
  • [page:Vector3 max] — [page:Vector3], представляющий верхнюю (x, y, z) границу бокса.

Устанавливает нижнюю и верхнюю (x, y, z) границы данного бокса. Обратите внимание, что этот метод только копирует значения из заданных объектов.

[method:this setFromArray]([param:Array array])

[page:Array array] — массив данных о положениях, которые будет охватывать результирующий бокс.

Устанавливает верхнюю и нижнюю границы текущего бокса, чтобы включить все данные из `array`.

[method:this setFromBufferAttribute]([param:BufferAttribute attribute])

[page:BufferAttribute attribute] — буферный атрибут с данными о положениях, которые будет охватывать результирующий бокс.

Устанавливает верхнюю и нижнюю границы текущего бокса, чтобы включить все данные из [page:BufferAttribute атрибута].

[method:this setFromCenterAndSize]([param:Vector3 center], [param:Vector3 size])

  • [page:Vector3 center] — желаемое положение центра бокса.
  • [page:Vector3 size] — желаемые размеры бокса по x, y и z.

Центрирует текущий бокс по [page:Vector3 center] и устанавливает его ширину, высоту и глубину в значения из вектора [page:Vector3 size].

[method:this setFromObject]([param:Object3D object])

  • [page:Object3D object] — [page:Object3D] для вычисления ограничивающего бокса.
  • [page:Boolean precise] — (необ.) вычислить наименьший бокс в мировой системе координат за счёт увеличения сложности и времени расчётов. По умолчанию `false`.

Вычисляет область объекта [page:Object3D] (включая его дочерние объекты), выровненную по мировой оси, с учетом мировых преобразований объекта и его дочерних объектов. Функция может привести к тому, что бокс будет больше, чем это необходимо.

[method:this setFromPoints]([param:Array points])

[page:Array points] — массив [page:Vector3 Vector3], который будет содержать результирующий бокс.

Устанавливает верхнюю и нижнюю границы этого бокса, чтобы включить все точки из [page:Array points].

[method:this translate]([param:Vector3 offset])

[page:Vector3 offset] — направление и расстояние смещения.

Добавляет смещение к верхней и нижней границам текущего бокса, эффективно перемещая его на [page:Vector3 offset] единиц в трехмерном пространстве.

[method:this union]([param:Box3 box])

[page:Box3 box] — бокс, который будет объединен с текущим боксом.

Вычисляет объединение текущего бокса и указанного [page:Box3 box], устанавливая верхнюю границу текущего бокса на большую из верхних границ двух боксов и нижнюю границу текущего бокса на меньшую из нижних границ двух боксов.
