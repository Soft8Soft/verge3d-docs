[name]

Создаёт сферическую гармонику третьего порядка (СГ). Зонды освещения используют этот класс для кодирования информации об освещении.

Конструктор

[name]()

Создает новый экземпляр [name].

Свойства

[property:Array coefficients]

Массив, содержащий 9 коэффициентов СГ. Каждый коэффициент представлен в виде экземпляра [page:Vector3].

[property:Boolean isSphericalHarmonics3]

Флаг, указывающий что данный объект является экземпляром [name]. Только для чтения.

Методы

[method:SphericalHarmonics3 add]([param:SphericalHarmonics3 sh])

[page:SphericalHarmonics3 sh] — добавляемая СГ.

Добавляет указанную СГ к текущей.

[method:SphericalHarmonics3 addScaledSH]([param:SphericalHarmonics3 sh], [param:Float scale])

  • [page:SphericalHarmonics3 sh] — добавляемая СГ.
  • [page:Float scale] — коэффициент масштабирования.

Удобный метод для одновременного выполнения [page:.add]() и [page:.scale]().

[method:SphericalHarmonics3 clone]()

Возвращает новый экземпляр [name] с теми же коэффициентами.

[method:SphericalHarmonics3 copy]([param:SphericalHarmonics3 sh])

[page:SphericalHarmonics3 sh] — СГ для копирования.

Копирует указанную СГ в текущую.

[method:Boolean equals]([param:SphericalHarmonics3 sh])

[page:SphericalHarmonics3 sh] — СГ для сравнения.

Возвращает `true`, если указанная СГ и текущая имеют одинаковые коэффициенты.

[method:SphericalHarmonics3 fromArray]([param:Array array], [param:Float offset])

  • [page:Array array] — массив, содержащий числа коэффициентов СГ.
  • [page:Float offset] — (необ.) смещение в массиве.

Устанавливает коэффициенты текущего экземпляра СГ из заданного массива.

[method:Vector3 getAt]([param:Vector3 normal], [param:Vector3 target])

  • [page:Vector3 normal] — вектор нормали (предполагается единичной длины).
  • [page:Vector3 target] — вектор результата.

Возвращает освещенность в направлении заданной нормали.

[method:Vector3 getIrradianceAt]([param:Vector3 normal], [param:Vector3 target])

  • [page:Vector3 normal] — вектор нормали (предполагается единичной длины).
  • [page:Vector3 target] — результирующий вектор.

Возвращает irradiance (излучение), т.е. radiance (освещенность), преобразованную с помощью косинусной доли) в направлении заданной нормали.

[method:SphericalHarmonics3 lerp]([param:SphericalHarmonics3 sh], [param:Float alpha])

  • [page:SphericalHarmonics3 sh] — СГ для интерполяции.
  • [page:Float alpha] — альфа-фактор.

Производит линейную интерполяцию между указанной СГ и текущим экземпляром по заданному альфа-фактору.

[method:SphericalHarmonics3 scale]([param:Float scale])

[page:Float scale] — коэффициент масштабирования.

Масштабирует данную СГ с использованием указанного коэффициента.

[method:SphericalHarmonics3 set]([param:Array coefficients])

[page:Array coefficients] — массив коэффициентов СГ.

Устанавливает указанные коэффициенты в текущий экземпляр СГ.

[method:Array toArray]([param:Array array], [param:Float offset])

  • [page:Array array] — (необ.) целевой массив.
  • [page:Float offset] — (необ.) смещение массива.

Возвращает массив с коэффициентами или копирует их в предоставленный массив. Коэффициенты представляются в виде чисел.

[method:SphericalHarmonics3 zero]()

Устанавливает все коэффициенты СГ в `0`.

Статические методы

[method:void getBasisAt]([param:Vector3 normal], [param:Array shBasis])

  • [page:Vector3 normal] — вектор нормали (предполагается единичной длины).
  • [page:Array shBasis] — полученный базис СГ.

Вычисляет базис СГ для заданного вектора нормали.
