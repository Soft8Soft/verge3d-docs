[name]

Производит линейную интерполяцию входящих массивов.

Пример

const interpolant = new v3d.[name]( new Float32Array(2), new Float32Array(2), 1, new Float32Array(1) ); interpolant.evaluate(0.5);

Конструктор

[name](parameterPositions, sampleValues, sampleSize, resultBuffer)

  • parameterPositions — массив позиций.
  • sampleValues — массив семплов.
  • sampleSize — количество семплов.
  • resultBuffer — буфер для хранения результатов интерполяции.

Свойства

[property:Array parameterPositions]

Массив позиций.

[property:Array resultBuffer]

Массив для хранения результатов интерполяции.

[property:Array sampleValues]

Массив семплов.

[property:Object settings]

Необязательная структура настроек, специфичных для подкласса.

[property:Integer valueSize]

Количество семплов.

Методы

[method:Array evaluate]([param:Float t])

Вычисляет интерполяцию в позиции `t`.
