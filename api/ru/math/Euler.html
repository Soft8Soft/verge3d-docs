[name]

Класс, определяющий [link:https://ru.wikipedia.org/wiki/Углы_Эйлера углы Эйлера].

Углы Эйлера описывают вращательное преобразование, посредством вращения объекта на заданную величину вокруг каждой оси в определённом порядке.

Перечисление экземпляра [name] выдаёт его компоненты (x, y, z, order) в том же порядке.

Пример

const a = new v3d.Euler(0, 1, 1.57, 'XYZ'); const b = new v3d.Vector3(1, 0, 1); b.applyEuler(a);

Конструктор

[name]([param:Float x], [param:Float y], [param:Float z], [param:String order])

  • [page:Float x] — (необ.) угол наклона оси x в радианах. По умолчанию `0`.
  • [page:Float y] — (необ.) угол наклона оси y в радианах. По умолчанию `0`.
  • [page:Float z] — (необ.) угол наклона оси z в радианах. По умолчанию `0`.
  • [page:String order] — (необ.) строка, представляющая порядок применения вращений, по умолчанию `'XYZ'` (должен быть в верхнем регистре).

Свойства

[property:Boolean isEuler]

Флаг, указывающий что данный объект является экземпляром [name].

[property:String order]

Порядок применения вращений. По умолчанию — `'XYZ'`, что означает, что сначала объект будет повернут вокруг оси X, затем вокруг оси Y и, наконец, вокруг оси Z. Другими вариантами являются: `'YZX'`, `'ZXY'`, `'XZY'`, `'YXZ'` и `'ZYX'`. Они должны быть в верхнем регистре.

«Вердж3Д» использует intrinsic (внутренние углы) Тайт-Брайана. Это означает, что вращение выполняется относительно локальной системы координат. То есть, для порядка `'XYZ'` вращение происходит сначала вокруг локальной оси X (которая совпадает с мировой осью X), затем вокруг локальной оси Y (которая теперь может отличаться от мировой оси Y), затем локальной оси Z (которая может отличаться от мировой оси Z).

[property:Float x]

Текущее значение компонента x.

[property:Float y]

Текущее значение компонента y.

[property:Float z]

Текущее значение компонента z.

Методы

[method:Euler copy]([param:Euler euler])

Копирует значение из [page:Euler euler] в текущие углы Эйлера.

[method:Euler clone]()

Возвращает новые углы Эйлера с теми же параметрами, что и текущие.

[method:Boolean equals]([param:Euler euler])

Проверяет строгое равенство данных углов Эйлера и [page:Euler euler].

[method:Boolean equalsEps]([param:Euler euler], [param:Float eps])

Проверяет равенство данных углов Эйлера и заданного [page:Euler euler] с учетом погрешности `eps`.

[method:Euler fromArray]([param:Array array])

[page:Array array] длиной 3 или 4. Необязательный 4-й аргумент соответствует [page:.order order].

Присваивает текущий Эйлеров угол [page:.x x] из элемента массива `array[0]`.
Присваивает текущий Эйлеров угол [page:.y y] из элемента массива `array[1]`.
Присваивает текущий Эйлеров угол [page:.z z] из элемента массива `array[2]`.
Также может присвоить параметр [page:.order order] из элемента массива `array[3]` (при наличии).

[method:Euler makeAlternative]()

Меняет текущие углы Эйлера на альтернативный набор вращений в диапазоне [-π, π), соответствующий той же ориентации (например: от `(0, 0, π)` до `(-π, -π, 0)`).

[method:Euler reorder]([param:String newOrder])

Создаёт углы Эйлера с новым порядком. Выполняется посредством создания кватерниона из углов Эйлера и установки углов с новым порядком из кватерниона.

Метод сбрасывает информацию о количестве поворотов.

[method:Euler set]([param:Float x], [param:Float y], [param:Float z], [param:String order])

  • [page:.x x] — угол наклона оси x в радианах.
  • [page:.y y] — угол наклона оси y в радианах.
  • [page:.z z] — угол наклона оси z в радианах.
  • [page:.order order] — (необ.) строка, представляющая порядок применения вращений.

Устанавливает углы Эйлера и, опционально, [page:.order order].

[method:Euler setFromRotationMatrix]([param:Matrix4 m], [param:String order])

  • [page:Matrix4 m] — матрица [page:Matrix4] верхняя 3x3 часть которой является матрицей вращения (т.е. без масштабирования).
  • [page:.order order] — (необ.) строка, представляющая порядок применения вращений.

Устанавливает углы Эйлера на основе матрицы вращения и указанного порядка.

[method:Euler setFromQuaternion]([param:Quaternion q], [param:String order])

  • [page:Quaternion q] — нормализованный кватернион.
  • [page:.order order] — (необ.) строка, представляющая порядок применения вращений.

Устанавливает углы Эйлера из нормализованного кватерниона на основе порядка, указанного в [page:.order order].

[method:Euler setFromVector3]([param:Vector3 vector], [param:String order])

  • [page:Vector3 vector] — [page:Vector3].
  • [page:.order order] — (необ.) строка, представляющая порядок применения вращений.

Устанавливает параметры [page:.x x], [page:.y y] и [page:.z z] и, по желанию, обновляет [page:.order order].

[method:Array toArray]([param:Array array], [param:Integer offset])

  • [page:Array array] — (необ.) массив для хранения эйлера.
  • [page:Integer offset] (необ.) смещение в массиве.

Возвращает массив вида [[page:.x x], [page:.y y], [page:.z z], [page:.order order]].
