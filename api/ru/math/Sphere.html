[name]

Сфера, определяемая своими центром и радиусом.

Конструктор

[name]([param:Vector3 center], [param:Float radius])

  • [page:Vector3 center] — центр сферы. По умолчанию используется вектор `(0, 0, 0)`.
  • [page:Float radius] — радиус сферы. По умолчанию `-1`.

Создает новую [name].

Свойства

[property:Vector3 center]

[page:Vector3], определяющий центр сферы. По умолчанию `(0, 0, 0)`.

[property:Float radius]

Радиус сферы. По умолчанию равен `-1`.

Методы

[method:Sphere applyMatrix4]([param:Matrix4 matrix])

[page:Matrix4 matrix] — матрица 4x4 для применения к сфере.

Преобразует текущую сферу с помощью предоставленной [page:Matrix4 матрицы].

[method:Vector3 clampPoint]([param:Vector3 point], [param:Vector3 target])

  • [page:Vector3 point] — [page:Vector3] точка для ограничения.
  • [page:Vector3 target] — результат будет скопирован в этот Vector3.

Ограничивает точку внутри сферы. Если точка находится вне сферы, то она будет закреплена в ближайшей точке на краю сферы. Точки, уже находящиеся внутри сферы, не будут затронуты.

[method:Sphere clone]()

Возвращает новую сферу с теми же [page:.center center] и [page:.radius radius], что и текущая.

[method:Boolean containsPoint]([param:Vector3 point])

[page:Vector3 point] — [page:Vector3] для проверки.

Проверяет, содержит ли сфера указанную [page:Vector3 точку], учитывая также точки, расположенные на поверхности.

[method:Sphere copy]([param:Sphere sphere])

Копирует значения свойств [page:.center center] и [page:.radius radius] переданной сферы в эту сферу.

[method:Float distanceToPoint]([param:Vector3 point])

Возвращает ближайшее расстояние от границы сферы до точки [page:Vector3]. Если сфера содержит точку, расстояние будет отрицательным.

[method:this expandByPoint]([param:Vector3 point])

[page:Vector3 point] — [page:Vector3 точка], которую должна охватывать сфера.

Расширяет границы сферы, чтобы включить указанную [page:Vector3 точку].

[method:Boolean isEmpty]()

Проверяет, пуста ли сфера (радиус установлен в отрицательное число). Сфера с радиусом `0` содержит свою центральную точку и поэтому не считается пустой.

[method:Sphere makeEmpty]()

Делает сферу пустой, устанавливая [page:.center center] в `(0, 0, 0)` и [page:.radius radius] в `-1`.

[method:Boolean equals]([param:Sphere sphere])

Проверяет, равны ли центры и радиусы двух сфер.

[method:Box3 getBoundingBox]([param:Box3 target])

[page:Box3 target] — результат будет скопирован в этот кубоид.

Возвращает[link:https://ru.wikipedia.org/wiki/AABB минимальный ограничивающий параллелепипед] для текущей сферы.

[method:Boolean intersectsBox]([param:Box3 box])

[page:Box3 box] — [page:Box3] для проверки пересечения.

Определяет, пересекает ли текущая сфера заданный [page:Box3 кубоид].

[method:Boolean intersectsPlane]([param:Plane plane])

[page:Plane plane] — плоскость для проверки пересечения.

Определяет, пересекает ли текущая сфера заданную [page:Plane плоскость].

[method:Boolean intersectsSphere]([param:Sphere sphere])

[page:Sphere sphere] — сфера для проверки пересечения.

Проверяет, пересекаются ли две сферы.

[method:Sphere set]([param:Vector3 center], [param:Float radius])

  • [page:Vector3 center] — центр сферы.
  • [page:Float radius] — радиус сферы.

Устанавливает свойства [page:.center center] и [page:.radius radius] этой сферы.

[method:Sphere setFromPoints]([param:Array points], [param:Vector3 optionalCenter])

  • [page:Array points] — [page:Array массив] из позиций [page:Vector3].
  • [page:Vector3 optionalCenter] — необязательное [page:Vector3 положение] центра сферы.

Вычисляет минимальную ограничивающую сферу для массива [page:Array точек]. Если задан [page:Vector3 optionalCenter], то он используется в качестве центра сферы. В противном случае используется центр выровненного по осям ограничивающего параллелепипеда, охватывающего [page:Array точки].

[method:Sphere translate]([param:Vector3 offset])

Перемещает центр сферы на заданное [page:Vector3 смещение].

[method:this union]([param:Sphere sphere])

[page:Sphere sphere] — сфера, которая будет объединена с текущей.

Расширяет текущую сферу, чтобы включить и текущую и указанную сферы.
