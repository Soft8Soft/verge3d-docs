[name]

Геометрический треугольник, определяемый тремя [page:Vector3 векторами], соответствующие его углам.

Конструктор

[name]([param:Vector3 a], [param:Vector3 b], [param:Vector3 c])

  • [page:Vector3 a] — первый угол треугольника. По умолчанию [page:Vector3] с координатами `(0, 0, 0)`.
  • [page:Vector3 b] — второй угол треугольника. По умолчанию [page:Vector3] с координатами `(0, 0, 0)`.
  • [page:Vector3 c] — последний угол треугольника. По умолчанию [page:Vector3] с координатами `(0, 0, 0)`.

Создает новый [name].

Свойства

[property:Vector3 a]

Первый угол треугольника. По умолчанию [page:Vector3] с координатами `(0, 0, 0)`.

[property:Vector3 b]

Второй угол треугольника. По умолчанию [page:Vector3] с координатами `(0, 0, 0)`.

[property:Vector3 c]

Последний угол треугольника. По умолчанию [page:Vector3] с координатами `(0, 0, 0)`.

Методы

[method:Triangle clone]()

Возвращает новый треугольник с теми же свойствами [page:.a a], [page:.b b] и [page:.c c], что и текущий.

[method:Vector3 closestPointToPoint]([param:Vector3 point], [param:Vector3 target])

  • [page:Vector3 point] — [page:Vector3].
  • [page:Vector3 target] — результат будет скопирован в этот Vector3.

Возвращает точку на треугольнике, ближайшую к указанной точке.

[method:Boolean containsPoint]([param:Vector3 point])

[page:Vector3 point] - [page:Vector3] для проверки.

Возвращает `true`, если переданная точка, спроецированная на плоскость треугольника, лежит внутри треугольника.

[method:Triangle copy]([param:Triangle triangle])

Копирует значения свойств [page:.a a], [page:.b b] и [page:.c c] переданного треугольника в текущий треугольник.

[method:Boolean equals]([param:Triangle triangle])

Возвращает `true`, если два треугольника имеют одинаковые свойства [page:.a a], [page:.b b] и [page:.c c].

[method:Float getArea]()

Возвращает площадь треугольника.

[method:Vector3 getBarycoord]([param:Vector3 point], [param:Vector3 target])

  • [page:Vector3 point] — [page:Vector3].
  • [page:Vector3 target] — результат будет скопирован в этот Vector3.

Возвращает [link:https://ru.wikipedia.org/wiki/Барицентрические_координаты барицентрические координаты] заданного вектора.

[method:Vector3 getMidpoint]([param:Vector3 target])

[page:Vector3 target] — результат будет скопирован в этот Vector3.

Вычисляет среднюю точку треугольника.

[method:Vector3 getNormal]([param:Vector3 target])

[page:Vector3 target] — результат будет скопирован в этот Vector3.

Вычисляет вектор нормали треугольника.

[method:Plane getPlane]([param:Plane target])

[page:Plane target] — результат будет скопирован в эту плоскость.

Вычисляет [page:Plane плоскость] на основе треугольника.

[method:Vector2 getUV]([param:Vector3 point], [param:Vector2 uv1], [param:Vector2 uv2], [param:Vector2 uv3], [param:Vector2 target])

  • [page:Vector3 point] — точка на треугольнике.
  • [page:Vector2 uv1] — uv-координата первой точки треугольника.
  • [page:Vector2 uv2] — uv-координата второй точки треугольникаx.
  • [page:Vector2 uv3] — uv-координата третьей точки треугольника.
  • [page:Vector2 target] — вектор для сохранения результата.

Возвращает UV-координаты указанной точки на треугольнике.

[method:Boolean intersectsBox]([param:Box3 box])

[page:Box3 box] — куб для проверки пересечения.

Определяет, пересекает ли текущий треугольник указанный [page:Box3 кубоид].

[method:Boolean isFrontFacing]([param:Vector3 direction])

[page:Vector3 direction] — направление для проверки.

Проверяет, направлен ли треугольник в указанном направлении.

[method:Triangle set]([param:Vector3 a], [param:Vector3 b], [param:Vector3 c]) [param:Triangle this]

Устанавливает свойства [page:.a a], [page:.b b] и [page:.c c] треугольника из указанных [page:Vector3 векторов]. Обратите внимание, что этот метод только копирует значения из заданных объектов.

[method:this setFromAttributeAndIndices]([param:BufferAttribute attribute], [param:Integer i0], [param:Integer i1], [param:Integer i2]) [param:Triangle this]

  • attribute — вертексный [page:BufferAttribute атрибут].
  • i0 — [page:Integer] индекс.
  • i1 — [page:Integer] индекс.
  • i2 — [page:Integer] индекс.

Устанавливает углы треугольника на основе данных вертексного атрибута.

[method:Triangle setFromPointsAndIndices]([param:Array points], [param:Integer i0], [param:Integer i1], [param:Integer i2]) [param:Triangle this]

  • points — [page:Array массив] [page:Vector3 векторов].
  • i0 — [page:Integer] индекс.
  • i1 — [page:Integer] индекс.
  • i2 — [page:Integer] индекс.

Устанавливает углы треугольника на основе векторов из указанного массива.
