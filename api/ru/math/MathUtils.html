Функции

[method:Float angleToRange_0_2Pi]([param:Float angle])

Конвертирует угол в интервал `[0, 2π)`.

v3d.MathUtils.angleToRange_0_2Pi(0.5 * Math.PI) // → 1.570796 = 1/2 π v3d.MathUtils.angleToRange_0_2Pi(-0.5 * Math.PI) // → 4.712388 = 3/2 π v3d.MathUtils.angleToRange_0_2Pi(2 * Math.PI) // → 0 v3d.MathUtils.angleToRange_0_2Pi(3 * Math.PI) // → 3.141592 = π v3d.MathUtils.angleToRange_0_2Pi(10 * Math.PI) // → 0

[method:Float angleToRange_mPi_Pi]([param:Float angle])

Конвертирует угол в интервал `[-π, π)`.

[method:Float lerp]([param:Float x], [param:Float y], [param:Float t])

  • [page:Float x] — начальная точка.
  • [page:Float y] — конечная точка.
  • [page:Float t] — коэффициент интерполяции в замкнутом интервале [0, 1].

Возвращает линейную интерполяцию двух известных точек на основе заданного интервала - [page:Float t] = 0 вернет [page:Float x] и [page:Float t] = 1 вернет [page:Float y].

[method:Float damp]([param:Float x], [param:Float y], [param:Float lambda], [param:Float dt])

  • [page:Float x] — текущая точка.
  • [page:Float y] — целевая точка.
  • [page:Float lambda] — высокая лямбда делает перемещение резким, низкая — более плавным.
  • [page:Float dt] — delta time in seconds.

Плавно интерполирует число от [page:Float x] к [page:Float y] подобно пружине, с использованием значения [page:Float dt], служащего для реализации движения, не зависящего от частоты кадров. Смотрите подробности [link:https://www.rorydriscoll.com/2016/03/07/frame-rate-independent-damping-using-lerp/ тут].

[method:Float smoothstep]([param:Float x], [param:Float min], [param:Float max])

  • [page:Float x] — значение для оценки на основе его положения между min и max.
  • [page:Float min] — любое значение x ниже min будет равно `0`.
  • [page:Float max] — любое значение x, превышающее max, будет равно `1`.

Возвращает значение от 0 до 1, которое представляет процент того, что x переместился между min и max, но сглаживается или замедляется, чем ближе X к min и max.

Для дополнительной информации ознакомьтесь с [link:https://en.wikipedia.org/wiki/Smoothstep со следующей статьёй].

[method:Float smootherstep]([param:Float x], [param:Float min], [param:Float max])

  • [page:Float x] — значение для оценки на основе его положения между min и max.
  • [page:Float min] — любое значение x ниже min будет равно `0`.
  • [page:Float max] — любое значение x, превышающее max, будет равно `1`.

Возвращает значение в диапазоне 0-1. Вариация smoothstep, которая имеет нулевые производные первого и второго порядка при x=0 и x=1.

[method:undefined setQuaternionFromProperEuler]([param:Quaternion q], [param:Float a], [param:Float b], [param:Float c], [param:String order])

  • [page:Quaternion q] — кватернион, который необходимо установить.
  • [page:Float a] — поворот, применимый к первой оси, в радианах.
  • [page:Float b] — поворот, применимый ко второй оси, в радианах.
  • [page:Float c] — поворот, применимый к третьей оси, в радианах.
  • [page:String order] — строка, определяющая порядок осей: 'XYX', 'XZX', 'YXY', 'YZY', 'ZXZ', или 'ZYZ'.

Задает [page:Quaternion кватернион] из [link:http://en.wikipedia.org/wiki/Euler_angles внутренних углов Эйлера], определяемых углами [page:Float a], [page:Float b], и [page:Float c], и порядком [page:String order].

Вращения применяются к осям в порядке, указанном [page:String order]: сначала применяется вращение на угол [page:Float a], затем на угол [page:Float b], затем на угол [page:Float c]. Углы указаны в радианах.
