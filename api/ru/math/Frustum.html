[name]

Усечённые пирамиды видимости («[link:https://en.wikipedia.org/wiki/Frustum фрустумы]») используются для определения того, что находится в поле зрения камеры. Они помогают ускорить процесс рендеринга - объекты, находящиеся за пределами пирамиды видимости камеры, могут быть исключены из рендеринга.

Этот класс в основном предназначен для внутреннего использования рендерером для вычисления пирамиды видимости [page:Camera камеры] или [page:LightShadow.camera теневой камеры].

Конструктор

[name]([param:Plane p0], [param:Plane p1], [param:Plane p2], [param:Plane p3], [param:Plane p4], [param:Plane p5])

  • [page:Plane p0] — (необ.) по умолчанию используется новая [page:Plane плоскость].
  • [page:Plane p1] — (необ.) по умолчанию используется новая [page:Plane плоскость].
  • [page:Plane p2] — (необ.) по умолчанию используется новая [page:Plane плоскость].
  • [page:Plane p3] — (необ.) по умолчанию используется новая [page:Plane плоскость].
  • [page:Plane p4] — (необ.) по умолчанию используется новая [page:Plane плоскость].
  • [page:Plane p5] — (необ.) по умолчанию используется новая [page:Plane плоскость].

Создает новый [name].

Свойства

[property:Array planes]

Массив из 6 [page:Plane плоскостей].

Методы

[method:Frustum clone]()

Возвращает новую пирамиду видимости с теми же параметрами, что и текущая.

[method:Boolean containsPoint]([param:Vector3 point])

[page:Vector3 point] — [page:Vector3] для проверки.

Проверяет, содержит ли пирамида видимости точку [page:Vector3 point].

[method:Frustum copy]([param:Frustum frustum])

[page:Frustum frustum] — пирамида видимости для копирования.

Копирует свойства указанной [page:Frustum пирамиды видимости] в текущую.

[method:Boolean intersectsBox]([param:Box3 box])

[page:Box3 box] — [page:Box3] для проверки пересечения.

Возвращает `true`, если [page:Box3 box] пересекается с данной пирамидой видимости.

[method:Boolean intersectsObject]([param:Object3D object])

Проверяет, пересекает ли пирамиду видимости [page:BufferGeometry.boundingSphere ограничивающая сфера] [page:Object3D объекта].

Обратите внимание, что объект должен иметь [page:BufferGeometry геометрию], чтобы можно было рассчитать ограничительную сферу.

[method:Boolean intersectsSphere]([param:Sphere sphere])

[page:Sphere sphere] — [page:Sphere сфера] для проверки пересечения.

Возвращает `true`, если [page:Sphere сфера] пересекается с данной пирамидой видимости.

[method:Boolean intersectsSprite]([param:Sprite sprite])

Проверяет, пересекает ли [page:Sprite спрайт] текущую пирамиду видимости.

[method:this set]([param:Plane p0], [param:Plane p1], [param:Plane p2], [param:Plane p3], [param:Plane p4], [param:Plane p5])

Устанавливает пирамиду видимости из переданных плоскостей. Порядок следования плоскостей не подразумевается. Обратите внимание, что этот метод копирует значения из заданных объектов.

[method:this setFromProjectionMatrix]([param:Matrix4 matrix])

[page:Matrix4 matrix] — [page:Matrix4 матрица] проекции, используемая для установки [page:.planes плоскостей].

Устанавливает плоскости пирамиды видимости из матрицы проекции.
