[name]

Луч, который испускается из начала координат в определенном направлении. Он используется классом [page:Raycaster] для осуществления [link:https://ru.wikipedia.org/wiki/Рейкастинг рейкастинга]. Рейкастинг используется для пикинга объектов (определение объектов в 3Д-пространстве, над которыми находится курсор мыши), а также для других целей.

Конструктор

[name]([param:Vector3 origin], [param:Vector3 direction])

  • [page:Vector3 origin] — (необ.) начало [page:Ray луча]. По умолчанию используется [page:Vector3 вектор] с координатами `(0, 0, 0)`.
  • [page:Vector3 direction] — [page:Vector3] направление [page:Ray луча]. Оно должно быть нормализовано (с помощью [page:Vector3.normalize]), чтобы методы класса работали правильно. По умолчанию используется [page:Vector3 вектор] с координатами `(0, 0, -1)`.

Создает новый [name].

Свойства

[property:Vector3 origin]

Начало координат [page:Ray луча]. По умолчанию используется [page:Vector3 вектор] с координатами `(0, 0, 0)`.

[property:Vector3 direction]

Направление [page:Ray луча]. Оно должно быть нормализовано (с помощью [page:Vector3.normalize]), чтобы методы работали правильно. По умолчанию используется [page:Vector3 вектор] с координатами `(0, 0, -1)`.

Методы

[method:Ray applyMatrix4]([param:Matrix4 matrix4])

[page:Matrix4 matrix4] — [page:Matrix4] для применения к данному [page:Ray лучу].

Преобразовывает текущий [page:Ray луч] с помощью [page:Matrix4].

[method:Vector3 at]([param:Float t], [param:Vector3 target])

  • [page:Float t] — расстояние вдоль [page:Ray] для получения позиции.
  • [page:Vector3 target] — результат будет скопирован в этот Vector3.

Получает [page:Vector3], который находится на заданном расстоянии вдоль данного [page:Ray луча].

[method:Ray clone]()

Создает новый луч со свойствами [page:.origin origin] и [page:.direction direction] идентичными данному.

[method:Vector3 closestPointToPoint]([param:Vector3 point], [param:Vector3 target])

  • [page:Vector3 point] — точка, к которой нужно подойти ближе всего.
  • [page:Vector3 target] — результат будет скопирован в этот Vector3.

Получает точку вдоль данного [page:Ray луча], которая ближе всего к заданному [page:Vector3].

[method:Ray copy]([param:Ray ray])

Копирует свойства [page:.origin origin] и [page:.direction direction direction] из [page:Ray луча], поданного в качестве параметра в текущий луч.

[method:Float distanceSqToPoint]([param:Vector3 point])

[page:Vector3 point] — точка для вычисления расстояния.

Получает квадратичное расстояние ближайшего расстояния между [page:Ray] и [page:Vector3].

[method:Float distanceSqToSegment]([param:Vector3 v0], [param:Vector3 v1], [param:Vector3 optionalPointOnRay], [param:Vector3 optionalPointOnSegment])

  • [page:Vector3 v0] — начало отрезка линии.
  • [page:Vector3 v1] — конец отрезка линии.
  • optionalPointOnRay — (необ.), если указан, получает точку на данном [page:Ray луче], которая ближе всего к отрезку.
  • optionalPointOnSegment - (необ.), если указан, получает точку на отрезке прямой, которая ближе всего к данному [page:Ray лучу].

Получает квадратичное расстояние между данным [page:Ray лучом] и отрезком прямой.

[method:Float distanceToPlane]([param:Plane plane])

[page:Plane plane] — плоскость для вычисления расстояния.

Получает расстояние от [page:.origin origin] до [page:Plane]. Возвращает `null`, если [page:Ray луч] не пересекает [page:Plane плоскость].

[method:Float distanceToPoint]([param:Vector3 point])

[page:Vector3 point] — точка для вычисления расстояния.

Получает расстояние ближайшего сближения между [page:Ray] и точкой [page:Vector3].

[method:Boolean equals]([param:Ray ray])

[page:Ray ray] — луч для сравнения.

Возвращает `true`, если этот и другой [page:Ray луч] имеют одинаковые [page:.origin origin] и [page:.direction direction].

[method:Vector3 intersectBox]([param:Box3 box], [param:Vector3 target])

  • [page:Box3 box] — [page:Box3] для пересечения.
  • [page:Vector3 target] — результат будет скопирован в этот Vector3.

Пересекает текущий [page:Ray луч] с [page:Box3], возвращая точку пересечения или `null`, если пересечения нет.

[method:Vector3 intersectPlane]([param:Plane plane], [param:Vector3 target])

  • [page:Plane plane] — [page:Plane] для пересечения.
  • [page:Vector3 target] — результат будет скопирован в этот Vector3.

Пересекает текущий [page:Ray луч] с [page:Plane плоскостью], возвращая точку пересечения или `null`, если пересечения нет.

[method:Vector3 intersectSphere]([param:Sphere sphere], [param:Vector3 target])

  • [page:Sphere sphere] — [page:Sphere] для пересечения.
  • [page:Vector3 target] — результат будет скопирован в этот Vector3.

Пересекает текущий [page:Ray луч] со [page:Sphere сферой], возвращая точку пересечения или `null`, если пересечения нет.

[method:Vector3 intersectTriangle]([param:Vector3 a], [param:Vector3 b], [param:Vector3 c], [param:Boolean backfaceCulling], [param:Vector3 target])

  • [page:Vector3 a], [page:Vector3 b], [page:Vector3 c] — вершины треугольника.
  • [page:Boolean backfaceCulling] — использовать ли backface culling.
  • [page:Vector3 target] — результат будет скопирован в этот Vector3.

Пересекает текущий [page:Ray луч] с треугольником, возвращая точку пересечения или `null`, если пересечения нет.

[method:Boolean intersectsBox]([param:Box3 box])

[page:Box3 box] — [page:Box3] для пересечения.

Возвращает `true`, если текущий [page:Ray луч] пересекается с [page:Box3].

[method:Boolean intersectsPlane]([param:Plane plane])

[page:Plane plane] — [page:Plane] для пересечения.

Возвращает `true`, если текущий [page:Ray луч] пересекается с [page:Plane плоскостью].

[method:Boolean intersectsSphere]([param:Sphere sphere])

[page:Sphere sphere] — [page:Sphere] для пересечения.

Возвращает `true`, если текущий [page:Ray луч] пересекается со [page:Sphere сферой].

[method:Ray lookAt]([param:Vector3 v])

[page:Vector3 v] — [page:Vector3 вектор] направления.

Меняет направление луча так, чтобы он указывал на вектор в мировых координатах.

[method:Ray recast]([param:Float t])

[page:Float t] — расстояние.

Сдвигает начало текущего луча вдоль своего направления на указанное расстояние.

[method:Ray set]([param:Vector3 origin], [param:Vector3 direction])

  • [page:Vector3 origin] — [page:.origin origin] данного [page:Ray].
  • [page:Vector3 origin] — [page:.direction direction] данного [page:Ray]. Для правильной работы методов его необходимо нормализовать (с помощью [page:Vector3.normalize]).

Устанавливает свойства [page:.origin origin] и [page:.direction direction] этого луча, копируя значения из заданных объектов.
