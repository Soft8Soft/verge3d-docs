[name]

Реализует повороты с помощью [link:https://ru.wikipedia.org/wiki/Кватернион кватернионов].

Перечисление [name] выдаёт его координаты `(x, y, z, w)` в том же порядке.

Пример

const quaternion = new v3d.Quaternion(); quaternion.setFromAxisAngle(new v3d.Vector3(0, 1, 0), Math.PI / 2); const vector = new v3d.Vector3(1, 0, 0); vector.applyQuaternion(quaternion);

Конструктор

[name]([param:Float x], [param:Float y], [param:Float z], [param:Float w])

  • [page:Float x] — x координата.
  • [page:Float y] — y координата.
  • [page:Float z] — z координата.
  • [page:Float w] — w координата.

Свойства

[property:Boolean isQuaternion]

Указывает, что объект является экземпляром класса [name]. Только для чтения.

Методы

[method:Float angleTo]([param:Quaternion q])

Возвращает угол между этим кватернионом и кватернионом [page:Quaternion q] в радианах.

[method:Quaternion clone]()

Создает новый кватернион со свойствами [page:.x x], [page:.y y], [page:.z z] и [page:.w w], идентичными данному.

[method:this conjugate]()

Возвращает вращательную конъюгату данного кватерниона. Сопряженный кватернион представляет собой одно и то же вращение в противоположном направлении вокруг оси вращения.

[method:this copy]([param:Quaternion q])

Копирует свойства [page:.x x], [page:.y y], [page:.z z] и [page:.w w] из [page:Quaternion q] в данный кватернион.

[method:Boolean equals]([param:Quaternion v])

[page:Quaternion v] — кватернион, с которым будет сравниваться данный кватернион.

Сравнивает свойства [page:.x x], [page:.y y], [page:.z z] и [page:.w w] [page:Quaternion v] с эквивалентными свойствами текущего кватерниона, чтобы определить, представляют ли они одно и то же вращение.

[method:Float dot]([param:Quaternion v])

Вычисляет [link:https://en.wikipedia.org/wiki/Dot_product скалярное произведение] кватернионов [page:Quaternion v] и данного.

[method:this fromArray]([param:Array array], [param:Integer offset])

  • [page:Array array] — массив формата (x, y, z, w), используемого для построения кватерниона.
  • [page:Integer offset] — (необ.) смещение в массиве.

Устанавливает свойства [page:.x x], [page:.y y], [page:.z z] и [page:.w w] текущего кватерниона из массива.

[method:this identity]()

Устанавливает текущий кватернион в кватернион тождества; то есть в кватернион, который представляет "отсутствие вращения".

[method:this invert]()

Инвертирует данный кватернион - вычисляет [page:.conjugate conjugate]. Предполагается, что кватернион имеет единичную длину.

[method:Float length]()

Вычисляет [link:https://en.wikipedia.org/wiki/Euclidean_distance Евклидову метрику] (длину прямой линии) данного кватерниона, рассматриваемого как 4-мерный вектор.

[method:Float lengthSq]()

Вычисляет квадрат [link:https://en.wikipedia.org/wiki/Euclidean_distance Евклидова расстояния] (длины прямой) данного кватерниона, рассматриваемого как 4-мерный вектор. Это может быть полезно, если вы сравниваете длины двух кватернионов, так как это немного более эффективное вычисление, чем [page:.length length]().

[method:this normalize]()

[link:https://en.wikipedia.org/wiki/Normalized_vector Нормализует] текущий кватернион - то есть вычисляет кватернион, который выполняет то же вращение, что и текущий, но имеет [page:.length длину] равную `1`.

[method:this multiply]([param:Quaternion q])

Умножает данный кватернион на [page:Quaternion q].

[method:this multiplyQuaternions]([param:Quaternion a], [param:Quaternion b])

Устанавливает текущий кватернион в [page:Quaternion a] x [page:Quaternion b]. Адаптация метода, изложенного [link:https://www.euclideanspace.com/maths/algebra/realNormedAlgebra/quaternions/code/index.htm здесь].

[method:this premultiply]([param:Quaternion q])

Предварительно умножает текущий кватернион на [page:Quaternion q].

[method:this random]()

Устанавливает текущий кватернион в случайный нормализованный кватернион.

[method:this rotateTowards]([param:Quaternion q], [param:Float step])

  • [page:Quaternion q] — целевой кватернион.
  • [page:Float step] — угловой шаг в радианах.

Поворачивает данный кватернион на заданный угловой шаг к определенному кватерниону `q`. Метод гарантирует, что конечный кватернион не будет превышать `q`.

[method:this slerp]([param:Quaternion qb], [param:Float t])

  • [page:Quaternion qb] — кватернион.
  • [page:Float t] — коэффициент интерполяции в замкнутом интервале `[0, 1]`.

Обрабатывает сферическую линейную интерполяцию между кватернионами. [page:Float t] представляет собой величину поворота между данным кватернионом (где [page:Float t] равно 0) и [page:Quaternion qb] (где [page:Float t] равно 1). Этот кватернион устанавливается в результат. Также смотрите статическую версию `slerp` ниже.

// повернуть меш в направлении целевого кватерниона mesh.quaternion.slerp(endQuaternion, 0.01);

[method:this set]([param:Float x], [param:Float y], [param:Float z], [param:Float w])

Задает [page:.x x], [page:.y y], [page:.z z], [page:.w w] свойства текущего кватерниона.

[method:this setFromAxisAngle]([param:Vector3 axis], [param:Float angle])

Устанавливает текущий кватернион из вращения, заданного осью [page:Vector3 axis] и углом [page:Float angle].

Адаптация следующего [link:https://www.euclideanspace.com/maths/geometry/rotations/conversions/angleToQuaternion/index.htm метода]. `axis` (ось) предполагается нормализованной, `angle` (угол) — в радианах.

[method:this setFromEuler]([param:Euler euler])

Устанавливает текущий кватернион из вращения, заданного углом [page:Euler Эйлера].

[method:this setFromRotationMatrix]([param:Matrix4 m])

[page:Matrix4 m] — a [page:Matrix4] [page:Matrix4], из которых верхняя 3x3 матрица является чистой [link:https://en.wikipedia.org/wiki/Rotation_matrix матрицей вращения] (т.е. немасштабированной).

Устанавливает текущий кватернион из компонента вращения [page:Matrix4 m]. Адаптация следующего [link:http://www.euclideanspace.com/maths/geometry/rotations/conversions/matrixToQuaternion/index.htm метода].

[method:this setFromUnitVectors]([param:Vector3 vFrom], [param:Vector3 vTo])

Применяет к данному кватерниону вращение, необходимое для поворота вектора направления [page:Vector3 vFrom] к вектору направления [page:Vector3 vTo]. Предполагается, что [page:Vector3 vFrom] и [page:Vector3 vTo] нормализованы.

[method:this slerpQuaternions]([param:Quaternion qa], [param:Quaternion qb], [param:Float t])

Производит сферическую интерполяцию между указанными кватернионами и сохраняет результат в текущий кватернион.

[method:Array toArray]([param:Array array], [param:Integer offset])

  • [page:Array array] — (необ.) массив для хранения кватерниона. Если он не указан, будет создан новый массив.
  • [page:Integer offset] — (необ.) если указан, результат будет скопирован в данный [page:Array].

Возвращает числовые элементы данного кватерниона в массиве формата [x, y, z, w].

[method:this fromBufferAttribute]([param:BufferAttribute attribute], [param:Integer index])

  • [page:BufferAttribute attribute] — атрибут источника.
  • [page:Integer index] — индекс в атрибуте.

Устанавливает [page:.x x], [page:.y y], [page:.z z], [page:.w w] свойства текущего кватерниона из атрибута [page:BufferAttribute].

Статические методы

[method:undefined slerpFlat]([param:Array dst], [param:Integer dstOffset], [param:Array src0], [param:Integer srcOffset0], [param:Array src1], [param:Integer srcOffset1], [param:Float t])

  • [page:Array dst] — выходной массив.
  • [page:Integer dstOffset] — смещение в выходном массиве.
  • [page:Array src0] — исходный массив начального кватерниона.
  • [page:Integer srcOffset0] — смещение в массиве `src0`.
  • [page:Array src1] — исходный массив целевого кватнериона.
  • [page:Integer srcOffset1] — смещение в массиве `src1`.
  • [page:Float t] — нормированный коэффициент интерполяции (от 0 до 1).

Подобен статическому методу [page:.slerp] выше, но работает непосредственно с плоскими массивами чисел.

[method:Array multiplyQuaternionsFlat]([param:Array dst], [param:Integer dstOffset], [param:Array src0], [param:Integer srcOffset0], [param:Array src1], [param:Integer srcOffset1])

  • [page:Array dst] — выходной массив.
  • [page:Integer dstOffset] — смещение в выходном массиве.
  • [page:Array src0] — исходный массив начального кватерниона.
  • [page:Integer srcOffset0] — смещение в массиве `src0`.
  • [page:Array src1] — исходный массив целевого кватнериона.
  • [page:Integer srcOffset1] — смещение в массиве `src1`.

Эта реализация умножения кватернионов предполагает, что данные находятся в плоских массивах.
