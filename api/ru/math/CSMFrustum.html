[name]

Этот класс создан в основном для внутреннего использования в [page:DirectionalLightShadowCSM DirectionalLightShadowCSM] для расчета каскадных пирамид видимости.

Конструктор

[name]()

Создает новый [name].

Свойства

[property:Object vertices]

Содержит 8 точек, которые формируют пирамиду видимости.

  • [page:Array near] — массив [page:Vector3 точек] формирующие ближню плоскость отсечения.
  • [page:Array far] — массив [page:Vector3 точек] формирующие дальную плоскость отсечения.

Методы

[method:this setFromProjectionMatrix]([param:Matrix4 matrix], [param:Float maxFar])

  • [page:Matrix4 matrix] — матрица проекции [page:Camera камеры] вида.
  • [page:Float maxFar] — расстояние до дальней плоскости отсечения.

Вычисляет точки пирамиды видимости из матрицы проекции.

[method:this split]([param:Array breaks], [param:Array target], [param:Boolean fitToScene])

  • [page:Array breaks] — массив интервалов.
  • [page:Array target] — массив [page:CSMFrustum CSMFrustum], `target.length <= breaks.length` условие должно быть верным.
  • [page:Boolean fitToScene] — при значении `true`, использует метод fit to scene иначе метод fit to cascade.

Разделяет текущую пирамиду видимости на каскады.

[method:this toSpace]([param:Matrix4 matrix], [param:this target])

  • [page:Matrix4 matrix] — матрица применяемая к каждой точке пирамиды видимости.
  • [page:this target] — [page:CSMFrustum пирамида видимости] в которую будет записан результат.

Умножает каждую точку пирамиды видимости на матрицу и записывает результат в target.
