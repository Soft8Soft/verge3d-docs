[name]

Представляет выровненную по оси ограничительную рамку (AABB) в двумерном пространстве.

Конструктор

[name]([param:Vector2 min], [param:Vector2 max])

  • [page:Vector2 min] — (необ.) [page:Vector2 вектор], представляющий нижнюю (x, y) границу рамки. По умолчанию `(+Infinity, +Infinity)`.
  • [page:Vector2 max] — (необ.) [page:Vector2 вектор], представляющий верхнюю (x, y) границу рамки. По умолчанию `(-Infinity, -Infinity)`.

Создает новую рамку [name], ограниченную `min` и `max`.

Свойства

[property:Vector2 min]

[page:Vector2] представляет собой нижнюю (x, y) границу рамки. По умолчанию `(+Infinity, +Infinity)`.

[property:Vector2 max]

[page:Vector2] представляет собой нижнюю верхнюю (x, y) границу рамки. По умолчанию `(-Infinity, -Infinity)`.

Методы

[method:Vector2 clampPoint]([param:Vector2 point], [param:Vector2 target])

  • [page:Vector2 point] — [page:Vector2 точка] для ограничения.
  • [page:Vector2 target] — результат будет скопирован в этот Vector2.

[link:https://en.wikipedia.org/wiki/Clamping_(graphics) Ограничивает] точку [page:Vector2 point] в границах рамки.

[method:Box2 clone]()

Возвращает новый [page:Box2] с теми же [page:.min min] и [page:.max max], что и данный.

[method:Boolean containsBox]([param:Box2 box])

[page:Box2 box] — [page:Box2 рамка] для проверки на включение.

Возвращает `true`, если текущая рамка включает в себя всю рамку [page:Box2 box]. Если текущая рамка и [page:Box2 box] идентичны, данная функция также возвращает `true`.

[method:Boolean containsPoint]([param:Vector2 point])

[page:Vector2 point] — [page:Vector2 точка] для проверки на включение.

Возвращает `true`, если указанная точка [page:Vector2 point] лежит внутри или на границах данной рамки.

[method:this copy]([param:Box2 box])

Копирует значения [page:.min min] и [page:.max max] из [page:Box2 box] в текущую рамку.

[method:Float distanceToPoint]([param:Vector2 point])

[page:Vector2 point] — [page:Vector2 точка] для измерения расстояния.

Возвращает расстояние от любого края текущей рамки до указанной точки. Если точка [page:Vector2 point] лежит внутри этой области, расстояние будет равно `0`.

[method:Boolean equals]([param:Box2 box])

[page:Box2 box] — рамка для сравнения с текущей.

Возвращает `true`, если у текущей рамки и [page:Box2 box] одинаковые нижняя и верхняя границы.

[method:this expandByPoint]([param:Vector2 point])

[page:Vector2 point] — [page:Vector2 точка], которая должна быть включена в рамку.

Расширяет границы этой области, включая [page:Vector2 point].

[method:this expandByScalar]([param:Float scalar])

[page:Float scalar] — расстояние, на которое нужно увеличить рамку.

Расширяет каждое измерение рамки на [page:Float scalar]. При отрицательном значении размеры ячейки сужаются.

[method:this expandByVector]([param:Vector2 vector])

[page:Vector2 vector] - [page:Vector2 вектор] для расширения рамки.

Производит равностороннее расширение рамки на [page:Vector2 vector]. Ширина текущей рамки будет увеличена на x-компонент [page:Vector2 vector] в обоих направлениях. Высота текущей рамки будет увеличена на y-компонент [page:Vector2 vector] в обоих направлениях.

[method:Vector2 getCenter]([param:Vector2 target])

[page:Vector2 target] — результат будет скопирован в этот Vector2.

Возвращает центральную точку рамки в виде [page:Vector2].

[method:Vector2 getParameter]([param:Vector2 point], [param:Vector2 target])

  • [page:Vector2 point] — [page:Vector2 точка].
  • [page:Vector2 target] — вектор для копирования результата.

Возвращает точку как пропорцию ширины и высоты текущей рамки.

[method:Vector2 getSize]([param:Vector2 target])

[page:Vector2 target] — результат будет скопирован в этот Vector2.

Возвращает ширину и высоту текущей рамки.

[method:this intersect]([param:Box2 box])

[page:Box2 box] — рамка для проверки пересечения.

Возвращает пересечение текущей рамки и [page:Box2 box], устанавливая верхнюю границу текущей рамки на меньшую из верхних границ двух рамок, а нижнюю границу текущей рамки на большую из нижних границ двух рамок.

[method:Boolean intersectsBox]([param:Box2 box])

[page:Box2 box] — рамка для проверки пересечения.

Определяет, пересекает ли данная рамка [page:Box2 box].

[method:Boolean isEmpty]()

Возвращает `true`, если рамка включает нулевые точки в своих границах. Обратите внимание, что квадрат с равными нижней и верхней границами все еще включает одну точку, общую для обеих границ.

[method:this makeEmpty]()

Делает текущую рамку пустым.

[method:this set]([param:Vector2 min], [param:Vector2 max])

  • [page:Vector2 min] — (требуется) [page:Vector2], представляющий нижнюю (x, y) границу рамки.
  • [page:Vector2 max] — (требуется) [page:Vector2], представляющий верхнюю (x, y) границу рамки.

Устанавливает нижнюю и верхнюю (x, y) границы текущей рамки. Обратите внимание, что этот метод только копирует значения из заданных объектов.

[method:this setFromCenterAndSize]([param:Vector2 center], [param:Vector2 size])

  • [page:Vector2 center] — желаемое положение центра рамки ([page:Vector2]).
  • [page:Vector2 size] — желаемые размеры x и y рамки ([page:Vector2]).

Центрирует текущую рамку по [page:Vector2 center] и устанавливает ширину и высоту текущей рамки значениям, указанным в [page:Vector2 size].

[method:this setFromPoints]([param:Array points])

[page:Array points] — массив [page:Vector2 векторов], который будет содержать итоговую рамку.

Устанавливает верхнюю и нижнюю границы текущей рамки, чтобы включить все точки из [page:Array points].

[method:this translate]([param:Vector2 offset])

[page:Vector2 offset] — направление и расстояние смещения.

Добавляет смещение [page:Vector2 offset] к верхней и нижней границам текущей рамки, эффективно перемещая текущую рамку на [page:Vector2 offset] единиц в 2Д-пространстве.

[method:this union]([param:Box2 box])

[page:Box2 box] — рамка, которая будет объединена с текущей рамкой.

Объединяет текущую рамку с [page:Box2 box], устанавливая верхнюю границу текущей рамки на большую из верхних границ двух рамок, а нижнюю границу текущей рамки на меньшую из нижних границ двух рамок.
