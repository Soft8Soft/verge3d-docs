[name]

Класс, представляющий четырехмерный вектор. Четырехмерный вектор — это упорядоченная четверка чисел (обозначенных x, y, z и w), которая может быть использована для представления ряда вещей, таких как:

  • Точка в четырехмерном пространстве.
  • Направление и длина в четырехмерном пространстве. В «Вердж3Д» длина равна Евклидову расстоянию (расстоянию по прямой) от `(0, 0, 0, 0)` до `(x, y, z, w)`. Направление также измеряется от `(0, 0, 0, 0)` до `(x, y, z, w)`.
  • Любая произвольная упорядоченная четверка чисел.

Перечисление [name] выдаёт его координаты `(x, y, z, w)` в том же порядке.

Пример

const a = new v3d.Vector4(0, 1, 0, 0); // в отсутствии аргументов станет (0, 0, 0, 0, 1) const b = new v3d.Vector4(); const d = a.dot(b);

Конструктор

[name]([param:Float x], [param:Float y], [param:Float z], [param:Float w])

  • [page:Float x] — значение x вектора. По умолчанию `0`.
  • [page:Float y] — значение y вектора. По умолчанию `0`.
  • [page:Float z] — значение z вектора. По умолчанию `0`.
  • [page:Float w] — значение w вектора. По умолчанию `1`.

Создает новый [name].

Свойства

[property:Boolean isVector4]

Флаг, указывающий, что данный объект является экземпляром [name]. Только для чтения.

[property:Float y]

Псевдоним для [page:.z z].

[property:Float height]

Псевдоним для [page:.w w].

Методы

[method:this add]([param:Vector4 v])

Добавляет [page:Vector4 v] к текущему вектору.

[method:this addScalar]([param:Float s])

Добавляет скалярное значение s к значениям [page:.x x], [page:.y y], [page:.z z] и [page:.w w] текущего вектора.

[method:this addScaledVector]([param:Vector4 v], [param:Float s])

Добавляет кратное [page:Vector4 v] и [page:Float s] к текущему вектору.

[method:this addVectors]([param:Vector4 a], [param:Vector4 b])

Устанавливает этот вектор в [page:Vector4 a] + [page:Vector4 b].

[method:this applyMatrix4]([param:Matrix4 m])

Умножает текущий вектор на 4x4 матрицу [page:Matrix4 m].

[method:this ceil]()

Округляет компоненты [page:.x x], [page:.y y], [page:.z z] и [page:.w w] текущего вектора вверх до ближайшего целого значения.

[method:this clamp]([param:Vector4 min], [param:Vector4 max])

  • [page:Vector4 min] — минимальные значения [page:.x x], [page:.y y], [page:.z z] и [page:.w w].
  • [page:Vector4 max] — максимальные значения [page:.x x], [page:.y y], [page:.z z] и [page:.w w].

Если значение x, y, z или w текущего вектора больше, чем значение x, y, z или w вектора max, оно заменяется соответствующим значением из max.

Если значение x, y, z или w текущего вектора меньше, чем значение x, y, z или w вектора min, оно заменяется соответствующим значением из min.

[method:this clampLength]([param:Float min], [param:Float max])

  • [page:Float min] — минимальное значение, до которого будет ограничиваться длина.
  • [page:Float max] — максимальное значение, до которого будет ограничиваться длина.

Если длина текущего вектора больше значения max, то она станет max. Если длина текущего вектора меньше минимального значения, она станет min.

[method:this clampScalar]([param:Float min], [param:Float max])

  • [page:Float min] — минимальное значение, до которого будут ограничиваться компоненты.
  • [page:Float max] — максимальное значение, на которое будут ограничиваться компоненты.

Если значения x, y, z или w текущего вектора больше максимального значения, они заменяются максимальным значением. Если значения x, y, z или w текущего вектора меньше минимального значения, они заменяются минимальным значением.

[method:Vector4 clone]()

Возвращает новый вектор с теми же значениями [page:.x x], [page:.y y], [page:.z z] и [page:.w w], что и текущий.

[method:this copy]([param:Vector4 v])

Копирует значения свойств [page:.x x], [page:.y y], [page:.z z] и [page:.w w] из указанного вектора в текущий.

[method:this divideScalar]([param:Float s])

Делит текущий вектор на скаляр [page:Float s].

[method:Float dot]([param:Vector4 v])

Вычисляет скалярное произведение данного вектора и [page:Vector4 v].

[method:Boolean equals]([param:Vector4 v])

Проверяет строгое равенство данного вектора и [page:Vector4 v].

[method:this floor]()

Компоненты текущего вектора округляются вниз до ближайшего целого значения.

[method:this fromArray]([param:Array array], [param:Integer offset])

  • [page:Array array] — исходный массив.
  • [page:Integer offset] — (необ.) смещение в массиве. По умолчанию равно `0`.

Устанавливает значение [page:.x x] текущего вектора в `array[offset]`, [page:.y y] в `array[offset + 1]`, [page:.z z] в `array[offset + 2]` и [page:.w w] в `array[offset + 3]`.

[method:this fromBufferAttribute]([param:BufferAttribute attribute], [param:Integer index])

  • [page:BufferAttribute attribute] — атрибут источника.
  • [page:Integer index] — индекс в атрибуте.

Устанавливает значения [page:.x x], [page:.y y], [page:.z z] и [page:.w w] текущего вектора из указанного [page:BufferAttribute атрибута].

[method:Float getComponent]([param:Integer index])

[page:Integer index] — `0`, `1`, `2` или `3`.

Если индекс равен 0, возвращается значение [page:.x x].
Если индекс равен 1, возвращается значение [page:.y y].
Если индекс равен 2, возвращается значение [page:.z z].
Если индекс равен 3, возвращается значение [page:.w w].

[method:Float length]()

Вычисляет Евклидову длину вектора (длину прямой линии) от `(0, 0, 0, 0, 0)` до `(x, y, z, w)`.

[method:Float manhattanLength]()

Вычисляет расстояние городских кварталов для текущего вектора.

[method:Float lengthSq]()

Вычисляет квадрат Евклидовой длины (длины прямой) от `(0, 0, 0, 0, 0)` до `(x, y, z, w)`. Если вы сравниваете длины векторов, следует сравнивать квадрат длины, так как он вычисляется немного эффективнее.

[method:this lerp]([param:Vector4 v], [param:Float alpha])

  • [page:Vector4 v] — [page:Vector4] для интерполяции.
  • [page:Float alpha] — коэффициент интерполяции, обычно из замкнутого интервала `[0, 1]`.

Линейно интерполирует между текущим вектором и [page:Vector4 v], где alpha - процентное расстояние вдоль линии. В частности, если `alpha = 0`, назначается текущий вектор, а если `alpha = 1` будет назначен [page:Vector4 v].

[method:this lerpVectors]([param:Vector4 v1], [param:Vector4 v2], [param:Float alpha])

  • [page:Vector4 v1] — начальный [page:Vector4].
  • [page:Vector4 v2] — конечный [page:Vector4].
  • [page:Float alpha] — коэффициент интерполяции, обычно в замкнутом интервале `[0, 1]`.

Устанавливает текущий вектор как вектор, линейно интерполированный между [page:Vector4 v1] и [page:Vector4 v2], где alpha - процентное расстояние вдоль линии, соединяющей два вектора. В частности, если `alpha = 0` будет назначен [page:Vector4 v1], а если `alpha = 1` будет назначен [page:Vector4 v2].

[method:this negate]()

Инвертирует текущий вектор — то есть устанавливает `x = -x`, `y = -y`, `z = -z` и `w = -w`.

[method:this normalize]()

Преобразует текущий вектор в единичный вектор — то есть устанавливает его равным вектору с тем же направлением, что и исходный, но [page:.length с длиной] равной 1.

[method:this max]([param:Vector4 v])

Если значение x, y, z или w текущего вектора меньше, чем значение x, y, z или w [page:Vector4 v], заменяет это значение соответствующим значением max.

[method:this min]([param:Vector4 v])

Если значение x, y, z или w текущего вектора больше, чем значение x, y, z или w [page:Vector4 v], заменяет это значение соответствующим значением min.

[method:this multiply]([param:Vector4 v])

Умножает текущий вектор на [page:Vector4 v].

[method:this multiplyScalar]([param:Float s])

Умножает текущий вектор на скаляр [page:Float s].

[method:this round]()

Округляет компоненты текущего вектора до ближайшего целого значения.

[method:this roundToZero]()

Компоненты текущего вектора округляются в сторону нуля (вверх, если отрицательные, вниз, если положительные) до целого значения.

[method:this set]([param:Float x], [param:Float y], [param:Float z], [param:Float w])

Задает компоненты [page:.x x], [page:.y y], [page:.z z] и [page:.w w] текущего вектора.

[method:this setAxisAngleFromQuaternion]([param:Quaterion q])

[page:Quaterion q] — нормализованный [page:Quaternion кватернион].

Устанавливает компоненты [page:.x x], [page:.y y] и [page:.z z] текущего вектора в ось кватерниона, а [page:.w w] — на его угол.

[method:this setAxisAngleFromRotationMatrix]([param:Matrix4 m])

[page:Matrix4 m] — [page:Matrix4], левая верхняя матрица 3x3 которой является чистой матрицей вращения.

Задает [page:.x x], [page:.y y] и [page:.z z] в ось вращения, а [page:.w w] — в угол.

[method:this setComponent]([param:Integer index], [param:Float value])

  • [page:Integer index] — `0`, `1` или `2`.
  • [page:Float value] — [page:Float].

Если индекс равен 0, устанавливает [page:.x x] в [page:Float value].
Если индекс равен 1, устанавливает [page:.y y] в [page:Float value].
Если индекс равен 2, устанавливает [page:.z z] в [page:Float value].
Если индекс равен 3, устанавливает [page:.w w] в [page:Float value].

[method:this setLength]([param:Float l])

Устанавливает текущий вектор в вектор с тем же направлением, что и исходный, но [page:.length с длиной] равной [page:Float l].

[method:this setScalar]([param:Float scalar])

Устанавливает значения [page:.x x], [page:.y y], [page:.z z] и [page:.w w] текущего вектора равными [page:Float scalar].

[method:this setX]([param:Float x])

Заменяет значение [page:.x x] текущего вектора на [page:Float x].

[method:this setY]([param:Float y])

Заменяет значение [page:.y y] текущего вектора на [page:Float y].

[method:this setZ]([param:Float z])

Заменяет значение [page:.z z] текущего вектора на [page:Float z].

[method:this setW]([param:Float w])

Заменяет значение [page:.w w] текущего вектора на [page:Float w].

[method:this sub]([param:Vector4 v])

Вычитает [page:Vector4 v] из данного вектора.

[method:this subScalar]([param:Float s])

Вычитает [page:Float s] из компонент [page:.x x], [page:.y y], [page:.z z] и [page:.w w] данного вектора.

[method:this subVectors]([param:Vector4 a], [param:Vector4 b])

Устанавливает текущий вектор в [page:Vector4 a] - [page:Vector4 b].

[method:Array toArray]([param:Array array], [param:Integer offset])

  • [page:Array array] — (необ.) массив для хранения вектора. Если он не указан, будет создан новый массив.
  • [page:Integer offset] — (необ.) смещение в массиве.

Возвращает массив [x, y, z, w], или копирует x, y, z и w в предоставленный [page:Array массив].

[method:this random]()

Устанавливает каждый компонент текущего вектора в псевдослучайное значение между `0` и `1`, исключая `1`.
