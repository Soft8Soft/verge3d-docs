[page:Texture] →

[name]

Создает кубическую текстуру, состоящую из шести изображений.

Пример

const loader = new v3d.CubeTextureLoader(); loader.setPath('textures/'); const textureCube = loader.load([ 'px.png', 'nx.png', 'py.png', 'ny.png', 'pz.png', 'nz.png' ]); const material = new v3d.MeshBasicMaterial({ color: 0xffffff, envMap: textureCube });

Конструктор

[name]([param:Array images], [param:Constant mapping], [param:Constant wrapS], [param:Constant wrapT], [param:Constant magFilter], [param:Constant minFilter], [param:Constant format], [param:Constant type], [param:Integer anisotropy], [param:Constant encoding])

CubeTexture почти эквивалентен по функциональности и использованию [page:Texture]. Единственные различия заключаются в том, что изображения представляют собой массив из 6 изображений, а не одно изображение, а типом маппинга является [page:Textures v3d.CubeReflectionMapping].

Свойства

Общие свойства смотрите в базовом классе [page:Texture Texture].

[property:Boolean flipY]

Если установлено значение `true`, текстура переворачивается вдоль вертикальной оси при загрузке на GPU. По умолчанию `false`.

[property:Boolean isCubeTexture]

Указывает, что объект является экземпляром класса [name]. Только для чтения.
