[page:Texture] →

[name]

Этот класс может использоваться только в сочетании с методом [page:WebGLRenderer.copyFramebufferToTexture]().

Конструктор

[name]([param:Integer width], [param:Integer height], [param:Constant format])

  • [page:Integer width] — ширина текстуры.
  • [page:Integer height] — высота текстуры.
  • [page:Constant format] — формат текстуры. Смотрите раздел [page:Textures константы формата] для получения подробной информации.

Свойства

Смотрите свойства базового класса [page:Texture Texture].

[property:Boolean isFramebufferTexture]

Указывает, что данный объект является экземпляром класса [name]. Только для чтения.

[property:Boolean needsUpdate]

По умолчанию `true`. Требуется чтобы данные текстуры были загружены.
