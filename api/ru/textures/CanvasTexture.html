[page:Texture] →

[name]

Создает текстуру из элемента `<canvas>`.

Данный класс похож на базовый [page:Texture Texture], за исключением того, что он сразу устанавливает [page:Texture.needsUpdate needsUpdate] в `true`.

Конструктор

[name]([param:HTMLElement canvas], [param:Constant mapping], [param:Constant wrapS], [param:Constant wrapT], [param:Constant magFilter], [param:Constant minFilter], [param:Constant format], [param:Constant type], [param:Integer anisotropy])

  • [page:HTMLElement canvas] — элемент HTML canvas, из которого загружается текстура.
  • [page:Constant mapping] — способ нанесения изображения на объект. Тип объекта [page:Textures v3d.UVMapping]. См. [page:Textures режимы маппинга] для других вариантов.
  • [page:Constant wrapS] — по умолчанию [page:Textures v3d.ClampToEdgeWrapping]. См. [page:Textures режимы развёрток] для других вариантов.
  • [page:Constant wrapT] — по умолчанию [page:Textures v3d.ClampToEdgeWrapping]. См. [page:Textures режимы развёрток] для других вариантов.
  • [page:Constant magFilter] — способ дискретизации текстуры, когда тексель занимает более одного пикселя. По умолчанию [page:Textures v3d.LinearFilter]. См. [page:Textures фильтры увеличения] для других вариантов.
  • [page:Constant minFilter] — способ дискретизации текстуры, когда тексель занимает менее одного пикселя. По умолчанию [page:Textures v3d.LinearMipmapLinearFilter]. См. [page:Textures фильтры уменьшения] для других вариантов.
  • [page:Constant format] — формат, используемый в текстуре. См. [page:Textures форматы текстур] для других вариантов.
  • [page:Constant type] — по умолчанию [page:Textures v3d.UnsignedByteType]. См. [page:Textures типы текстур] для других вариантов.
  • [page:Integer anisotropy] — количество семплов, взятых вдоль оси, проходящей через пиксель, имеющий наибольшую плотность текселей. По умолчанию это значение равно `1`. Большее значение дает менее размытый результат, чем базовый мипмап, ценой использования большего количества сэмплов текстуры. Используйте [page:WebGLRenderer.getMaxAnisotropy renderer.getMaxAnisotropy](), чтобы найти максимальное допустимое значение анизотропии для GPU; обычно это значение равно 2.

Свойства

Общие свойства см. в базовом классе [page:Texture Texture].

[property:Boolean isCanvasTexture]

Указывает, что объект является экземпляром класса [name]. Только для чтения.

[property:Boolean needsUpdate]

True по умолчанию. Это необходимо для того, чтобы данные canvas были загружены.

Методы

Общие методы см. в базовом классе [page:Texture Texture].

Пазлы

Используйте пазлы create canvas elem и replace texture, чтобы создавать и управлять текстурами холста без программирования.
