[name]

Создает текстуру на основе данных в сжатом виде, например, из файла [link:https://www.khronos.org/ktx/ KTX].

Для использования с [page:CompressedTextureLoader CompressedTextureLoader].

Конструктор

[name]([param:Array mipmaps], [param:Integer width], [param:Integer height], [param:Constant format], [param:Constant type], [param:Constant mapping], [param:Constant wrapS], [param:Constant wrapT], [param:Constant magFilter], [param:Constant minFilter], [param:Integer anisotropy], [param:Constant encoding])

  • [page:Array mipmaps] — массив mipmaps должен содержать объекты с данными, шириной и высотой. Мипмапы должны иметь правильный формат и тип.
  • [page:Integer width] — ширина самого большого мипмапа.
  • [page:Integer height] — высота самого большого мипмапа.
  • [page:Constant format] — формат, используемый в мипмапах. Варианты см. [page:Textures ST3C Compressed Texture Formats], [page:Textures PVRTC Compressed Texture Formats] и [page:Textures ETC Compressed Texture Format].
  • [page:Constant type] — по умолчанию [page:Textures v3d.UnsignedByteType]. См. [page:Textures type constants] для других вариантов.
  • [page:Constant mapping] — способ нанесения изображения на объект. Тип объекта [page:Textures v3d.UVMapping]. См. [page:Textures mapping constants] для других вариантов.
  • [page:Constant wrapS] — по умолчанию [page:Textures v3d.ClampToEdgeWrapping]. См. раздел [page:Textures текстурные константы] с описанием вариантов.
  • [page:Constant wrapT] — по умолчанию [page:Textures v3d.ClampToEdgeWrapping]. См. раздел [page:Textures текстурные константы] с описанием других вариантов.
  • [page:Constant magFilter] — как сэмплируется текстура, если тексель занимает более одного пикселя. По умолчанию [page:Textures v3d.LinearFilter]. См. раздел [page:Textures текстурные константы] для других вариантов.
  • [page:Constant minFilter] — как сэмплируется текстура, если тексель занимает менее одного пикселя. По умолчанию [page:Textures v3d.LinearMipmapLinearFilter]. См. [page:Textures minification filter constants] для других вариантов.
  • [page:Integer anisotropy] — количество семплов, взятых вдоль оси, проходящей через пиксель, имеющий наибольшую плотность текселей. По умолчанию это значение равно 1. Большее значение дает менее размытый результат, чем базовый мипмап, ценой использования большего количества сэмплов текстуры. Используйте renderer.getMaxAnisotropy(), чтобы найти максимальное допустимое значение анизотропии для GPU; это значение обычно равно 2.

Свойства

Унаследованные свойства см. в базовом классе [page:Texture Texture].

[property:Boolean flipY]

False по умолчанию. Переворачивание текстур не работает для сжатых текстур.

[property:Boolean generateMipmaps]

False по умолчанию. Мипмапы не могут быть сгенерированы для сжатых текстур.
