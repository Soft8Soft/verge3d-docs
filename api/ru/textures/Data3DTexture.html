[page:Texture] →

[name]

Создаёт трёхмерную текстуру. Может использоваться только с контекстом рендеринга WebGL 2.

Конструктор

[name]([param:TypedArray data], [param:Integer width], [param:Integer height], [param:Integer depth])

  • [page:Object data] — данные текстуры.
  • [page:Integer width] — ширина текстуры.
  • [page:Integer height] — высота текстуры.
  • [page:Integer depth] — глубина текстуры.

Свойства

Смотрите общие свойства в базовом классе [page:Texture Texture].

[property:Constant wrapR]

Определяет, как заворачивается текстура в направлении глубины.

По умолчанию используется [page:Textures v3d.ClampToEdgeWrapping], для которого пиксели края ограничиваются внешними пикселями. Другие варианты: [page:Textures v3d.RepeatWrapping] и [page:Textures v3d.MirroredRepeatWrapping]. Смотрите раздел [page:Textures текстурные константы] для получения дополнительной информации.
