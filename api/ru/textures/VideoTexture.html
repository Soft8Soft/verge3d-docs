[page:Texture] →

[name]

Создает текстуру для использования с видео.

После первого использования текстуры, её видео не может быть изменено. Вместо этого вызовите [page:.dispose]() на старой текстуре и создайте новую.

Пример

// предполагается что элемент видео был создан с id="video" const video = document.getElementById('video'); const texture = new v3d.VideoTexture(video);

Конструктор

[name]([param:HTMLVideoElement video], [param:Constant mapping], [param:Constant wrapS], [param:Constant wrapT], [param:Constant magFilter], [param:Constant minFilter], [param:Constant format], [param:Constant type], [param:Integer anisotropy])

  • [page:Video video] — элемент видео, который будет использоваться в качестве текстуры.
  • [page:Constant mapping] — как изображение наносится на объект. Тип объекта [page:Textures v3d.UVMapping]. См. [page:Textures режимы маппинга] для других вариантов.
  • [page:Constant wrapS] — по умолчанию [page:Textures v3d.ClampToEdgeWrapping]. См. [page:Textures режимы развёртки] для других вариантов.
  • [page:Constant wrapT] — по умолчанию [page:Textures v3d.ClampToEdgeWrapping]. См. [page:Textures режимы развёртки] для других вариантов.
  • [page:Constant magFilter] — способ дискретизации текстуры, когда тексель занимает более одного пикселя. По умолчанию [page:Textures v3d.LinearFilter]. См. [page:Textures фильтры увеличения] для других вариантов.
  • [page:Constant minFilter] — способ дискретизации текстуры, когда тексель занимает менее одного пикселя. По умолчанию [page:Textures v3d.LinearMipmapLinearFilter]. См. [page:Textures фильтры уменьшения] для других вариантов.
  • [page:Constant format] — формат, используемый в текстуре. См. [page:Textures форматы текстур] для других вариантов.
  • [page:Constant type] — по умолчанию [page:Textures v3d.UnsignedByteType]. См. [page:Textures типы текстур] для других вариантов.
  • [page:Integer anisotropy] — количество образцов, взятых вдоль оси, проходящей через пиксель, имеющий наибольшую плотность текселей. По умолчанию это значение равно `1`. Большее значение дает менее размытый результат, чем базовый мипмап, за счет использования большего количества образцов текстуры. Используйте [page:WebGLRenderer.getMaxAnisotropy renderer.getMaxAnisotropy](), чтобы найти максимальное допустимое значение анизотропии для GPU; это значение обычно равно степени 2.

Свойства

См. базовый класс [page:Texture Texture] для общих свойств.

[property:Boolean generateMipmaps]

Нужно ли генерировать мипмапы. По умолчанию `false`.

[property:Boolean isVideoTexture]

Указывает, что объект является экземпляром класса [name]. Только для чтения.

[property:Boolean needsUpdate]

Не нужно устанавливать этот параметр вручную, так как он обрабатывается методом [page:VideoTexture.update update update].

Методы

См. базовый класс [page:Texture Texture] для общих методов.

[method:undefined update]()

Вызывается автоматически и устанавливает [property:Boolean needsUpdate] в значение `true` каждый раз, когда когда доступен новый кадр.

Пазлы

Используйте пазлы load video и replace texture чтобы управлять видео-текстурами без необходимости писать код.
