[name]

Класс источника для текстур.

Конструктор

[name]([param:Any data])

[page:Any data] — данные для определения текстуры. По умолчанию `null`.

Свойства

[property:Any data]

Данные текстуры. Тип данных зависит от текстуры, использующей данный источник.

[property:Boolean needsUpdate]

Установите в `true`, чтобы начать передачу данных текстуры в память GPU при следующем использовании источника.

[property:String uuid]

[link:https://ru.wikipedia.org/wiki/UUID Уникальный идентификатор] экземпляра источника. Назначается автоматически.

[property:Integer version]

Версия источника. Первоначально установлена в `0` и увеличивается каждый раз при установке [page:Source.needsUpdate .needsUpdate] в `true`.
