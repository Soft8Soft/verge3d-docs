[name]

Здесь содержатся методы для настройки [link:https://developer.mozilla.org/ru/docs/Web/API/AudioContext AudioContext].

Используется внутри классов [page:AudioListener AudioListener] и [page:AudioLoader AudioLoader].

Использует [link:https://developer.mozilla.org/ru/docs/Web/API/Web_Audio_API Web Audio API].

Методы

[method:AudioContext getContext]()

Возвращает значение переменной `context` во внешней области видимости, если она определена, иначе устанавливает её в новый [link:https://developer.mozilla.org/ru/docs/Web/API/AudioContext AudioContext].

[method:undefined setContext]([param:AudioContext value])

Устанавливает переменную `context` во внешней области видимости в значение `value`.

Пазлы

«Вердж3Д» поддерживает ряд пазлов аудио, упрощающих работу со звуками и музыкой.
