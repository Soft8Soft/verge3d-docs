[name]

Создаёт непозиционный (глобальный) аудиообъект.

Для этого используется [link:https://developer.mozilla.org/ru/docs/Web/API/Web_Audio_API Web Audio API].

Пример

// создаём AudioListener и привязываем его к камере const listener = new v3d.AudioListener(); app.camera.add(listener); // создаём глобальный источник аудио const sound = new v3d.Audio(listener); // загружаем звук const audioLoader = new v3d.AudioLoader(); audioLoader.load('mysound.mp3', function(buffer) { sound.setBuffer(buffer); sound.setLoop(true); sound.setVolume(0.5); sound.play(); });

Конструктор

[name]([param:AudioListener listener])

listener — (обязательный) экземпляр слушателя [page:AudioListener AudioListener].

Свойства

[property:Boolean autoplay]

Должно ли воспроизведение начинаться автоматически. По умолчанию `false`.

[property:AudioContext context]

[link:https://developer.mozilla.org/ru/docs/Web/API/AudioContext AudioContext] [page:AudioListener слушателя], заданного в конструкторе.

[property:Integer detune]

Изменение высоты тона, измеряется в центах. +/- 100 - это полутон. +/- 1200 - октава. По умолчанию `0`.

[property:Array filters]

Представляет собой массив [link:https://developer.mozilla.org/en-US/docs/Web/API/BiquadFilterNode BiquadFilterNodes]. Может использоваться для применения различных фильтров низжего порядка для создания более сложных звуковых эффектов. Фильтры устанавливаются через [page:Audio.setFilter] или [page:Audio.setFilters].

[property:GainNode gain]

Узел [link:https://developer.mozilla.org/en-US/docs/Web/API/GainNode GainNode], созданный с помощью [link:https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/createGain AudioContext.createGain]().

[property:Boolean hasPlaybackControl]

Можно ли управлять воспроизведением с помощью методов [page:Audio.play play](), [page:Audio.pause pause]() и т.д.. По умолчанию `true`.

[property:Boolean isPlaying]

Воспроизводится ли аудио в данный момент.

[property:AudioListener listener]

Ссылка на объект-слушатель.

[property:Float playbackRate]

Скорость воспроизведения. По умолчанию `1`.

[property:Float offset]

Смещение до времени в аудиобуфере, когда должно начаться воспроизведение. Аналогично параметру `offset` в [link:https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/start AudioBufferSourceNode.start](). По умолчанию `0`.

[property:Float duration]

Переопределяет длительность аудио. Аналогично параметру `duration` в [link:https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/start AudioBufferSourceNode.start](). По умолчанию `undefined` для воспроизведения всего буфера.

[property:String source]

Нода [link:https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode AudioBufferSourceNode], созданная с помощью [link:https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/createBufferSource AudioContext.createBufferSource]().

[property:String sourceType]

Тип источника звука. По умолчанию строка `"empty"`.

[property:String type]

Строка, обозначающая тип объекта. Всегда `"Audio"`.

Методы

[method:this connect]()

Подключить к [page:Audio.source]. Внутренний метод, используется при инициализации и при установке/удалении фильтров.

[method:this disconnect]()

Отключить от [page:Audio.source]. Внутренний метод, используется при установке/удалении фильтров.

[method:Float getDetune]()

Возвращает коэффициент изменения высоты тона (в центах).

[method:BiquadFilterNode getFilter]()

Возвращает первый элемент массива [page:Audio.filters filters].

[method:Array getFilters]()

Возвращает массив [page:Audio.filters filters].

[method:Boolean getLoop]()

Возвращает значение параметра [link:https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/loop source.loop] (должно ли воспроизведение зацикливаться).

[method:GainNode getOutput]()

Возвращает [page:Audio.gain gainNode].

[method:Float getPlaybackRate]()

Возвращает значение параметра [page:Audio.playbackRate playbackRate].

[method:Float getVolume](value)

Возвращает текущую громкость.

[method:this play](delay)

Если [page:Audio.hasPlaybackControl hasPlaybackControl] равно true, начинает воспроизведение.

[method:this pause]()

Если [page:Audio.hasPlaybackControl hasPlaybackControl] равно true, приостанавливает воспроизведение.

[method:undefined onEnded]()

Вызывается автоматически по окончании воспроизведения.

[method:this setBuffer](audioBuffer)

Устанавливает audioBuffer в [page:Audio.source source], и `"buffer"` в [page:Audio.sourceType sourceType]. Если [page:Audio.autoplay autoplay] установлен, также запускает воспроизведение.

[method:Float getDetune]()

Устанавливает коэффициент изменения высоты тона (в центах).

[method:this setFilter](filter)

Применяет один фильтр к аудио.

[method:this setFilters]([param:Array value])

value — массивы фильтров.

Применяет массив фильтров к аудио.

[method:this setLoop]([param:Boolean value])

Устанавливает [link:https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/loop source.loop] в `value` (должно ли воспроизведение зацикливаться).

[method:this setLoopStart]([param:Float value])

Устанавливает [link:https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/loopStart source.loopStart] в `value`.

[method:this setLoopEnd]([param:Float value])

Устанавливает [link:https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/loopEnd source.loopEnd] в `value`.

[method:this setMediaElementSource](mediaElement)

Применяет данный объект типа [link:https://developer.mozilla.org/ru/docs/Web/API/HTMLMediaElement HTMLMediaElement] в качестве источника аудио. Также устанавливает [page:Audio.hasPlaybackControl hasPlaybackControl] в false.

[method:this setMediaStreamSource](mediaStream)

Применяет данный объект типа [link:https://developer.mozilla.org/ru/docs/Web/API/MediaStream MediaStream] в качестве источника данного аудио. Также устанавливает [page:Audio.hasPlaybackControl hasPlaybackControl] в false.

[method:this setNodeSource](audioNode)

Устанавливает [page:Audio.source source] в audioBuffer и устанавливает [page:Audio.sourceType sourceType] в `"audioNode"`. Также устанавливает [page:Audio.hasPlaybackControl hasPlaybackControl] в false.

[method:this setPlaybackRate]([param:Float value])

Если [page:Audio.hasPlaybackControl hasPlaybackControl] включен, устанавливает [page:Audio.playbackRate playbackRate] в `value`.

[method:this setVolume]([param:Float value])

Устанавливает уровень громкости.

[method:this stop]()

Если [page:Audio.hasPlaybackControl hasPlaybackControl] включен, останавливает воспроизведение.

Пазлы

«Вердж3Д» поддерживает ряд пазлов аудио, упрощающих работу со звуками и музыкой.
