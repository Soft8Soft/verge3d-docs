[name]

Класс с утилитами для работы с экземплярами [page:BufferGeometry BufferGeometry].

Методы

[method:undefined batchMeshes]([param:Array meshObjs], [param:Object3D batchParent])

  • [page:Array meshObjs] — массив объединяемых [page:Mesh мешей].
  • [page:Object3D batchParent] — контейнер (родительский объект) для сохранения сгруппированного меша.

Объединяет меши вместе. Эта техника используется для сокращения количества вызовов отрисовки WebGL, что способствует увеличению производительности.

Группировка производится среди мешей, для которых совпадают значения свойств:

  • `material.name`
  • `visible`
  • `disableChildRendering`
  • `castShadow`
  • `receiveShadow`
  • `renderOrder`
  • `groupNames`
  • `geometry.attributes` (keys only)
  • `geometry.morphAttributes` (keys only)

[method:Object computeMorphedAttributes]([param:Mesh|Line|Points object])

object — экземпляр [page:Mesh Mesh], [page:Line Line], [page:Points Points].

Возвращает атрибуты (позицию и нормаль) с применённым морфингом/скиннингом и исходные. Возвращаемый объект содержит 4 свойства: `positionAttribute`, `normalAttribute`, `morphedPositionAttribute` и `morphedNormalAttribute`. Метод используется для трассировки лучей и рендеринга декалей.

[method:BufferAttribute deepCloneAttribute]([param:BufferAttribute attribute])

attribute — экземпляр [page:BufferAttribute BufferAttribute] для копирования в глубину.

Возвращает клон атрибута, полученного с использованием глубокого копирования.

[method:Float estimateBytesUsed]([param:BufferGeometry geometry])

geometry — экземпляр [page:BufferGeometry BufferGeometry] для анализа потребления памяти.

Возвращает количество байт, используемых всеми атрибутами в указанной геометрии.

[method:BufferAttribute mergeBufferAttributes]([param:Array attributes])

attributes — массив экземпляров [page:BufferAttribute BufferAttribute].

Объединяет массив атрибутов в один атрибут. Все подданные атрибуты должны иметь одинаковые свойства и типы. Если объединение невозможно, метод возвращает `null`.

[method:BufferGeometry mergeBufferGeometries]([param:Array geometries], [param:Boolean useGroups])

  • geometries — массив экземпляров [page:BufferGeometry BufferGeometry].
  • useGroups — нужно ли создавать группы в объединённой геометрии или нет.

Объединяет массив геометрий в одну геометрию. Все подданные геометрии должны иметь одинаковые свойства и типы. Если объединение невозможно, метод возвращает `null`.

[method:BufferGeometry mergeGroups]([param:BufferGeometry geometry])

geometry — экземпляр [page:BufferGeometry BufferGeometry] для объединения групп.

Объединяет [page:BufferGeometry.groups группы] внутри данной геометрии.

[method:BufferGeometry mergeVertices]([param:BufferGeometry geometry], [param:Float tolerance])

  • geometry — экземпляр [page:BufferGeometry BufferGeometry] для объединения вертексов.
  • tolerance — максимально возможная разница между вертексными атрибутами. По умолчанию `1e-4`.

Возвращает новый [page:BufferGeometry BufferGeometry] с объединёнными вертексами. Объединение вертексов происходит, если значения их атрибутов примерно одинаковы (в пределах указанной разницы).

[method:BufferGeometry toCreasedNormals]([param:BufferGeometry geometry], [param:Float creaseAngle])

  • geometry — входная геометрия.
  • creaseAngle — угол сгиба.

Создаёт новую неиндексированную геометрию со сглаженными нормалями. Сглаживание производится для всех граней, угол между которыми меньше указанного угла сгиба.

[method:BufferGeometry toTrianglesDrawMode]([param:BufferGeometry geometry], [param:TrianglesDrawMode drawMode])

  • geometry — экземпляр [page:BufferGeometry BufferGeometry].
  • drawMode — режим отрисовки геометрии. Допустимые значения: `v3d.TriangleStripDrawMode` и `v3d.TriangleFanDrawMode`.

Возвращает новую индексированную геометрию с режимом отрисовки `v3d.TrianglesDrawMode`. Этот режим отрисовки соответствует WeBGL-примитивам типа `gl.TRIANGLES`.
