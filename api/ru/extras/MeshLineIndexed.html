[name]

Специальный меш, содержащий геометрию для рисования линий. Предназначен для использования с материалом [page:MeshLineMaterial]. Может создавать геометрию из [page:BufferGeometry]. Для данных [page:Array]/[page:TypedArray Float32Array] используйте [page:MeshLine].

Конструктор

[name]()

Конструктор не принимает на вход никаких аргументов.

Свойства

[property:BufferGeometry geometry]

Геометрия линии для передачи в конструктор [page:Mesh]. Создается после вызова метода [page:.fromBufferGeometry fromBufferGeometry].

Методы

[method:undefined fromBufferGeometry]([param:BufferGeometry geometry])

Строит геометрию линии на основе данных из [page:BufferGeometry].
