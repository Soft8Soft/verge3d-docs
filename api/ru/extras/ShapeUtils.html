[name]

Класс, содержащий полезные функции для рисования фигур.

Обратите внимание, что все они являются линейными функциями, поэтому их необходимо вычислять отдельно для x, y (и z, w, если есть) компонентов вектора.

Методы

[method:Float area]([param:Array contour])

contour — двумерный полигон. Массив [page:Vector2 двумерных векторов].

Вычисляет площадь (2Д) контурного многоугольника.

[method:Boolean isClockWise]([param:Array pts])

pts — точки, определяющие двумерный полигон.

Обратите внимание, что это линейная функция, поэтому её необходимо вычислять отдельно для x, y компонентов полигона.

Используется внутри [page:Path Path], [page:ExtrudeGeometry ExtrudeGeometry] и [page:ShapeGeometry ShapeGeometry].

[method:Array triangulateShape]([param:Array contour], [param:Array holes])

  • contour — 2Д-полигон.
  • holes — массив отверстий.

Используется внутри [page:ExtrudeGeometry ExtrudeGeometry] и [page:ShapeGeometry ShapeGeometry] для вычисления граней в фигурах с отверстиями.
