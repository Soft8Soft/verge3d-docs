[name]

Базовый класс для прелоадеров.

Конструктор

[name]()

Ничего не делает, должен быть переопределён в дочернем классе.

Методы

[method:undefined onFinish]()

Функция обратного вызова, вызываемая, когда прелоадер завершает работу.

[method:undefined onUpdate]([page:Float percentage])

Функция обратного вызова, которая постоянно вызывается во время загрузки сцены. Параметр процента варьируется от `0` (0%) до `1` (100%).

Исходный файл

Исходный файл данного класса свободно доступен по следующему пути ``src/extras/Preloader.js`` внутри установочной папки «Вердж3Д».

Смотрите также

«Вердж3Д» включает встроенный прелоадер с лого и индикатором прогресса в виде полосы. Смотрите класс [page:SimplePreloader] для получения подробной информации.
