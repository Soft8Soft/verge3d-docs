[name]

Класс, содержащий служебные функции для преобразования данных.

Методы

[method:Integer toHalfFloat]([param:Float val])

val — значения с плавающей запятой одинарной точности.

Преобразует значение с плавающей запятой одинарной точности в значение с плавающей запятой половинной точности (представленное в виде целочисленного 16-битного значения).

[method:Float fromHalfFloat]([param:Integer val])

val — значение с плавающей запятой половинной точности.

Преобразует значение с плавающей запятой половинной точности (представленное в виде целочисленного 16-битного значения) в значение с плавающей запятой одинарной точности.
