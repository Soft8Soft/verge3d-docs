[name]

Двумерное представление пути. Класс предоставляет методы для создания путей и контуров двумерных фигур, аналогичные API 2D Canvas.

Пример

const path = new v3d.Path(); path.lineTo(0, 0.8); path.quadraticCurveTo(0, 1, 0.2, 1); path.lineTo(1, 1); const points = path.getPoints(); const geometry = new v3d.BufferGeometry().setFromPoints(points); const material = new v3d.LineBasicMaterial({ color: 0xffffff }); const line = new v3d.Line(geometry, material); app.scene.add(line);

Конструктор

[name]([param:Array points])

points — (необ.) массив [page:Vector2 Vector2].

Создает контур из точек. Первая точка определяет смещение, затем последующие точки добавляются в массив [page:CurvePath.curves curves] как [page:LineCurve LineCurves].

Если точки не указаны, создается пустой контур, а [page:.currentPoint] устанавливается в начало координат.

Свойства

Общие свойства смотрите в базовом классе [page:CurvePath].

[property:Array currentPoint]

Текущее смещение контура. Любая новая добавленная [page:Curve] будет начинаться здесь.

Методы

Общие методы смотрите в базовом классе [page:CurvePath].

[method:this absarc]([param:Float x], [param:Float y], [param:Float radius], [param:Float startAngle], [param:Float endAngle], [param:Boolean clockwise])

  • x, y — абсолютный центр дуги.
  • radius — радиус дуги.
  • startAngle — начальный угол в радианах.
  • endAngle — конечный угол в радианах.
  • clockwise — развернуть дугу по часовой стрелке. По умолчанию `false`.

Добавляет абсолютно позиционированную [page:EllipseCurve EllipseCurve] к пути.

[method:this absellipse]([param:Float x], [param:Float y], [param:Float xRadius], [param:Float yRadius], [param:Float startAngle], [param:Float endAngle], [param:Boolean clockwise], [param:Float rotation])

  • x, y — абсолютный центр эллипса.
  • xRadius — радиус эллипса по оси x.
  • yRadius — радиус эллипса по оси y.
  • startAngle — начальный угол в радианах.
  • endAngle — конечный угол в радианах.
  • clockwise — развернуть эллипс по часовой стрелке. По умолчанию имеет значение `false`.
  • rotation — угол поворота эллипса в радианах, против часовой стрелки от положительной оси X. Необязателен, по умолчанию равен 0.

Добавляет абсолютно позиционированную [page:EllipseCurve EllipseCurve] к пути.

[method:this arc]([param:Float x], [param:Float y], [param:Float radius], [param:Float startAngle], [param:Float endAngle], [param:Boolean clockwise])

  • x, y — центр дуги, смещенный относительно последнего вызова.
  • radius — радиус дуги.
  • startAngle — начальный угол в радианах.
  • endAngle — конечный угол в радианах.
  • clockwise — развернуть дугу по часовой стрелке. По умолчанию `false`.

Добавляет [page:EllipseCurve EllipseCurve] в контур, позиционированный относительно [page:.currentPoint].

[method:this bezierCurveTo]([param:Float cp1X], [param:Float cp1Y], [param:Float cp2X], [param:Float cp2Y], [param:Float x], [param:Float y])

Создает кривую Безье из [page:.currentPoint] с (cp1X, cp1Y) и (cp2X, cp2Y) в качестве контрольных точек и обновляет [page:.currentPoint] до x и y.

[method:this ellipse]([param:Float x], [param:Float y], [param:Float xRadius], [param:Float yRadius], [param:Float startAngle], [param:Float endAngle], [param:Boolean clockwise], [param:Float rotation])

  • x, y — центр эллипса, смещенный относительно последнего вызова.
  • xRadius — радиус эллипса по оси x.
  • yRadius — радиус эллипса по оси y.
  • startAngle — начальный угол в радианах.
  • endAngle — конечный угол в радианах.
  • clockwise — развернуть эллипс по часовой стрелке. По умолчанию `false`.
  • rotation — угол поворота эллипса в радианах, против часовой стрелки от положительной оси X. Необязательно, по умолчанию `0`.

Добавляет [page:EllipseCurve EllipseCurve] в контур, позиционированный относительно [page:.currentPoint].

[method:this lineTo]([param:Float x], [param:Float y])

Соединяет [page:LineCurve] из [page:.currentPoint] с x, y на пути.

[method:this moveTo]([param:Float x], [param:Float y])

Перемещает [page:.currentPoint] к x, y.

[method:this quadraticCurveTo]([param:Float cpX], [param:Float cpY], [param:Float x], [param:Float y])

Создает квадратичную кривую из [page:.currentPoint] с cpX и cpY в качестве контрольных точек и обновляет [page:.currentPoint] до x и y.

[method:this setFromPoints]([param:Array vector2s])

points — массив[page:Vector2 Vector2].

Точки добавляются в массив [page:CurvePath.curves curves] как [page:LineCurve LineCurve].

[method:this splineThru] ([param:Array points])

points - массив [page:Vector2 Vector2].

Подключает новую [page:SplineCurve] к пути.
