[name]

Создаёт набор [page:Shape Shapes], представляющий шрифт, загруженный в формате JSON.

Конструктор

[name]([param:Object data])

data — данные JSON, представляющие шрифт.

Этот конструктор создает новый [name], который представляет собой массив [page:Shape Shapes].

Свойства

[property:Array data]

Данные JSON, переданные в конструкторе.

Методы

[method:Array generateShapes]([param:String text], [param:Float size], [param:String alignX], [param:String alignY], [param:Float lineHeight], [param:Boolean scaledEmSize])

  • [page:String text] — строка текста.
  • [page:Float size] — (необ.) масштабирование для [page:Shape Shapes]. По умолчанию `100`.
  • [page:String alignX] — (необ.) горизонтальное выравнивание текста. По умолчанию `"left"`.
  • [page:String alignY] — (необ.) вертикальное выравнивание текста. По умолчанию `"topBaseline"`.
  • [page:Float lineHeight] — (необ.) высота строки. По умолчанию `-1` for auto.
  • [page:Boolean scaledEmSize] — (необ.) уменьшать размер шрифта, чтобы соответствовать границам шрифта, а не вернему и нижнему выносным элементам. По умолчанию `false`.

Создает массив [page:Shape фигур], представляющий собой текст, отрисованный с использованием текущего шрифта. Внутри данный метод использует [page:ShapePath] для генерации фигур.
