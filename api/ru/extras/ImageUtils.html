[name]

Класс, содержащий служебные функции для изображений.

Методы

[method:String getDataURL]([param:HTMLCanvasElement|HTMLImageElement|ImageBitmap image])

image — объект изображения.

Возвращает Data URL данных, содержащий репрезентацию заданного изображения.

[method:Object sRGBToLinear]([param:HTMLCanvasElement|HTMLImageElement|ImageBitmap image])

image — объект изображения.

Преобразует sRGB-изображение в линейное цветовое пространство.
