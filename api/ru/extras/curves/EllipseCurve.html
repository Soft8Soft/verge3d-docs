[name]

Создает двухмерную кривую в форме эллипса. При установке [page:Float xRadius] равным [page:Float yRadius] получится круг.

Пример

const curve = new v3d.EllipseCurve( 0, 0, // ax, aY 10, 10, // xRadius, yRadius 0, 2 * Math.PI, // aStartAngle, aEndAngle false, // aClockwise 0 // aRotation ); const points = curve.getPoints(50); const geometry = new v3d.BufferGeometry().setFromPoints(points); const material = new v3d.LineBasicMaterial({ color: 0xff0000 }); // создаём объект и добавляем его на сцену const ellipse = new v3d.Line(geometry, material); app.scene.add(ellipse);

Конструктор

[name]([param:Float aX], [param:Float aY], [param:Float xRadius], [param:Float yRadius], [param:Float aStartAngle], [param:Float aEndAngle], [param:Boolean aClockwise], [param:Float aRotation])

  • [page:Float aX] – X координата центра эллипса. По умолчанию `0`.
  • [page:Float aY] – Y координата центра эллипса. По умолчанию `0`.
  • [page:Float xRadius] – радиус эллипса в направлении x. По умолчанию `1`.
  • [page:Float yRadius] – радиус эллипса в направлении y. По умолчанию `1`.
  • [page:Float aStartAngle] – начальный угол кривой в радианах, начиная с положительной оси X. По умолчанию `0`.
  • [page:Float aEndAngle] – конечный угол кривой в радианах, начиная с положительной оси X. По умолчанию `2 x Math.PI`.
  • [page:Boolean aClockwise] – будет ли эллипс рисоваться по часовой стрелке. По умолчанию `false`.
  • [page:Float aRotation] – угол поворота эллипса в радианах, против часовой стрелки от положительной оси X (необ.). По умолчанию `0`.
