[name]

Создаёт гладкую двухмерную квадратичную кривую Безье, заданную начальной точкой, конечной точкой и одной контрольной точкой.

Пример

const curve = new v3d.QuadraticBezierCurve( new v3d.Vector2(-10, 0), new v3d.Vector2(20, 15), new v3d.Vector2(10, 0) ); const points = curve.getPoints(50); const geometry = new v3d.BufferGeometry().setFromPoints(points); const material = new v3d.LineBasicMaterial({ color: 0xff0000 }); // создаём объект кривой и добавляем его на сцену const curveObject = new v3d.Line(geometry, material); app.scene.add(curveObject);

Конструктор

[name]([param:Vector2 v0], [param:Vector2 v1], [param:Vector2 v2])

  • [page:Vector2 v0] – начальная точка.
  • [page:Vector2 v1] – контрольная точка.
  • [page:Vector2 v2] – конечная точка.
