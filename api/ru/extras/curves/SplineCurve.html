[name]

Создает гладкую двухмерную сплайн-кривую из серии точек. Для создания кривой используется [page:Interpolations.CatmullRom] интерполяция.

Пример

// кривая похожая на волну const curve = new v3d.SplineCurve([ new v3d.Vector2(-4, 0), new v3d.Vector2(-2, 2), new v3d.Vector2(0, 0), new v3d.Vector2(2, -2), new v3d.Vector2(4, 0) ]); const points = curve.getPoints(50); const geometry = new v3d.BufferGeometry().setFromPoints(points); const material = new v3d.LineBasicMaterial({ color: 0xff0000 }); // создаём объект и добавляем на сцену const splineObject = new v3d.Line(geometry, material); app.scene.add(splineObject);

Конструктор

[name]([param:Array points])

points – Массив точек [page:Vector2], определяющих кривую.

Свойства

Общие свойства смотрите в базовом классе [page:Curve].

[property:Array points]

Массив точек [page:Vector2], определяющих кривую.
