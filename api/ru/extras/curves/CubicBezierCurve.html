[name]

Создаёт гладкую двумерную кубическую кривую Безье, заданную начальной точкой, конечной точкой и двумя контрольными точками.

Пример

const curve = new v3d.CubicBezierCurve( new v3d.Vector2(-10, 0), new v3d.Vector2(-5, 15), new v3d.Vector2(20, 15), new v3d.Vector2(10, 0) ); const points = curve.getPoints(50); const geometry = new v3d.BufferGeometry().setFromPoints(points); const material = new v3d.LineBasicMaterial({ color: 0xff0000 }); // создаём объект и добавляем его на сцену const curveObject = new v3d.Line(geometry, material); app.scene.add(curveObject);

Конструктор

[name] ([param:Vector2 v0], [param:Vector2 v1], [param:Vector2 v2], [param:Vector2 v3])

  • [page:Vector2 v0] – исходная точка.
  • [page:Vector2 v1] – первая контрольная точка.
  • [page:Vector2 v2] – вторая контрольная точка.
  • [page:Vector2 v3] – конечная точка.
