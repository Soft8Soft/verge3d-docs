[name]

Создаёт гладкую трёхмерную сплайн-кривую из серии точек с помощью алгоритма [link:https://en.wikipedia.org/wiki/Centripetal_Catmull-Rom_spline Катмулла-Рома].

Пример

// создаём волнистую замкнутую кривую const curve = new v3d.CatmullRomCurve3([ new v3d.Vector3(-10, 0, 10), new v3d.Vector3(-5, 5, 5), new v3d.Vector3(0, 0, 0), new v3d.Vector3(5, -5, 5), new v3d.Vector3(10, 0, 10) ], true); const points = curve.getPoints(50); const geometry = new v3d.BufferGeometry().setFromPoints(points); const material = new v3d.LineBasicMaterial({ color : 0xff0000 }); // создаём объект кривой и добавляем его на сцену const curveObject = new v3d.Line(geometry, material); app.scene.add(curveObject);

Конструктор

[name]([param:Array points], [param:Boolean closed], [param:String curveType], [param:Float tension])

  • points – массив [page:Vector3 точек].
  • closed – является ли кривая замкнутой. По умолчанию `false`.
  • curveType – тип кривой. По умолчанию `"centripetal"`.
  • tension – натяжение кривой. По умолчанию `0.5`.

Свойства

Общие свойства смотрите в базовом классе [page:Curve].

[property:Array points]

Массив точек [page:Vector3], определяющих кривую. Должен содержать не меньше двух элементов.

[property:Boolean closed]

Если `true`, кривая будет замыкаться сама на себя.

[property:String curveType]

Возможные значения: `"centripetal"`, `"chordal"` и `"catmullrom"`.

[property:Float tension]

Если [page:.curveType] равен `"catmullrom"`, определяет напряжение кривой.
