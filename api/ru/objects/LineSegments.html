[name]

Серия линий, проведенных между парами вершин.

Это почти то же самое, что [page:Line]; разница лишь в том, что для рендеринга используется [link:https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext/drawElements gl.LINES] вместо [link:https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext/drawElements gl.LINE_STRIP].

Конструктор

[name]([param:BufferGeometry geometry], [param:Material material])

  • [page:BufferGeometry geometry] — пара(ы) вершин, представляющих каждый сегмент(ы) линии.
  • [page:Material material] — материал для линии. По умолчанию это [page:LineBasicMaterial LineBasicMaterial].

Свойства

Общие свойства см. в базовом классе [page:Line].

[property:Boolean isLineSegments]

Указывает, что объект является экземпляром класса [name]. Только для чтения.
