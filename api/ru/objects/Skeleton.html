[name]

Представляет массив [page:Bone костей] для создания скелета, который может быть использован в [page:SkinnedMesh].

Пример

// создаём простую руку const bones = []; const shoulder = new v3d.Bone(); const elbow = new v3d.Bone(); const hand = new v3d.Bone(); shoulder.add(elbow); elbow.add(hand); bones.push(shoulder); bones.push(elbow); bones.push(hand); shoulder.position.y = -5; elbow.position.y = 0; hand.position.y = 5; const armSkeleton = new v3d.Skeleton(bones);

Пример использования со стандартной [page:BufferGeometry] смотрите на странице [page:SkinnedMesh].

Конструктор

[name]([param:Array bones], [param:Array boneInverses])

  • [page:Array bones] — массив [page:Bone костей]. По умолчанию используется пустой массив.
  • [page:Array boneInverses] — (необ.) массив из [page:Matrix4 Matrix4].

Создает новый [name].

Свойства

[property:Array bones]

Массив [page:Bone костей]. Обратите внимание, что это копия исходного массива, а не референс, поэтому вы можете изменять исходный массив, не затрагивая этот.

[property:Array boneInverses]

Массив [page:Matrix4 Matrix4], представляющий обратную сторону [page:Matrix4 matrixWorld] отдельных костей.

[property:Float32Array boneMatrices]

Буфер массива, содержащий данные о костях при использовании вертексной текстуры.

[property:DataTexture boneTexture]

[page:DataTexture] содержит данные костей при использовании вертексной текстуры.

[property:Integer boneTextureSize]

Размер [page:.boneTexture].

Методы

[method:Skeleton clone]()

Возвращает клон данного Skeleton-объекта.

[method:undefined calculateInverses]()

Генерирует массив [page:.boneInverses boneInverses], если он не предоставлен в конструкторе.

[method:this computeBoneTexture]()

Вычисляет экземпляр [page:DataTexture], который используется для подачи информации о костях в шейдер. Сама текстура назначается в [page:.boneTexture boneTexture].

[method:undefined pose]()

Возвращает скелет к базовой позе.

[method:undefined update]()

Обновляет [page:Float32Array boneMatrices] и [page:DataTexture boneTexture] после изменения костей. Это вызывается автоматически [page:WebGLRenderer], если скелет используется с [page:SkinnedMesh].

[method:Bone getBoneByName]([param:String name])

name — строка для сопоставления со свойством `.name` кости.

Ищет по массиву костей скелета и возвращает первую с совпадающим именем.

[method:undefined dispose]()

Освобождает все связанные с GPU ресурсы, используемые экземпляром [name]. Этот метод следует вызвать, если [name] больше не используется в приложении.
