[name]

Уровни детализации позволяют показывать меши с большей или меньшей детализацией геометрии в зависимости от расстояния до камеры.

Каждый уровень связан с собственным объектом, который переключается через указанное расстояние во время рендеринга. Обычно создается три меша: один для дальнего расстояния (низкая детализация), другой для среднего расстояния (средняя детализация) и один для близкого расстояния (высокая детализация).

Пример

const lod = new v3d.LOD(); // создаём сферу с 3 уровнями детализации for (let i = 0; i < 3; i++) { const geometry = new v3d.IcosahedronGeometry(10, 3 - i) const mesh = new v3d.Mesh(geometry, material); lod.addLevel(mesh, i * 75); } app.scene.add(lod);

Конструктор

[name]()

Создает новый [name].

Свойства

Общие свойства базового класса [page:Object3D].

[property:Boolean autoUpdate]

Обновляется ли объект LOD автоматически рендерером в каждом кадре или нет. Если установлено значение `false`, вы должны самостоятельно вызывать [page:LOD.update]() в цикле рендеринга. По умолчанию `true`.

[property:Boolean isLOD]

Флаг, указывающий, что данный объект является экземпляром [name]. Только для чтения.

[property:Array levels]

Массив [page:Object объектов] с уровнями детализации.

Каждый уровень представляет собой объект с тремя свойствами:

  • [page:Object3D object] — [page:Object3D объект] для отображения на этом уровне.
  • [page:Float distance] — расстояние, на котором будет отображаться данный уровень детализации.
  • [page:Float hysteresis] — порог, используемый для предотвращения мерцания на границе между уровнями детализации. Определяется как доля от расстояния.

Методы

Смотрите методы базового класса [page:Object3D].

[method:this addLevel]([param:Object3D object], [param:Float distance])

  • [page:Object3D object] — [page:Object3D объект] для отображения на этом уровне.
  • [page:Float distance] — расстояние, на котором отображается данный уровень детализации. По умолчанию `0.0`.
  • [page:Float hysteresis] — порог, используемый для предотвращения мерцания на границе между уровнями детализации. Определяется как доля от расстояния. По умолчанию `0.0`.

Добавляет меш, который будет отображаться на определенном расстоянии и дальше. Как правило, чем дальше расстояние, тем меньше детализация меша.

[method:LOD clone]()

Возвращает клон данного LOD-объекта и связанных с ним объектов, определяющих расстояние.

[method:Integer getCurrentLevel]()

Получает текущий активный уровень LOD. Индекс в массиве уровней детализации.

[method:Object3D getObjectForDistance]([param:Float distance])

Получить ссылку на первый [page:Object3D] (меш) с уровнем детализации большим, чем [page:Float distance].

[method:Array raycast]([param:Raycaster raycaster], [param:Array intersects])

Получить пересечения между отбрасываемым [page:Ray лучом] и текущим уровнем детализации. Метод [page:Raycaster.intersectObject] вызовет данный метод.

[method:undefined update]([param:Camera camera])

Установить видимость каждого [page:Object3D объекта], соответствующего [page:levels уровням детализации] в зависимости от расстояния от [page:Camera камеры].
