[name]

Непрерывная линия, которая соединяется с началом.

Это почти то же самое, что [page:Line]; разница лишь в том, что для рендеринга используется [link:https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext/drawElements gl.LINE_LOOP] вместо [link:https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext/drawElements gl.LINE_STRIP], который рисует прямую линию к следующей вершине и соединяет последнюю вершину с первой.

Конструктор

[name]([param:BufferGeometry geometry], [param:Material material])

  • [page:BufferGeometry geometry] — список вершин, представляющих точки на контуре линии.
  • [page:Material material] — материал для линии. По умолчанию [page:LineBasicMaterial LineBasicMaterial].

Свойства

Общие свойства см. в базовом классе [page:Line].

[property:Boolean isLineLoop]

Указывает, что объект является экземпляром класса [name]. Только для чтения.
