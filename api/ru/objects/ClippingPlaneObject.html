[name]

Объект, представляющий собой плоскость отсечения.

Отсечение в «Вердж3Д» является довольно сложным эффектом. Для его реализации требуются:

  • Экземпляр [name].
  • Один или несколько [page:Mesh мешей], которые нужно отсекать.
  • Два меша шаблонов (передний/задний) на каждый отсекаемый меш. Эти меши имеют ту же геометрию, что и оригинальный меш, но имеют специализированные материалы, основанные на [page:MeshBasicMaterial].
  • Опционально может быть задействована геометрия плоскости, которая показывает сечение. В отличие от мешей шаблонов, данная плоскость привязывается к [name] как дочерний объект.

Объекты шаблонов и сечений помечаются специальным флагом `.isAuxClippingMesh = true`.

Конструктор

[name]()

Создаёт новый [name].

Свойства

Смотрите свойства базового класса [page:Object3D].

[property:Boolean isClippingPlaneObject]

Указывает, что данный объект является экземпляром [name]. Только для чтения.

[property:String type]

Всегда `"ClippingPlaneObject"`, может использоваться для поиска всех плоскостей отсечения на сцене.

Методы

Смотрите методы базового класса [page:Object3D].

[method:Boolean needsClippingPlane]([param:Object3D objToClip])

objToClip — отсекаемый объект.

Проверяет, нужно ли отсекать данный меш.

[method:undefined assignToObject]([param:Object3D objToClip], [param:Float renderOrder] = 0)

  • objToClip — отсекаемый объект.
  • renderOrder — (необ.) порядок отрисовки, назначаемый дополнительным объектам-шаблонам.

Назначает параметры отсечения и дополнительные меши-шаблоны на данном объекте-меше.

[method:undefined createCrossSectionPlane]([param:Array planes], [param:Float renderOrder] = 0)

  • planes — массив со всеми плоскостями отсечения, находящимися на сцене.
  • renderOrder — (необ.) порядок отрисовки, назначаемый дополнительным объектам-шаблонам.

Создаёт и назначает дополнительную плоскость-сечение на [name].

[method:undefined cleanupAuxMeshes]([param:Object3D objToClip] = null)

objToClip — (необ.) отсекаемый объект.

Удаляет все дополнительные меши из `objToClip`, либо саму плоскость отсечения если `objToClip=null`.
