[name]

Класс практически идентичный [page:Object3D Object3D]. Его цель — сделать работу с группами объектов синтаксически более понятной.

Не путайте данные группы (разновидности объектов) с именами групп, находящимися в свойстве [page:Object3D.groupNames].

Пример

const geometry = new v3d.BoxGeometry(1, 1, 1); const material = new v3d.MeshBasicMaterial({color: 0x00ff00}); const cubeA = new v3d.Mesh(geometry, material); cubeA.position.set(100, 100, 0); const cubeB = new v3d.Mesh(geometry, material); cubeB.position.set(-100, -100, 0); // создаём группу из двух кубов // после чего эти кубы можно крутить/масштабировать как группу const group = new v3d.Group(); group.add(cubeA); group.add(cubeB); app.scene.add(group);

Конструктор

[name]()

Свойства

Общие свойства см. в базовом классе [page:Object3D].

[property:Boolean isGroup]

Указывает, что объект является экземпляром класса [name]. Только для чтения.

[property:String type]

Строка `"Group"`. Это значение не должно изменяться.
