[name]

Этот свет излучается из одной точки в одном направлении, вдоль конуса, размер которого увеличивается тем больше, чем дальше от света он находится.

Этот свет может отбрасывать тени — подробности смотрите на странице [page:SpotLightShadow].

Таргетированные и свободные источники

В «Вердж3Д» направленные источники света могут работать в двух различных режимах в зависимости от значения флага [page:.isFreeLight]. Если `isFreeLight=true`, [name] эквивалентен тому, что часто называют "Target Directional Light" в «3дс Максе». Если `isFreeLight=true`, источник света эквивалентен "Free Directional Light" в «3дс Максе», "Sun" в «Блендере» или просто "Directional Light" в «Майе».

В любом случае направление света рассчитывается как направление от [page:Object3D.position] источника света к [page:.target target]. В первом режиме `target` указывается явно, а во втором режиме `target` рассчитывается движком на основе поворота [page:Object3D.quaternion] источника освещения.

Пример

// белый прожектор, светящий сбоку и отбрасывающий тени const spotLight = new v3d.SpotLight(0xffffff); spotLight.position.set(100, 1000, 100); spotLight.castShadow = true; spotLight.shadow.mapSize.width = 1024; spotLight.shadow.mapSize.height = 1024; spotLight.shadow.camera.near = 500; spotLight.shadow.camera.far = 4000; spotLight.shadow.camera.fov = 30; app.scene.add(spotLight);

Конструктор

[name]([param:Integer color], [param:Float intensity], [param:Float distance], [param:Float angle], [param:Float penumbra], [param:Float decay])

  • [page:Integer color] — (необ.) шестнадцатеричный цвет света. По умолчанию `0xffffff` (белый).
  • [page:Float intensity] — (необ.) числовое значение силы/интенсивности света. По умолчанию `1`.
  • [page:Float distance] — максимальная дальность действия света. По умолчанию `0` (без ограничения).
  • [page:Float angle] — максимальный угол рассеивания света от его направления, верхняя граница которого равна Math.PI/2.
  • [page:Float penumbra] — процент конуса прожектора, который ослаблен из-за полутени. Принимает значения от `0` до `1`. По умолчанию `0`.
  • [page:Float decay] — величина ослабления света в зависимости от расстояния до него.

Создает новый [name].

Свойства

Общие свойства смотрите в базовом классе [page:Light Light].

[property:Float angle]

Максимальный размах прожектора, в радианах, от его направления. Должно быть не более *Math.PI/2*. По умолчанию *Math.PI/3*.

[property:Boolean castShadow]

Если установить значение `true`, свет будет отбрасывать динамические тени. Предупреждение: это дорого и требует настройки, чтобы тени выглядели правильно. Подробности смотрите в [page:SpotLightShadow]. По умолчанию используется значение `false`.

[property:Float decay]

Величина ослабления света в зависимости от расстояния до него. По умолчанию `2`. Для физически корректного освещения вам не следует менять этот параметр.

[property:Float distance]

Когда расстояние равно нулю, свет будет ослабевать по закону обратного квадрата до бесконечного расстояния. Когда расстояние ненулевое, свет будет ослабевать по обратно-квадратичному закону до тех пор, пока не приблизится к отсечке расстояния, где он будет быстро и плавно ослабевать до `0`. Подобная отсечка не является физически корректной.

По умолчанию `0.0`.

[property:Float intensity]

Интенсивность источника освещения. По умолчанию `1`. Интенсивность это сила света, измеряемая в канделах (кд).

Изменение этого параметра также изменяет мощность.

[property:Boolean isFreeLight]

Флаг, используемый для определения источников освещения без явной цели. Для таких источников виртуальный `target` рассчитывается на основе [page:Object3D.quaternion поворота], применённого к объекту источника освещения.

[property:Boolean isSpotLight]

Указывает, что данный объект является экземпляром класса [name]. Только для чтения.

[property:Float penumbra]

Процент конуса прожектора, который ослаблен из-за полутени. Принимает значения от нуля до 1. По умолчанию `0.0`.

[property:Vector3 position]

Он устанавливается равным [page:Object3D.DefaultUp] `(0, 1, 0)`, чтобы свет светил сверху вниз.

[property:Float power]

Мощность источника. Мощность это световой поток источника освещения, измеряемый в люменах (лм).

Изменение этого параметра также изменяет интенсивность.

[property:SpotLightShadow shadow]

[page:SpotLightShadow] используется для расчета теней для этого света.

[property:Object3D target]

Прожектор указывает из своего положения [page:.position position] на target.position. По умолчанию позиция целевого объекта равна `(0, 0, 0)`

Чтобы положение целевого объекта можно было изменить на любое другое, отличное от значения по умолчанию, его необходимо добавить в [page:Scene сцену] с помощью функции

app.scene.add(light.target);

Это делается для того, чтобы [page:Object3D.matrixWorld matrixWorld] целевого объекта автоматически обновлялся каждый кадр.

Если `isFreeLight=false`, также можно установить цель на другой объект в сцене (все, что имеет свойство [page:Object3D.position position]):

const targetObject = new v3d.Object3D(); app.scene.add(targetObject); light.target = targetObject;

После этого прожектор будет отслеживать целевой объект.

Методы

Общие методы смотрите в базовом классе [page:Light Light].

[method:this copy]([param:SpotLight source])

Копирует значения всех свойств из [page:SpotLight source] в данный SpotLight.

[method:undefined dispose]()

Освобождает все связанные с GPU ресурсы, используемые экземпляром [name]. Этот метод следует вызвать, если [name] больше не используется в приложении.
