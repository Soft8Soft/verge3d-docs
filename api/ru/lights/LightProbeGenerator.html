[name]

Вспомогательный класс для создания экземпляров [page:LightProbe].

Статические методы

[method:LightProbe fromCubeTexture] ([param:CubeTexture cubeTexture])

Создаёт зонд освещения на основе заданной карты освещенности (яркости). Метод предполагает, что карта окружения представлена в виде кубической текстуры.

[method:LightProbe fromCubeRenderTarget] ([param:WebGLRenderer renderer], [param:WebGLCubeRenderTarget cubeRenderTarget])

Создаёт зонд освещения на основе заданной карты окружения (яркости). Метод ожидает, что карта окружения представлена в виде кубической целевой визуализации.

Формат [page:Texture.format format] кубической карты окружения должен быть установлен в `RGBA`.
