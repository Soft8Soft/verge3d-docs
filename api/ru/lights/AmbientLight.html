[name]

Этот источник освещения равномерно освещает все объекты в сцене.

Этот свет нельзя использовать для отбрасывания теней, так как он не имеет направления.

Пример

const light = new v3d.AmbientLight(0x404040); // мягкий белый свет app.scene.add(light);

Конструктор

[name]([param:Integer color], [param:Float intensity])

  • [page:Integer color] — (необ.) числовое значение RGB-компонента цвета. По умолчанию `0xffffff` (белый).
  • [page:Float intensity] — (необ.) числовое значение силы/интенсивности света. По умолчанию — `1`.

Создаёт новый [name].

Свойства

Общие свойства смотрите в базовом классе [page:Light Light].

[property:Boolean isAmbientLight]

Указывает, что данный объект является экземпляром класса [name]. Только для чтения.

Методы

Общие методы смотрите в базовом классе [page:Light Light].

Пазлы
