[name]

Используется внутри [page:PointLight PointLights] для расчета теней.

Подобно теням от точечного источника, данные тени требуют до 6 раз больше вызовов отрисовки по сравнению с тенями от направленного света. Они также потребляют больше видеопамяти. Поэтому их лучше использовать только в случае крайней необходимости.

Конструктор

[name]()

Создает новый [name]. Этот параметр не предназначен для прямого вызова - он вызывается внутри [page:PointLight].

Свойства

Общие свойства смотрите в базовом классе [page:PointLightShadow PointLightShadow].

[property:Boolean isReactAreaLightShadow]

Указывает, что данный объект является экземпляром класса [name]. Только для чтения.

Методы

Общие методы смотрите в базовом классе [page:PointLightShadow PointLightShadow].

Пазлы

Пазл set shadow param позволяет включать/выключать отбрасывание теней без программирования.
