[name]

Используется внутри [page:PointLight PointLights] для расчета теней.

Тени от точечного света требуют до 6 раз больше вызовов отрисовки по сравнению с тенями от направленного света. Они также потребляют больше видеопамяти. Поэтому их лучше использовать только в случае крайней необходимости.

Пример

// создаём WebGLRenderer и включает тени const renderer = new v3d.WebGLRenderer(); renderer.shadowMap.enabled = true; renderer.shadowMap.type = v3d.PCFShadowMap; // по умолчанию // создаём PointLight и включает для него тени const light = new v3d.PointLight(0xffffff, 1, 100); light.position.set(0, 10, 4); light.castShadow = true; // по умолчанию false app.scene.add(light); // настраиваем тени light.shadow.mapSize.width = 512; // по умолчанию light.shadow.mapSize.height = 512; // по умолчанию light.shadow.camera.near = 0.5; // по умолчанию light.shadow.camera.far = 500; // по умолчанию // создаём сферу, отбрасывающую тени (но не принимающую) const sphereGeometry = new v3d.SphereGeometry(5, 32, 32); const sphereMaterial = new v3d.MeshStandardMaterial({ color: 0xff0000 }); const sphere = new v3d.Mesh(sphereGeometry, sphereMaterial); sphere.castShadow = true; //по умолчанию is false sphere.receiveShadow = false; //по умолчанию app.scene.add(sphere); // создаём плоскость, принимающую тени (но не отбрасывающую) const planeGeometry = new v3d.PlaneGeometry(20, 20, 32, 32); const planeMaterial = new v3d.MeshStandardMaterial({ color: 0x00ff00 }) const plane = new v3d.Mesh(planeGeometry, planeMaterial); plane.receiveShadow = true; app.scene.add(plane); // создаём вспомогательный объект для отображения камеры (опционально) const helper = new v3d.CameraHelper(light.shadow.camera); app.scene.add(helper);

Конструктор

[name]()

Создает новый [name]. Этот параметр не предназначен для прямого вызова - он вызывается внутри [page:PointLight].

Свойства

Общие свойства смотрите в базовом классе [page:LightShadow LightShadow].

[property:Boolean isPointLightShadow]

Указывает, что данный объект является экземпляром класса [name]. Только для чтения.

Методы

Общие методы смотрите в базовом классе [page:LightShadow LightShadow].

[method:undefined updateMatrices]([param:Light light], [param:number viewportIndex])

[page:Light light]
Источник освещения, для которого рендерится тень.
[page:Integer viewportIndex]
Вьюпорт для расчёта матрицы.

Обновляет матрицы для камеры и тени, используемые внутри рендерера.

Пазлы

Пазл set shadow param позволяет включать/выключать отбрасывание теней без программирования.
