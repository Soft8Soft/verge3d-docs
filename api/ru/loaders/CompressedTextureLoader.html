[name]

Абстрактный базовый класс для загрузчика текстур на основе блоков (ktx, dds, ...). Он использует [page:FileLoader] для загрузки файлов.

Конструктор

[name]([param:LoadingManager manager])

[page:LoadingManager manager] — [page:LoadingManager loadingManager] для использования загрузчиком. По умолчанию [page:LoadingManager v3d.DefaultLoadingManager].

Создает новый [name].

Свойства

Общие свойства см. в базовом классе [page:Loader].

Методы

Общие методы см. в базовом классе [page:Loader].

[method:CompressedTexture load]([param:String url], [param:Function onLoad], [param:Function onProgress], [param:Function onError])

  • [page:String url] — путь или URL-адрес к файлу. Это также может быть [link:https://developer.mozilla.org/en-US/docs/Web/HTTP/Basics_of_HTTP/Data_URIs Data URI].
  • [page:Function onLoad] — будет вызван после завершения загрузки. Аргументом будет загруженная текстура.
  • [page:Function onProgress] — вызывается в процессе загрузки. Аргументом будет экземпляр ProgressEvent, который содержит .[page:Boolean lengthComputable], .[page:Integer total] и .[page:Integer loaded]. Если сервер не устанавливает заголовок Content-Length header, .[page:Integer total] будет равен `0`.
  • [page:Function onError] — вызывается при ошибках загрузки.

Начинает загрузку из `url` и передаёт загруженную текстуру в `onLoad`. Метод также возвращает новый текстурный объект, который может быть использован при создании материала.
