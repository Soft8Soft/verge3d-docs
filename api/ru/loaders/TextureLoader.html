[name]

Класс для загрузки текстуры [page:Texture]. Внутри этот класс использует [page:ImageLoader] для загрузки файлов.

Пример

const texture = new v3d.TextureLoader().load('mytexture.jpg'); // immediately use the texture for material creation const material = new v3d.MeshBasicMaterial({ map: texture });

Пример кода с обратными вызовами

// создаём экземпляр загрузчика const loader = new v3d.TextureLoader(); // загружаем ресурс loader.load( // resource URL 'mytexture.webp', // onLoad коллбек function(texture) { // в данном примере создадим материал по окончании загрузки текстуры const material = new v3d.MeshBasicMaterial({ map: texture }); }, // onProgress коллбек не поддерживается undefined, // onError коллбек function(err) { console.error('Произошла ошибка.'); } );

Конструктор

[name]([param:LoadingManager manager])

[page:LoadingManager manager] — [page:LoadingManager loadingManager] для использования загрузчиком. По умолчанию [page:LoadingManager v3d.DefaultLoadingManager].

Создает новый [name].

Свойства

Общие свойства см. в базовом классе [page:Loader].

Методы

Общие методы см. в базовом классе [page:Loader].

[method:Texture load]([param:String url], [param:Function onLoad], [param:Function onProgress], [param:Function onError])

  • [page:String url] — путь или URL-адрес к файлу. Также может быть [link:manual/ru/puzzles/HTML.html#data_url Data URL].
  • [page:Function onLoad] — (необ.) будет вызван после завершения загрузки. Аргументом будет загруженная [page:Texture текстура].
  • [page:Function onProgress] — (необ.) в данный момент не поддерживается.
  • [page:Function onError] — (необ.) вызывается при ошибках загрузки.

Начинает загрузку заданного URL и передаёт полностью загруженную [page:Texture текстуру] в onLoad. Метод также возвращает новый объект текстуры, который может быть непосредственно использован для создания материала. Таким образом, текстура может появиться на сцене после завершения процесса загрузки.
