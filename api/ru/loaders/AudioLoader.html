[name]

Класс для загрузки [link:https://developer.mozilla.org/en-US/docs/Web/API/AudioBuffer AudioBuffer]. Для загрузки файлов используется [page:FileLoader].

Пример

// instantiate a listener const audioListener = new v3d.AudioListener(); // add the listener to the camera camera.add(audioListener); // instantiate audio object const oceanAmbientSound = new v3d.Audio(audioListener); // add the audio object to the scene app.scene.add(oceanAmbientSound); // instantiate a loader const loader = new v3d.AudioLoader(); // load a resource loader.load( // resource URL 'audio/ambient_ocean.ogg', // onLoad callback function(audioBuffer) { // set the audio object buffer to the loaded object oceanAmbientSound.setBuffer(audioBuffer); // play the audio oceanAmbientSound.play(); }, // onProgress callback function(xhr) { console.log((xhr.loaded / xhr.total * 100) + '% loaded'); }, // onError callback function(err) { console.log('An error happened'); } );

Конструктор

[name]([param:LoadingManager manager])

[page:LoadingManager manager] — [page:LoadingManager loadingManager] для использования загрузчиком. По умолчанию [page:LoadingManager v3d.DefaultLoadingManager].

Создает новый [name].

Свойства

Общие свойства см. в базовом классе [page:Loader].

Методы

Общие методы см. в базовом классе [page:Loader].

[method:undefined load]([param:String url], [param:Function onLoad], [param:Function onProgress], [param:Function onError])

  • [page:String url] — путь или URL-адрес к файлу. Это также может быть [link:https://developer.mozilla.org/en-US/docs/Web/HTTP/Basics_of_HTTP/Data_URIs Data URI].
  • [page:Function onLoad] — будет вызван после завершения загрузки. Аргументом будет загруженный текстовый отклик.
  • [page:Function onProgress] — вызывается в процессе загрузки. Аргументом будет экземпляр ProgressEvent, который содержит .[page:Boolean lengthComputable], .[page:Integer total] и .[page:Integer loaded]. Если сервер не устанавливает заголовок Content-Length header, .[page:Integer total] будет равен `0`.
  • [page:Function onError] — вызывается при ошибках загрузки.

Начинает загрузку `url` и передаёт загруженный [page:String AudioBuffer] в `onLoad`.
