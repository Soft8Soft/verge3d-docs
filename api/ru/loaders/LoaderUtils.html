[name]

Объект с полезными функциями, используемыми загрузчиками.

Функции

[method:String decodeText]([param:TypedArray array])

[page:TypedArray array] — поток байтов в виде типизированного массива.

Функция принимает на вход поток байтов и возвращает их в виде Юникод-строки.

[method:String extractUrlBase]([param:String url])

[page:String url] — УРЛ для извлечения базового адреса.

Извлекает базовый адрес из URL-адреса. Например, ``https://example.com/mydata.csv`` становится ``https://example.com/``.

[method:String resolveURL]([param:String url], [param:String path])

  • [page:String url] — абсолютный или относительный УРЛ-адрес.
  • [page:String path] — базовый путь для резолвинга относительных путей.

Резолвит относительный УРЛ-адрес относительно указанного пути. Абсолютные пути, Data URL и Blob URL возвращаются как есть. Неверные пути возвращают пустую строку.
