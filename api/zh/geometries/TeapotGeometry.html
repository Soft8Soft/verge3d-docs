[name]

A class for generating Utah teapot geometry.

Code Example

const geometry = new v3d.TeapotGeometry(2); const material = v3d.MaterialUtils.createStandardPBRMaterial('blender', { color: 'gold', roughness: 0.2, metalness: 1 }); const teapot = new v3d.Mesh(geometry, material); app.scene.add(teapot);

Constructor

[name]([param:Float size], [param:Integer segments], [param:Boolean bottom], [param:Boolean lid], [param:Float body], [param:Boolean fitLid], [param:Boolean blinn])

  • [page:Float size] — radius of the teapot. Default is `1`.
  • [page:Integer segments] — number of segmented used to generate teapot. Default is `10`.
  • [page:Boolean bottom] — generate bottom geometry. Default is `true`.
  • [page:Boolean lid] — generate lid geometry. Default is `true`.
  • [page:Boolean body] — generate body geometry. Default is `true`.
  • [page:Boolean fitLid] — stretch lid a bit so no gap left. Default is `false`.
  • [page:Boolean blinn] — Jim Blinn vertical scaling. With this scaling applied the teapot will look nicer. Default is `true`.

Procedural geometry is fun. However, in real life applications this feature is rarely needed. It would be more efficient do design teapots in the preferred modelling suite and export/load to Verge3D via glTF.
