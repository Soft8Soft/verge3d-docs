[name]

Camera controls.

Controls Constants

These constants define camera controls.

Tweening Movement Types

v3d.TweenLinear v3d.TweenSpherical

Constructor

[name]([param:Camera object], [param:HTMLElement domElement])

[page:Camera object]
The camera to be controlled.
[page:HTMLElement domElement]
The HTML element used for event listeners (optional). By default this is the whole document, however if you only want to the controls to work over a specific element (e.g. the canvas) you can specify that here.

Creates a new [name]. Note that this class is not intended to be called directly; you probably want to use [page:OrbitControls], [page:FlyingControls], or [page:FirstPersonControls] instead.

Properties

[property:Boolean allowMouseOverIframes]

Whether or not the mouse will be allowed to move above the `<iframe>` elements located on the page, when it's controlling the camera. Default is `false`. Please note that if the [page:App.enableCSSRenderer]() method is called, it will set [page:.allowMouseOverIframes] to `true`.

To allow camera movements when mouse cursor is above iframes, the internal mouse event listeners execute [page:.lockIframeEvents]() once the user starts moving the camera, and [page:.unlockIframeEvents]() once the movement is stopped.

[property:HTMLElement domElement]

The HTMLElement used to listen for mouse / touch events. This must be passed in the constructor; changing it here will not set up new event listeners. Default is the whole document.

[property:Boolean enabled]

Whether or not the controls are enabled.

[property:Camera object]

The camera (or other object) that is being controlled.

Methods

[method:undefined lockIframeEvents]()

Prevent all `<iframe>` elements located on the current page to capture user events. Usually this method is called by the internal event listeners of the corresponding controls class. To be able to execute it manually, set [page:.allowMouseOverIframes] to `false`.

[method:Float unlockIframeEvents]()

Allow all `<iframe>` elements located on the current page to capture user events. Usually this method is called by the internal event listeners of the corresponding controls class. To be able to execute it manually, set [page:.allowMouseOverIframes] to `false`.
