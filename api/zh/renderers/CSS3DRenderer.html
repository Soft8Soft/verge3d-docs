[name]

[name] can be used to apply hierarchical 3D transformations to HTML elements. This renderer is useful to combine HTML elements with WebGL content, e.g. to embed whole websites, YouTube videos, or custom web UI into a 3D scene.

The [name] operates with HTML elements, not regular Verge3D objects. These elements should be wrapped into special objects [page:CSS3DObject] and then added to the scene graph.

Example

if (!app.cssRenderer) app.enableCSSRenderer(); // place renderer above 3D canvas app.cssRenderer.viewElement.style.zIndex = 0; const iframe = document.createElement('iframe'); iframe.src = 'https://www.soft8soft.com'; iframe.style.border = 'none'; iframe.width = 800; iframe.height = 600; const cssObject = new v3d.CSS3DObject(iframe); // 5 units width cssObject.scale.setScalar(5/iframe.width); app.cssScene.add(cssObject);

Constructor

[name]([param:HTMLElement domElement])

[page:HTMLElement element] — an HTML element where the renderer appends its child-elements.

This corresponds to the [page:CSS3DRenderer.domElement domElement] property below.

Properties

[property:HTMLElement domElement]

An [page:HTMLElement] where the renderer appends its child-elements.

[property:HTMLElement viewElement]

An [page:HTMLElement] representing viewing plane (created automatically by constructor).

Methods

[method:Object getSize]()

Returns an object containing the width and height of the renderer.

[method:undefined render]([param:Scene scene], [param:Camera camera])

Renders a [page:Scene scene] using a [page:PerspectiveCamera perspective] or [page:OrthographicCamera orphographic] camera.

[method:undefined setSize]([param:Float width], [param:Float height])

Resizes the renderer to specified width and height.

Puzzles

There is a puzzle create object / plane with html to create planes which render HTML-based resources, such as websites, custom UIs, or YouTube videos. This puzzle uses [name] under the hood.
