[name]

Creates a texture based on data in compressed form, for example from a [link:https://www.khronos.org/ktx/ KTX] file.

For use with the [page:CompressedTextureLoader CompressedTextureLoader].

Constructor

[name]([param:Array mipmaps], [param:Integer width], [param:Integer height], [param:Constant format], [param:Constant type], [param:Constant mapping], [param:Constant wrapS], [param:Constant wrapT], [param:Constant magFilter], [param:Constant minFilter], [param:Integer anisotropy], [param:Constant encoding])

  • [page:Array mipmaps] — the mipmaps array should contain objects with data, width and height. The mipmaps should be of the correct format and type.
  • [page:Integer width] — the width of the biggest mipmap.
  • [page:Integer height] — the height of the biggest mipmap.
  • [page:Constant format] — the format used in the mipmaps. See [page:Textures ST3C Compressed Texture Formats], [page:Textures PVRTC Compressed Texture Formats] and [page:Textures ETC Compressed Texture Format] for possible choices.
  • [page:Constant type] — default is [page:Textures v3d.UnsignedByteType]. See [page:Textures type constants] for other choices.
  • [page:Constant mapping] — how the image is applied to the object. An object type of [page:Textures v3d.UVMapping]. See [page:Textures mapping constants] for other choices.
  • [page:Constant wrapS] — the default is [page:Textures v3d.ClampToEdgeWrapping]. See [page:Textures wrap mode constants] for other choices.
  • [page:Constant wrapT] — the default is [page:Textures v3d.ClampToEdgeWrapping]. See [page:Textures wrap mode constants] for other choices.
  • [page:Constant magFilter] — how the texture is sampled when a texel covers more than one pixel. The default is [page:Textures v3d.LinearFilter]. See [page:Textures magnification filter constants] for other choices.
  • [page:Constant minFilter] — how the texture is sampled when a texel covers less than one pixel. The default is [page:Textures v3d.LinearMipmapLinearFilter]. See [page:Textures minification filter constants] for other choices.
  • [page:Integer anisotropy] — the number of samples taken along the axis through the pixel that has the highest density of texels. By default, this value is 1. A higher value gives a less blurry result than a basic mipmap, at the cost of more texture samples being used. Use renderer.getMaxAnisotropy() to find the maximum valid anisotropy value for the GPU; this value is usually a power of 2.

Properties

See the base [page:Texture Texture] class for inherited properties.

[property:Boolean flipY]

False by default. Flipping textures does not work for compressed textures.

[property:Boolean generateMipmaps]

False by default. Mipmaps can't be generated for compressed textures

[property:Boolean isCompressedTexture]
