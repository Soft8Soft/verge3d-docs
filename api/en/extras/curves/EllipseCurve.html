[page:Curve] →

[name]

Creates a 2D curve in the shape of an ellipse. Setting the [page:Float xRadius] equal to the [page:Float yRadius] will result in a circle.

Code Example

const curve = new v3d.EllipseCurve( 0, 0, // ax, aY 10, 10, // xRadius, yRadius 0, 2 * Math.PI, // aStartAngle, aEndAngle false, // aClockwise 0 // aRotation ); const points = curve.getPoints(50); const geometry = new v3d.BufferGeometry().setFromPoints(points); const material = new v3d.LineBasicMaterial({ color: 0xff0000 }); // create the final object to add to the scene const ellipse = new v3d.Line(geometry, material); app.scene.add(ellipse);

Constructor

[name]([param:Float aX], [param:Float aY], [param:Float xRadius], [param:Float yRadius], [param:Float aStartAngle], [param:Float aEndAngle], [param:Boolean aClockwise], [param:Float aRotation])

  • [page:Float aX] – the X center of the ellipse. Default is `0`.
  • [page:Float aY] – the Y center of the ellipse. Default is `0`.
  • [page:Float xRadius] – the radius of the ellipse in the x direction. Default is `1`.
  • [page:Float yRadius] – the radius of the ellipse in the y direction. Default is `1`.
  • [page:Float aStartAngle] – the start angle of the curve in radians starting from the positive X axis. Default is `0`.
  • [page:Float aEndAngle] – the end angle of the curve in radians starting from the positive X axis. Default is `2 x Math.PI`.
  • [page:Boolean aClockwise] – whether the ellipse is drawn clockwise. Default is `false`.
  • [page:Float aRotation] – the rotation angle of the ellipse in radians, counterclockwise from the positive X axis (optional). Default is `0`.
