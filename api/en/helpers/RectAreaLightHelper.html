[page:Object3D] → [page:Line] →

[name]

Creates a visual aid for a [page:RectAreaLight].

Code Example

const light = new v3d.RectAreaLight(0xffffbb, 1.0, 5, 5); const helper = new RectAreaLightHelper(light); light.add(helper); // helper must be added as a child of the light

Constructor

[name]([param:RectAreaLight light], [param:Color|Integer|String color])

  • [page:RectAreaLight light] — the light being visualized.
  • [page:Color color] — (optional) if this is not the set the helper will take the color of the light.

Properties

See the base [page:Line] class for common properties.

[property:RectAreaLight light]

Reference to the [page:RectAreaLight] being visualized.

[property:Color color]

The color parameter passed in the constructor. Default is `undefined`.
