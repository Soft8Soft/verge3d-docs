[page:Constraint] →

[name]

A constraint which shows/hides the object depending on 3D viewport width/height or orientation settings (implements the so called visibility breakpoints).

To influence some object, push a [name] instance into the [page:Object3D.constraints] array.

Constructor

[name]()

The constructor takes no arguments.

Properties

See the base [page:Constraint] class for common properties.

[property:App appInstance]

The current [page:App application]. Default is `undefined`.

[property:Boolean isCanvasBreakpointsConstraint]

Used to check whether this or derived classes are canvas breakpoints constraints. Default is `true`.

[property:Integer maxHeight]

Maximum canvas height the object stays visible. Default is `Infinity`.

[property:Integer maxWidth]

Maximum canvas width the object stays visible. Default is `Infinity`.

[property:Integer minHeight]

Minimum canvas height the object stays visible. Default is `0`.

[property:Integer minWidth]

Minimum canvas width the object stays visible. Default is `0`.

[property:String orientation]

Screen orientation the object stays visible.

  • `"ALL"` — object stays visible for any screen orientation
  • `"LANDSCAPE"` — object stays visible only for landscape (horizontal) screen orientation
  • `"PORTRAIT"` — object stays visible only for portrait (vertical) screen orientation

Default is `"ALL"`.

[property:String type]

The constraint's type. Equals to `"CanvasBreakpointsConstraint"`.

Methods

See the base [page:Constraint] class for common methods.

[method:Camera findAlternativeCamera]([param:Camera camera], [param:Scene scene], [param:Integer width], [param:Integer height])

  • camera — the current camera in scene.
  • scene — the scene in which we are looking for the camera.
  • width — the canvas width.
  • height — the canvas height.

Find and return an alternative camera (with acceptable visibility breakpoints) located on the specified scene. If no alternative camera is found, returns `null`.
