[page:TargetConstraint] →

[name]

This constraint fits camera-parented UI elements such as buttons, panels, or texts, regardless of the screen resolution or a device.

To influence some object, push a [name] instance into the [page:Object3D.constraints] array.

Constructor

[name]([param:Object3D target])

[page:Object3D target] — constraint's target object.

Properties

See the base [page:TargetConstraint] class for common properties.

[property:String edgeH]

The horizontal canvas edge to fit to. Default is `'NONE'`.

  • `'LEFT'` — left edge.
  • `'RIGHT'` — right edge.
  • `'STRETCH'` — stretch from left to right edge.
  • `'NONE'` — no horizontal fit.

[property:String edgeV]

The vertical canvas edge to fit to. Default is `'NONE'`.

  • `'TOP'` — top edge.
  • `'BOTTOM'` — bottom edge.
  • `'STRETCH'` — stretch from top to bottom.
  • `'NONE'` — no vertical fit.

[property:Float offset]

Additional fit offset (can be negative). Default is `0.0`.

[property:Boolean isCanvasFitConstraint]

Read-only flag to check if a given object is of type [name].

[property:String type]

The constraint's type. Equals to `"CanvasFitConstraint"`.

[property:String fitShape]

Bounding shape for canvas fit. Default is `'BOX'`.

  • `'SPHERE'` — bounding sphere.
  • `'BOX'` — bounding box.
  • `'POINT'` — zero-sized fit shape (point).
