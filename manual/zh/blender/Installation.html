安装/Blender

[contents] [anchor:Prerequisites]

先决条件

Verge3D可以基于Blender 4.2-5.0运行，请预先安装对应的版本。我们推荐使用最新兼容版本以获得最多功能和更长的可用期。Blender是一款开源软件，可从 官方网站 免费下载。

[anchor:Downloading_Verge3D]

下载Verge3D

下载适用于您的操作系统的 Verge3D for Blender （Windows的 .exe 安装程序，macOS的 .pkg 安装程序，或Linux/ChromeOS的 .xz 压缩包）。

[anchor:Installation_for_Windows]

在Windows中安装

双击 .exe 文件以运行安装程序。

点击链接阅读最新版本的 Verge3D 许可协议。

选择您要安装的组件。

选择一个有足够读写权限的安装目录（建议使用默认路径）。

请等待安装程序执行完成。

当安装完成时，屏幕显示如下。

请点击完成并打开Blender。如果Blender正在运行，请先关闭然后再次打开。

您也可以通过桌面图标或开始菜单中的快捷方式来打开应用管理器，这种启动方式无需启动Blender。

[anchor:installation_macos]

在macOS中安装

双击 .pkg 文件以运行安装程序。

点击链接阅读最新版本的 Verge3D 许可协议。

然后点击*同意*以接受许可协议。

您可以快速跳过下一步，因为Verge3D在macOS上始终安装到用户主目录中。

请等待安装程序完成文件复制。

安装完成后，您将看到以下屏幕。

点击*关闭*并打开Blender。如果Blender正在运行，请先关闭然后再次打开。

您也可以通过Launchpad中的图标来打开应用管理器，无需启动Blender：

[anchor:installation_linux]

在Linux中安装

将 .xz 压缩包解压到您选择的目录中。请确保您有足够的权限在此文件夹中进行读/写操作。不建议在系统目录中安装。在下文中，我们将解压后的目录称为 Verge3D安装文件夹。

在Blender中，通过选择*编辑*菜单中的相应选项来打开*偏好设置*窗口。

在*获取扩展*选项卡上，点击*仓库*菜单。在打开的对话框中，点击*添加*（+）按钮来添加一个新仓库。

选择*添加本地仓库*。

在接下来的对话框中，将"Soft8Soft"指定为仓库名称，激活*自定义目录*，然后提供解压后的Verge3D压缩包中"addons"文件夹的路径。点击*创建*按钮。

请注意此步骤。指定的文件夹应以"addons"结尾，而不是"addons/verge3d"。

从扩展菜单（*v*）中点击*查看详情*以打开扩展设置（或者您也可以在*插件*选项卡中找到Verge3D）。

启用Verge3D扩展，然后关闭*Blender偏好设置*窗口。

安装完成！

[anchor:installation_chromeos_blender]

在ChromeOS上安装Blender

要在ChromeOS上安装Blender，请启动终端：

执行以下命令以更新仓库元数据：

sudo apt update

然后安装Blender（及其所有依赖项）：

sudo apt install blender

Verge3D插件还需要 *numpy* 库（由导出器使用）和 *zenity* 工具（使应用管理器设置对话框正常工作）。以类似方式安装两者：

sudo apt install python3-numpy zenity

Blender安装完成！您可以像其他ChromeOS应用一样使用快捷方式运行它：

[anchor:installation_chromeos_verge3d]

安装Verge3D

打开Verge3D的 .xz 压缩包并将其解压到您选择的文件夹中。为了简化在Blender设置中指定Verge3D文件夹，建议将 *verge3d_blender* 直接解压到*Linux文件*中：

在Blender中，通过选择*编辑*菜单中的相应选项来打开*偏好设置*窗口，然后转到*文件路径*：

在*文件路径*选项卡上，找到*脚本*字段，并将其路径指向Verge3D安装的文件夹。关闭*偏好设置*窗口并 重启Blender。

再次打开*偏好设置*窗口并转到*插件*选项卡。找到并启用Verge3D插件，然后关闭窗口。

点击*应用管理器*按钮并继续下一步。

[anchor:installation_chromeos_first_run]

首次运行

首次运行时，会显示一个启动画面，提示您设置Verge3D应用程序文件夹的路径。您可以保持默认值。在这种情况下，Verge3D应用程序将在Linux环境中创建：

设置好应用程序文件夹后，点击*应用*。安装完成！

或者，如果您希望将应用程序保存在ChromeOS中，请执行以下操作。在ChromeOS的*文件*中创建一个文件夹，右键点击它并在菜单中选择*与Linux共享*。以类似方式，您还可以提供位于Google Drive或Windows共享上的文件夹。
