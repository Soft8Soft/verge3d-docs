PayPal拼图

[anchor:paypal_create_order]

paypal create order(创建Paypal订单)

下PayPal订单。此拼图是最简单的电子商务解决方案，因为它无需任何服务器端配置。要使用他，您需要由已通过验证的PayPal企业账号。

client ID
PayPal企业账号客户ID，请在 此页 获取。其提供了用于测试目的沙盒凭证，如果要用于真实销售，您需要执行 额外的步骤 来接收实时凭证。
title
产品标题。
item price
产品单价。
currency
货币。
quantity
产品数量。
on success do
此插槽中的拼图将在交易成功后执行。
on error do
此插槽中的拼图将在遇到错误时执行（例如资金不足等情况）。

[anchor:woo_product_info]

product info(产品信息)

返回一个 dictionary(字典) ，其中包含由 connect to WooCommerce 拼图检索的产品信息：

该字典包含以下字段：

price
客户选择的产品选项的价格，例如：12。
quantity
客户选择的产品项目的数量，例如：2。
sku
客户选择的产品选项的库存单位。
name
产品的名称，因为它将在商店的购物车中看到，例如 "Spinner - Yellow, Large"。
attributes
一个包含客户所选产品选项的属性名称/值对的字典，例如：{color: "Yellow", size: "Large"}。
weight
客户选择的产品选项的实际产品重量。
length, width, height
客户选择的产品选项的实际产品尺寸。
type
在WooCommerce管理面板中指定的以下产品类型之一："variable"、"simple"、"group"、"external" 或 "composite"。
children
只对 "group" 产品有效。返回包含每个子产品信息的列表。
components
只对 "composite" 产品有效。返回包含每个组件信息的列表。为方便使用，您可以使用 product component 拼图来获取此信息。
status
服务器响应："ok" 或 "error"。
[anchor:woo_product_attribute]

product attribute(产品属性)

返回客户选择的产品选项属性值，例如：对于属性 "color" 返回 "Yellow"。如果该属性不存在，拼图返回 `""` （空字符串）。

此拼图最常用于获取 "variable" 产品当前选定的变体。传入的属性名称以不区分大小写的方式进行匹配，例如 "Color"、"color" 或 "COLOR" 表示相同的属性。

详情见此教程： 英文版 ，中文版。

[anchor:woo_product_component]

product component(产品组件)

返回由 WooCommerce Composite Products 扩展提供的产品组件的值。

为方便使用，您可以将组件名称（标题）（例如 "Drawer Top"）或组件ID（例如 "1685435951"）作为第一个参数指定。

您可以从组件中检索以下值之一：

product name
在组件中选择的产品名称。如果未选择产品，则等于 `""` （空字符串）。
sku
在组件中选择的产品SKU。如果未选择产品或产品未分配SKU，则等于 `""` （空字符串）。
quantity
产品数量。
type
产品类型："simple"、"variable"，或未选择产品时为 "none"。
weight
产品重量。如果未指定产品重量，则等于 0（零）。
width
产品宽度。如果未指定产品宽度，则等于 0（零）。
height
产品高度。如果未指定产品高度，则等于 0（零）。
length
产品长度。如果未指定产品长度，则等于 0（零）。
attributes
分配给所选产品的属性字典。在大多数情况下，此值用于获取 "variable" 产品当前选定变体的属性。
component title
组件名称（标题），例如 "Drawer Top"。不要与产品名称混淆。
component id
组件ID，例如 "1685435951"。

WordPress订单表单拼图

[anchor:place_order]

place order(下单)

编写订单并将其提交到指定的 URL。默认情况下，订购表单会被提交到 sandbox ordering page。

[demo:ring]

Verge3D带有一个免费的Wordpress插件，用于处理由这个拼图提交的请求。收到此类请求后，此Wordpress插件会生产带有扩展表单的页面，并补充联系人、评论、屏幕截图等字段。填好的表单最后由客户提交，并在Wordpress管理界面创建一个新的订单。

send to
WordPress 插件提供的订单表单的 URL。请参考 此处指南 ，了解设置方法。
content
订单内容（以人类可读的形式呈现）。
item price
产品项目价格。
quantity
产品的数量。
make screenshot
生成应用屏幕截图并将其附加到订单中。请确保在 configure application(配置应用程序) 拼图中启用屏幕截图，否则屏幕截图可能会显示为纯黑色。

由您（或销售经理）来验证订单内容和价格的正确性。尽管可能性很小，但黑客可能会通过篡改此拼图提交的内容，尝试以较低的价格购买产品。为防止此类事件，您需要使用 place order + 拼图，该拼图依赖于服务器上分配的产品信息来验证订单。

[anchor:place_order_adv]

place order +

编写订单并将其提交到指定的 URL。此拼图工作方式类似于 place order ，但有更多特性，安全性也更高，并且允许自定义。

[demo:recliner/index]
send to
WordPress 插件提供的订单表单的 URL。有关设置信息，请参阅 此处指南 。
item(s)
订单项目或订单项目列表。参阅 下文 了解详情。
attachment(s)
订单附件或订单附件列表。附件是一个 Data URL link ，用来表示屏幕截图、图片、声音，视频，PDF，文本或glTF模型。

quantity
