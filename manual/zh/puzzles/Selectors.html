选择器 | Selectors

此类拼图用于选择3D对象、组、动画片段和材质，以适配其他拼图。

拼图参考

[anchor:select_object]

select object

下拉菜单包含按字母顺序排列的场景中所有对象的列表。

[anchor:all_objects]

all objects

表示场景中的所有对象，以便可以批量对其应用操作。

此拼图不可迭代，例如它不能用作for each in list拼图的输入。要迭代对象列表，请使用get objects from拼图。

[anchor:select_group]

select group

下拉菜单包含按字母顺序排列的场景中所有对象组的列表。可以批量对组中的对象应用操作。

"组"实际代表的内容取决于您的建模套件。在Blender中，这是对象的集合（最顶层的"Scene Collection"不会暴露给拼图）：

在3ds Max中，可以是组（"Furniture"）或选择集（"Furniture2"）：

在Maya中，可以是组（"Furniture"）或集（"Furniture2"）：

"select group"拼图不可迭代，例如它不能用作for each in list拼图的输入。要迭代对象列表，请使用get objects from拼图。

[anchor:select_animation]

select animation

下拉菜单包含按字母顺序排列的场景中所有动画片段的列表。动画片段根据在Blender、3ds Max或Maya中应用动画的对象来命名。

[anchor:select_material]

select material

下拉菜单包含按字母顺序排列的场景中所有材质的列表。

[anchor:get_entity_by_name]

get by name

选择由其名称给定的实体（对象、组、动画片段或材质）。

此拼图最常见的用例是动态场景加载，当加载的实体名称无法通过基于列表的选择器选择时。
